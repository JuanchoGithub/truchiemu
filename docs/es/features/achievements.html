Integracion con RetroAchievements

TruchiEmu se integra con RetroAchievements.org para rastrear y desbloquear logros en juegos clasicos.

Vista General del Servicio

El servicio de RetroAchievements se conecta a RetroAchievements.org para rastrear y desbloquear logros durante el juego. Se integra con el core de Libretro para detectar condiciones de logros en tiempo real.

Pipeline de deteccion de logros desde la memoria del juego hasta la sincronizacion con RetroAchievements.org

Caracteristicas Principales

  • Desbloqueo en Tiempo Real: Los logros se detectan y desbloquean durante el juego
  • Rich Presence: Comparte tu juego y actividad actual con la comunidad de RetroAchievements
  • Modo Hardcore: Gana logros sin save states, rebobinado ni cheats para maximo prestigio

Para detalles de implementacion, consulta la Guia del Desarrollador.

Guia de Configuracion Paso a Paso

Configuracion Inicial

  1. Crea una Cuenta de RetroAchievements

    Visita RetroAchievements.org y crea una cuenta gratuita. Verifica tu direccion de correo electronico para desbloquear la funcionalidad completa.

  2. Configura las Credenciales en TruchiEmu

    En TruchiEmu, ve a Settings → Achievements → Account e ingresa tu nombre de usuario y API key de RetroAchievements. Genera tu API key desde el sitio web de RetroAchievements en Account Settings.

  3. Prueba la Conexion

    Haz clic en "Test Connection" para verificar que tus credenciales funcionen correctamente. Deberias ver un mensaje de exito con tus estadisticas actuales.

  4. Habilita la Deteccion de Logros

    Activa "Enable Achievement Detection" en el panel principal de configuracion de Achievements.

  5. Configura Rich Presence

    Habilita "Show Rich Presence" para compartir tu actividad de juego con Discord y la comunidad de RA. Personaliza el formato del mensaje en el campo de texto proporcionado.

Configuracion Especifica por Juego

  1. Carga un Juego Compatible

    Abre una ROM de un sistema compatible. TruchiEmu detecta automaticamente si el juego tiene logros disponibles.

  2. Ve la Lista de Logros

    Abre la lista de logros desde el menu del juego para ver todos los logros disponibles para el juego actual.

  3. Rastrea el Progreso de Logros

    El progreso de los logros se muestra durante el juego con notificaciones en pantalla cuando se cumplen las condiciones.

Solucion de Problemas

Logros No Se Desbloquean

Sintoma: Estás jugando un juego compatible pero los logros no se detectan.

Solucion: Verifica que tu ROM sea la version correcta (usualmente USA/World). Compara el hash de la ROM contra la base de datos de RetroAchievements. Asegurate de que la deteccion de logros este habilitada en la configuracion.

Errores de Conexion

Sintoma: Aparece el mensaje de error "Failed to connect to RetroAchievements.org".

Solucion: Verifica tu conexion a internet y la configuracion del firewall. Comprueba que la API key sea correcta y no haya expirado. Intenta generar una nueva API key desde el sitio web de RA.

Rich Presence No Funciona

Sintoma: Discord o el perfil de RA no muestra el estado actual del juego.

Solucion: Habilita rich presence en la configuracion. Verifica que no estes en Modo Hardcore (algunas plataformas desactivan rich presence por integridad competitiva). Comprueba la conexion de Discord en la configuracion de Privacidad de macOS.

Restricciones del Modo Hardcore

Sintoma: No puedes usar save states ni rebobinado despues de habilitar el Modo Hardcore.

Solucion: Este es el comportamiento esperado. El Modo Hardcore desactiva estas funciones por equidad competitiva. Desactiva el Modo Hardcore para restaurar la funcionalidad.
