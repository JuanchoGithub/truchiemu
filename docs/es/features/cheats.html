Sistema de Trucos

Descripción General

TruchiEmu viene con una biblioteca integrada de códigos de trucos para miles de juegos. Cuando cargas una ROM, los trucos conocidos aparecen en el panel de Trucos: elige cuáles quieres y se aplican en vivo. También puedes ingresar tus propios códigos si los que quieres aún no están en la biblioteca.

Lo Que Ofrece

  • Biblioteca de Trucos Integrada: Colecciones de trucos prefabricadas para miles de juegos, obtenidas del libretro-database
  • Auto-Descubrimiento: Los trucos del juego actual aparecen en el panel automáticamente cuando cargas una ROM
  • Activación en Vivo: Activa y desactiva trucos sin reiniciar el juego
  • Persistencia de Estado: Una vez que habilitas un truco, permanece habilitado para ese juego hasta que lo desactives
  • Tus Propios Códigos: Agrega manualmente códigos de Game Genie, Pro Action Replay, GameShark o hexadecimales sin procesar para trucos que no estén en la biblioteca

Formatos de Código Soportados

TruchiEmu lee Game Genie (códigos alfanuméricos de 6–8 caracteres), Pro Action Replay (códigos hexadecimales con direcciones), GameShark (el formato varía según el sistema) y códigos de memoria crudos. No necesitas especificar qué formato es: TruchiEmu lo deduce a partir del propio código.

Guía de Configuración Paso a Paso

Uso Básico de Trucos

  1. Acceder al Menú de Trucos

    Abre el menú de trucos seleccionando Herramientas → Trucos o presionando Cmd+Shift+C. La ventana de gestión de trucos muestra los trucos disponibles para el juego actual.

  2. Explorar la Base de Datos de Trucos

    Usa la barra de búsqueda para encontrar trucos específicos o explora por categoría. Categorías populares incluyen Jugabilidad (vidas infinitas, salud), Objetos y Equipamiento (armas, power-ups), Depuración y Pruebas (selección de nivel) y Códigos Personalizados.

  3. Habilitar Trucos

    Marca la casilla junto a cualquier truco para activarlo inmediatamente. Los trucos habilitados muestran un indicador verde. Múltiples trucos pueden estar activos simultáneamente.

  4. Probar en el Juego

    Vuelve a tu juego y verifica que el truco funcione como se espera. Algunos trucos requieren condiciones específicas (por ejemplo, debes estar en la pantalla de título, requiere reinicio).

  5. Guardar Configuración de Trucos

    Tus selecciones de trucos se guardan automáticamente al activar/desactivar un cheat. La próxima vez que cargues el juego, los trucos previamente habilitados se reactivarán automáticamente.

Entrada Manual de Trucos

  1. Agregar Nuevo Truco

    En el menú de trucos, haz clic en "Agregar Truco" e ingresa un nombre descriptivo. Selecciona el formato del truco (Game Genie, Action Replay, etc.) desde el menú desplegable.

  2. Ingresar Código de Truco

    Escribe o pega el código del truco en el campo de código. TruchiEmu detecta automáticamente el formato y lo analiza correctamente.

  3. Descripción y Notas

    Agrega una descripción explicando qué hace el truco y cualquier condición especial. Esto ayuda a organizar colecciones grandes de trucos.

  4. Probar y Refinar

    Habilita el truco y pruébalo en el juego. Si no funciona, verifica el formato del código y asegúrate de que coincida con tu versión y región del juego.

Solución de Problemas

Truco No Funciona

Síntoma: Truco habilitado pero no tiene efecto en el juego.

Solución: Verifica que el truco coincida con tu versión y región del juego. Algunos trucos solo funcionan en la pantalla de título o requieren reinicio del juego. Verifica si los trucos están deshabilitados en el modo Hardcore de RetroAchievements.

El Juego Se Cuelga con Trucos

Síntoma: El juego se cuelga cuando se habilitan trucos específicos.

Solución: Desactiva trucos en conflicto. Algunos trucos modifican direcciones de memoria críticas que causan inestabilidad. Intenta habilitar los trucos uno a la vez para identificar el código problemático.

Base de Datos de Trucos No Carga

Síntoma: La base de datos de trucos no muestra trucos para juegos soportados.

Solución: Re-descarga la base de datos de trucos desde la configuración. Verifica la conexión a internet para la descarga de la base de datos. Verifica que el hash de la ROM coincida con volcados buenos conocidos en la base de datos.

Funciones Relacionadas

RetroAchievements

Los trucos se desactivan automáticamente en el modo Hardcore para mantener la integridad de los logros.

Sistema de Estados de Guardado

Combina códigos de trucos con estados de guardado para probar escenarios específicos del juego.
