Soporte de Ratón Analógico

TruchiEmu ofrece captura completa de ratón y teclado para sistemas DOS, ScummVM y otros que requieren entrada de puntero analógico. El ratón se captura directamente en la ventana de juego con soporte para sensibilidad ajustable, aceleración y configuración independiente por juego.

Descripción General

El sistema de ratón analógico de TruchiEmu captura el dispositivo de entrada directamente en la ventana del juego, proporcionando una experiencia fluida y precisa. Al iniciar un título compatible, el cursor del sistema se oculta automáticamente y los movimientos del ratón se traducen directamente a la entrada del emulador. El sistema soporta perfiles de sensibilidad y aceleración configurables individualmente para cada juego, permitiendo ajustar la respuesta del ratón según las necesidades específicas de cada título.

Características Principales

  • Captura Completa de Ratón: El cursor se captura dentro de la ventana del juego, ocultando el cursor del sistema y traduciendo los movimientos directamente a la emulación. Compatible con monitores de alta frecuencia de actualización.
  • Entrada de Teclado: El teclado también se captura simultáneamente, permitiendo jugar títulos DOS que requieren combinaciones de ratón y teclado sin necesidad de cambiar entre dispositivos.
  • Sensibilidad y Aceleración: Ajustes independientes de sensibilidad horizontal y vertical, con curvas de aceleración seleccionables (lineal, suave, agresiva) para un control preciso del puntero.
  • Configuración por Juego: Cada juego puede tener su propia configuración de ratón, incluyendo sensibilidad, aceleración y límites de movimiento, que se almacenan y restauran automáticamente.
  • Detección Automática: El sistema detecta automáticamente si un título requiere entrada de ratón analógico y activa la captura sin intervención del usuario.

Cómo Usarlo

Uso Básico

  1. Iniciar un Juego Compatible

    Al lanzar un juego DOS o ScummVM, TruchiEmu activa automáticamente la captura del ratón. El cursor del sistema desaparece y el ratón controla el puntero del juego.

  2. Liberar el Ratón

    Presiona la tecla Escape para liberar el ratón de la ventana de juego. El cursor del sistema vuelve a aparecer y puedes interactuar con otras aplicaciones. Presiona cualquier botón dentro de la ventana para recapturar el ratón.

Ajustar Sensibilidad

  1. Acceder a la Configuración

    Ve a Configuración → Controles → Ratón Analógico para abrir el panel de ajustes del ratón.

  2. Ajustar Parámetros

    Modifica los deslizadores de sensibilidad horizontal y vertical, y selecciona la curva de aceleración deseada. Los cambios se aplican en tiempo real para que puedas probar la configuración mientras juegas.

  3. Guardar Perfil

    Si deseas mantener la configuración para el juego actual, haz clic en Guardar como Perfil. El perfil se cargará automáticamente la próxima vez que inicies el mismo juego.
