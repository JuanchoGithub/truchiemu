Mouse Analógico

Usa los sticks analógicos de tu gamepad como mouse en juegos DOS y ScummVM — con D-pad como flechas y mapping configurable de clicks.

Descripción General

Juegos DOS y ScummVM a menudo requieren mouse. Con Mouse Analógico, no necesitas un mouse físico — el stick primario mueve el cursor a 60fps; el stick secundario da control fino a 1/5 de velocidad; el D-pad envía flechas; Start envía Enter; Select envía Espacio.

Características

  • Stick Analógico como Mouse: Stick primario configurable (izq/der) con sensibilidad ajustable
  • Stick Secundario para Control Fino: 1/5 de velocidad para posicionamiento preciso
  • D-Pad como Teclado: Flechas, Enter, Espacio
  • Mapeo de Botones Configurable: Asigna click izq/der/medio a cualquier botón
  • Per-System y Per-Game: Override independientes para DOS y ScummVM
  • Auto-Release con Game Guide: Captura se libera al abrir Game Guide y se reanuda al cerrar

Cómo Usarlo

  1. Settings → Analog Mouse: activa por sistema (DOS, ScummVM, o ambos)
  2. Set Stick Handedness: izq o der como primario; el otro queda fino
  3. Tune Sensitivity y Deadzone
  4. Map Mouse Buttons a Gamepad: click un campo, presiona un botón
  5. Per-Game Overrides: desde Game Detail, click Game → Analog Mouse Override
