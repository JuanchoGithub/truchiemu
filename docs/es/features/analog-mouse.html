Soporte de Ratón Analógico

TruchiEmu te permite usar los joysticks analógicos de tu mando para controlar el cursor del ratón en juegos de DOS y ScummVM, con botones configurables para clics y la cruceta para entradas de teclado.

Descripción General

El Soporte de Ratón Analógico te permite jugar aventuras point-and-click de DOS y ScummVM con un mando en lugar de un ratón. El stick izquierdo mueve el cursor, el derecho hace ajuste fino, la cruceta envía flechas y puedes asignar acciones de clic a cualquier botón frontal. Los ajustes se pueden configurar por sistema y anular por juego.

Cómo Funciona

  • Stick Analógico a Ratón: El stick analógico principal (izquierdo o derecho, tú eliges) mueve el cursor según lo lejos que lo empujes
  • Stick Secundario para Control Fino: El otro stick mueve el cursor a 1/5 de velocidad para una colocación precisa
  • Cruceta como Teclado: La cruceta envía flechas, Start envía Enter, Select envía Espacio — útil para navegar menús en juegos DOS
  • Asignación de Botones Configurable: Asigna clic izquierdo, derecho y central a cualquier botón frontal o de hombro (A, B, X, Y, L1, R1, L2, R2, L3, R3, Start, Select)

Opciones de Ajuste

  • Sensibilidad: Ajusta la velocidad del puntero de 0.1x a 5.0x para adaptarla a tu preferencia
  • Zona Muerta: Define un umbral (0.00–0.50) para filtrar la deriva del stick
  • Selección de Stick: Elige qué stick analógico controla el ratón
  • Configuración por Sistema: Configura DOS y ScummVM de forma independiente
  • Anulación por Juego: Activa o desactiva el ratón analógico para un juego individual sin cambiar el valor por defecto del sistema
  • Visualizador en Vivo: Ve la posición de tu stick y la zona muerta en tiempo real mientras ajustas

Cómo Usarlo

Configuración Básica

  1. Abrir Ajustes de Ratón Analógico

    Ve a Configuración → Ratón Analógico para configurar las preferencias de sistema para DOS y ScummVM.

  2. Activar la Función

    Activa el ratón analógico para DOS, ScummVM o ambos. La función está desactivada por defecto.

  3. Ajustar Sensibilidad

    Usa el control deslizante de sensibilidad (0.1x–5.0x) para definir la velocidad del cursor en respuesta a la desviación del joystick.

  4. Configurar Zona Muerta

    Ajusta la zona muerta para evitar movimiento no deseado del cursor por deriva del joystick. El visualizador en vivo muestra la posición actual del joystick en relación con la zona muerta.

  5. Elegir tu Joystick

    Selecciona qué joystick analógico (izquierdo o derecho) controla el ratón. El otro joystick proporciona control fino a velocidad reducida.

  6. Asignar Botones del Ratón

    Asigna clic izquierdo, clic derecho y clic central a tus botones del mando preferidos.

Anulación por Juego

  1. Abrir Detalle del Juego

    Selecciona una ROM de DOS o ScummVM en tu biblioteca y abre su vista de detalle.

  2. Activar Ratón Analógico

    Usa el interruptor de Ratón Analógico para anular la configuración de sistema para este juego específico.

  3. Restablecer a Valor por Defecto

    Usa el botón Restablecer para limpiar la anulación por juego y volver a la configuración de sistema.

Durante el Juego

  • El joystick analógico mueve el cursor — empuja suavemente para movimiento preciso, desviación completa para navegación rápida
  • El joystick secundario ofrece 1/5 de velocidad para colocación pixel-perfect
  • La cruceta envía teclas de flecha (útil para navegación de menús en juegos DOS)
  • Start actúa como Enter, Select actúa como Espacio
  • Los botones asignados realizan acciones de clic izquierdo/derecho/central
