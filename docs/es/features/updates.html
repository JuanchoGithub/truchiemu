Verificador de Actualizaciones

El Verificador de Actualizaciones de TruchiEmu te mantiene al día con las últimas versiones del emulador. Busca actualizaciones automáticamente, muestra el registro de cambios detallado y te notifica cuando hay una nueva versión disponible para que nunca te pierdas las últimas mejoras y correcciones.

Descripción General

TruchiEmu vigila discretamente si hay nuevas versiones. Comprueba los lanzamientos en segundo plano y muestra una notificación cuando hay algo nuevo. Puedes leer el registro de cambios directamente en la app antes de decidir actualizar y explorar un historial de versiones para ver qué cambió con el tiempo. El verificador solo se comunica con la API pública de lanzamientos de GitHub sin análisis, sin rastreo.

Qué Obtienes

  • Comprobaciones en Segundo Plano: TruchiEmu busca actualizaciones al iniciar y periódicamente, sin interrumpir tu sesión de juego
  • Registro de Cambios en la App: Lee las notas de la versión actual o de cualquier versión pasada sin salir de la app
  • Notificaciones de Actualización: Aparece una píldora cuando hay una nueva versión, con un enlace directo a la descarga
  • Historial de Versiones: Explora todos los lanzamientos pasados con sus fechas y registros de cambios
  • Comprobación Manual: ¿Quieres saber ahora mismo? Abre el menú y activa una comprobación bajo demanda
  • Actual vs. Última: El panel Acerca de muestra tu versión instalada junto a la última disponible

Cómo Usarlo

Buscar Actualizaciones Manualmente

  1. Abrir el Verificador

    Ve a TruchiEmu → Buscar Actualizaciones en la barra de menú para abrir el verificador de actualizaciones.

  2. Iniciar la Búsqueda

    Haz clic en Buscar Ahora para comprobar manualmente si hay una nueva versión disponible.

  3. Ver Resultados

    Si hay una actualización disponible, se mostrará la versión, el tamaño de la descarga y un resumen de los cambios. Si ya tienes la última versión, se mostrará un mensaje indicando que estás al día.

Consultar el Registro de Cambios

  1. Abrir el Registro de Cambios

    Ve a TruchiEmu → Registro de Cambios para abrir el historial completo de versiones.

  2. Navegar por Versiones

    Las versiones se muestran ordenadas cronológicamente, con la más reciente al principio. Cada entrada incluye el número de versión, la fecha de publicación y la lista de cambios.

  3. Filtrar por Tipo

    Usa los filtros para mostrar solo un tipo específico de cambio: nuevas funcionalidades, mejoras o correcciones de errores.

Configurar las Verificaciones

  1. Acceder a Configuración

    Ve a Configuración → Acerca de para ajustar las preferencias de actualización.

  2. Configurar Frecuencia

    Selecciona la frecuencia de las comprobaciones automáticas: diaria, semanal, mensual o nunca (desactivado).

  3. Activar Notificaciones

    Mantén activada la opción Notificar Actualizaciones para recibir alertas cuando haya nuevas versiones disponibles.

Funciones Relacionadas

Este servicio es independiente y no requiere de otros servicios relacionados.
