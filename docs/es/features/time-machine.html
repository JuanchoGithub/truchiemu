Time Machine

Controles de rebobinado, avance rápido y cámara lenta directamente desde la barra del juego.

Descripción General

Time Machine graba tu juego reciente en un buffer corto y lo reproduce a demanda. Mantén rebobinado para retroceder por lo que acaba de pasar — como un DVR para tu juego — sin salir de la ventana.

Características

  • Rebobinado: Retrocede por el juego reciente para reintentar un salto fallido, combo errado, o golpe fatal sin recurrir a un save state
  • Avance Rápido: Salta diálogos lentos, grind, o cutscenes largas
  • Cámara Lenta: Estudia secuencias frame-perfect a velocidad reducida — ideal para combos de fighting games o setups difíciles de platformer
  • Compatibilidad: Algunos sistemas no lo soportan (por ejemplo Dolphin). Play! (PS2) te avisa antes de capturar, así puedes retroceder

Cómo Usarlo

  1. Habilitar Time Machine: Settings → Time Machine, toggle on (o desde el Setup Wizard).
  2. Elegir Profundidad del Buffer: Profundidad de rebobinado en segundos (mayor = más memoria).
  3. Definir Ratio de Slow Motion: 0.5×, 0.25×, 0.1×, etc.
  4. Asignar Hotkeys: Bind de rebobinado / avance rápido / slow motion en Hotkeys. Soporta teclado y gamepad.
  5. Usar en juego: Dispara los controles desde la barra o los hotkeys. El overlay muestra el estado actual.

Restricciones

Modo Hardcore: Time Machine se bloquea cuando el Modo Hardcore de RetroAchievements está activo.
