Sistema de Notificaciones

El Sistema de Notificaciones de TruchiEmu proporciona retroalimentación visual no intrusiva mediante píldoras de notificación animadas. Desde alertas de conexión de controladores hasta confirmaciones de acciones y mensajes del sistema, las notificaciones mantienen al usuario informado sin interrumpir la experiencia de juego.

Descripción General

El sistema de notificaciones de TruchiEmu está diseñado para ofrecer retroalimentación inmediata al usuario de forma elegante y no intrusiva. Las notificaciones aparecen como pequeñas píldoras animadas en la esquina de la pantalla, con diferentes estilos según el tipo de mensaje: informativo, éxito, advertencia o error. Cada notificación se desvanece automáticamente tras unos segundos, y el historial completo está disponible para consultar mensajes anteriores. Todos los mensajes están localizados al idioma actual de la aplicación.

Características Principales

  • Píldoras No Intrusivas: Las notificaciones aparecen como pequeñas burbujas redondeadas en la esquina superior derecha de la pantalla. No bloquean la interacción con la aplicación y se desvanecen suavemente tras la duración configurada.
  • Alertas de Control: Notificaciones automáticas cuando se conecta o desconecta un controlador, mostrando el nombre del dispositivo y el perfil de mapeo asignado.
  • Confirmaciones de Acciones: Retroalimentación visual inmediata al guardar estados, capturar pantallas, cambiar configuraciones o completar acciones del sistema.
  • Historial de Notificaciones: Accede al historial completo de notificaciones desde Ventana → Historial de Notificaciones para revisar mensajes que hayas podido perder. El historial muestra la fecha, hora y tipo de cada notificación.
  • Mensajes Localizados: Todas las notificaciones se muestran en el idioma configurado en la aplicación, con soporte completo para todos los idiomas disponibles.

Cómo Usarlo

Interactuar con Notificaciones

  1. Ver una Notificación

    Las notificaciones aparecen automáticamente en la esquina superior derecha cuando ocurre un evento relevante. El color de la píldora indica el tipo: azul para información, verde para éxito, amarillo para advertencia y rojo para error.

  2. Descartar una Notificación

    Haz clic en la notificación para descartarla inmediatamente, o espera a que se desvanezca automáticamente tras la duración configurada (predeterminado: 4 segundos).

Consultar el Historial

  1. Abrir el Historial

    Ve a Ventana → Historial de Notificaciones o presiona Cmd+Shift+N para abrir la ventana de historial.

  2. Revisar Mensajes

    El historial muestra todas las notificaciones recibidas durante la sesión actual, ordenadas cronológicamente con su tipo, mensaje y marca de tiempo.

  3. Filtrar por Tipo

    Usa los filtros en la parte superior del historial para mostrar solo notificaciones de un tipo específico (información, éxito, advertencia o error).

Configurar Notificaciones

  1. Acceder a Configuración

    Ve a Configuración → General → Notificaciones para ajustar las preferencias del sistema.

  2. Ajustar Duración

    Modifica el deslizador de duración para controlar cuánto tiempo permanecen visibles las notificaciones antes de desvanecerse.

  3. Desactivar Notificaciones

    Puedes desactivar categorías específicas de notificaciones o silenciar todas las notificaciones temporalmente desde el mismo panel.
