Modo de Práctica

El Modo de Práctica de TruchiEmu proporciona herramientas de automatización de P2 para juegos de lucha, permitiéndote controlar el dummy con postura configurable, guardia, técnica de despertar, acciones de reversal, programación de secuencias y grabación de entradas.

Descripción General

El Modo de Práctica coloca una superposición en pantalla sobre tu juego de lucha para que puedas practicar contra un dummy controlable en lugar de arrastrar a un amigo. El dummy puede quedarse quieto, bloquear, saltar, ejecutar una secuencia de movimientos o reproducir una grabación de tus propias entradas lo que necesites para trabajar el matchup.

Qué Puedes Hacer

  • Configurar el Dummy: Elige el comportamiento de P2 qué postura mantener, cómo bloquear, qué hacer al despertar y qué reversal (si alguno) lanzar al levantarse
  • Programar una Secuencia: Construye una lista de movimientos para que el dummy los ejecute. Define el disparador (bucle, al bloquear, al golpear) y la tolerancia de frames para que se alinee con lo que quieres practicar
  • Grabar y Reproducir Entradas: Graba tus propias pulsaciones de botones en una de las 3 ranuras de cinta y haz que el dummy las reproduzca como P2
  • Ver Entradas en Vivo: Las entradas de ambos jugadores se muestran en pantalla como notación de movimientos, con números de frame, para que veas exactamente qué pasó
  • Seguir Secuencias Activas: Un monitor en vivo muestra el movimiento actual, el progreso de frames y si el disparador se ha activado
  • Reiniciar Bajo Demanda: Devuelve a P2 al inicio de la ronda, una esquina o cualquier posición de reinicio guardada con una tecla rápida
  • Tomar de la Lista de Movimientos: Explora personajes y sus movimientos dentro de la superposición de entrenamiento y luego añádelos a una secuencia

Cómo Usarlo

Activar el Modo de Práctica

  1. Iniciar un Juego de Lucha

    Abre cualquier juego de lucha compatible desde tu biblioteca.

  2. Abrir el Panel de Práctica

    Desde la barra de herramientas del juego, haz clic en el icono de Modo de Práctica o presiona la tecla rápida configurada para abrir el panel.

  3. Activar el Entrenamiento

    Haz clic en el botón Activar Entrenamiento en la parte superior del panel. El modo de práctica unirá automáticamente a P2 al juego.

  4. Configurar el Comportamiento del Dummy

    Usa la pestaña Dummy para configurar el modo de control, postura, guardia, técnica de despertar y acción de reversal de P2. Los cambios se aplican inmediatamente.

Programar Secuencias

  1. Abrir la Pestaña de Secuencias

    Navega a la pestaña de Secuencias en el panel de práctica.

  2. Añadir Cartas

    Haz clic en el botón + para añadir movimientos FMD (desde la lista de movimientos), cartas de retardo (pausa por un número de frames) o bloques de cinta (reproducir una entrada grabada).

  3. Configurar la Condición de Activación

    Elige cuándo se reproduce la secuencia: bucle continuo, al bloquear o al golpear.

  4. Ajustar el Perfil de Frames

    Configura la tolerancia de frames (1 = estricto, 5 = muy flexible) para controlar la precisión con la que P2 ejecuta la secuencia.

Grabar Entradas

  1. Seleccionar una Ranura de Cinta

    En la pestaña de Grabación, elige una de las 3 ranuras para grabar.

  2. Iniciar Grabación

    Presiona el botón de grabar. Aparecerá una cuenta atrás de 3 segundos, luego comenzará la grabación.

  3. Reproducir

    Asigna la cinta grabada a un bloque de cinta en la pestaña de Secuencias, o activa la reproducción mediante tecla rápida. P2 replicará tus entradas grabadas.

Funciones Relacionadas

Superposición de Movimientos

Los datos de movimientos de personajes alimentan directamente el modo de práctica para programación de secuencias y acciones de reversal.

Estados de Guardado

Las posiciones de reinicio personalizadas usan datos de estados guardados para restaurar P1 y P2 a escenarios de práctica específicos.

Controles

Configura teclas rápidas para los controles del modo de práctica como reinicio, grabación y reproducción.
