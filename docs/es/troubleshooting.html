Solución de Problemas

La mayoría de los problemas se pueden diagnosticar desde los registros. Si necesitas más ayuda, consulta los Issues de GitHub.

Revisa los Registros

TruchiEmu escribe registros detallados para ayudar a diagnosticar problemas:

  • Registros de la App: ~/Library/Logs/TruchiEmu/ — registros generales de la aplicación y emulación
  • Reportes de Crash: ~/Library/Logs/DiagnosticReports/ — registros de fallos del sistema

Activa el registro verbose en Configuración → Avanzado → Nivel de Registro para capturar más detalles.

Issues de GitHub

Busca issues existentes o reporta uno nuevo en github.com/JuanchoGithub/truchiemu/issues.

Al reportar un bug, incluye tu versión de macOS, la versión de TruchiEmu y el contenido relevante de los registros.
