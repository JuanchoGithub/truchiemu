Solución de Problemas

¿Tienes problemas con TruchiEmu? Esta guía cubre problemas comunes y sus soluciones para instalación, rendimiento, controladores, shaders y más.

Obtener Ayuda

Antes de contactar al soporte, prueba estos pasos:

  • Consulta la guía de Primeros Pasos para lo básico de configuración
  • Busca en GitHub Issues problemas conocidos
  • Pregunta a la comunidad en GitHub Discussions

Problemas de Instalación

La App No Se Abre

Síntoma: TruchiEmu rebota en el dock pero no se inicia, o muestra "TruchiEmu no puede abrirse porque es de un desarrollador no identificado."

Solución: macOS puede bloquear apps que no están notarizadas por Apple. Haz clic derecho (o Ctrl+clic) en la app y selecciona "Abrir" desde el menú contextual, luego haz clic en "Abrir" en el diálogo. Alternativamente, ve a Configuración del Sistema > Privacidad y Seguridad y busca un mensaje sobre TruchiEmu siendo bloqueado.

La App Se Cuelga al Iniciar

Síntoma: TruchiEmu se cuelga inmediatamente después de iniciarse.

Solución: Verifica que tu versión de macOS sea 14.0 (Sonoma) o posterior. Si la app no se abre en absoluto, intenta eliminar el archivo de preferencias en ~/Library/Preferences/com.truchiemu.plist.

Dependencias Faltantes

Síntoma: Mensajes de error sobre librerías o frameworks faltantes al compilar desde el código fuente.

Solución: Asegúrate de que las Herramientas de Línea de Comandos de Xcode estén instaladas (xcode-select --install). Instala las dependencias requeridas con Homebrew: brew install cmake xcodegen.

Problemas de Rendimiento

Baja Tasa de Fotogramas / Tartamudeo

Síntoma: Los juegos funcionan por debajo de la velocidad completa o tienen tartamudeos frecuentes.

Solución: Prueba estos pasos en orden:

  1. Reduce la complejidad del shader o usa el shader Passthrough
  2. Baja la escala de resolución interna (para sistemas 3D como N64, PSP)
  3. Aumenta el búfer de audio a 128-256ms
  4. Cierra otras aplicaciones para liberar recursos del sistema

Crujidos o Pops de Audio

Síntoma: Audio distorsionado, especialmente durante transiciones de escena o secuencias de audio complejas.

Solución: Aumenta el tamaño del búfer de audio en Configuración > Audio. Prueba 128ms o 256ms. Desactiva "Reducir Latencia de Audio" si está habilitado.

Alto Uso de CPU

Síntoma: TruchiEmu usa excesiva CPU incluso cuando está inactivo o en juegos simples.

Solución: Desactiva el renderizado por hilos si está habilitado en sistemas de un solo núcleo. Usa cores de emulación más ligeros (snes9x en lugar de bsnes para SNES). Desactiva la función de rebobinado si no la necesitas.

Problemas de Controladores

Controlador No Detectado

Síntoma: Controlador conectado pero no reconocido por TruchiEmu.

Solución: Verifica Configuración del Sistema de macOS > Privacidad y Seguridad > Bluetooth (para inalámbricos). Asegúrate de que el controlador esté emparejado antes de iniciar TruchiEmu. Para controladores Xbox, prueba primero una conexión USB por cable. Reinicia TruchiEmu con el controlador conectado.

Retardo de Entrada

Síntoma: Retardo entre presionar un botón y la acción que aparece en pantalla.

Solución: Usa una conexión por cable en lugar de Bluetooth. Reduce el tamaño del búfer de audio. Desactiva V-Sync.

Mapeo de Botones Incorrecto

Síntoma: Los botones no coinciden con la configuración esperada.

Solución: Abre Configuración > Controladores > Mapeo de Botones y remapea los botones según sea necesario. Guárdalo como perfil para reutilización. Verifica si hay una anulación por core o por juego activa.

Deriva del Stick Analógico

Síntoma: El personaje se mueve sin tocar el controlador.

Solución: Aumenta la zona muerta al 15-20% en la configuración de calibración del controlador. Limpia los sticks del controlador con aire comprimido.

Problemas de Shaders

Fallos de Compilación de Shaders

Síntoma: "Error del compilador Metal" al seleccionar un shader.

Solución: Actualiza macOS a la última versión para las funciones Metal más recientes. Verifica que tu GPU soporte el conjunto de funciones Metal requerido (requiere macOS 14+).

Sin Efecto Visible

Síntoma: El shader está seleccionado pero no se aprecia cambio visual.

Solución: Algunos shaders tienen efectos sutiles. Revisa los controles deslizantes de intensidad del shader en la configuración. Prueba un shader más notorio como CRT Lottes para verificar que el sistema funciona.

Impacto en el Rendimiento del Shader

Síntoma: La tasa de fotogramas cae con shaders complejos habilitados.

Solución: Usa shaders más simples (Lite CRT en lugar de CRT Multipass, Sharp Bilinear en lugar de Smooth Upscale). Reduce la complejidad de la cadena de shaders. Considera usar configuraciones de shader por juego para usar shaders ligeros en juegos exigentes.

Problemas de Carga de ROMs

ROM No Reconocida

Síntoma: El juego aparece como "Desconocido" o no aparece en la biblioteca.

Solución: Verifica que el tipo de archivo ROM sea soportado por el sistema destino. Comprueba que la extensión del archivo esté en la lista permitida. Prueba un volcado diferente de ROM desde una fuente verificada. Identifica manualmente el juego mediante clic derecho > Identificar Juego.

El Juego No Inicia

Síntoma: El juego aparece en la biblioteca pero se cuelga al iniciar.

Solución: Asegúrate de tener el core correcto instalado para el sistema. Verifica si el juego requiere archivos BIOS (PlayStation, Saturn, Neo Geo). Prueba un core de emulación diferente. Verifica que la ROM no esté corrupta.

Sistema Incorrecto Detectado

Síntoma: El juego se inicia con el core de emulación equivocado.

Solución: Haz clic derecho en el juego y selecciona "Editar Metadatos," luego corrige la asignación del sistema. También puedes establecer cores predeterminados por sistema en Configuración > Cores.

Problemas de Estados de Guardado

Los Juegos de Dreamcast No Pueden Guardar

Síntoma: Los juegos de Dreamcast no reconocen ninguna tarjeta de memoria (VMU). Los guardados fallan silenciosamente sin mensaje de error.

Solución: Esto típicamente es causado por opciones del core Flycast mal configuradas o archivos VMU faltantes/corruptos. Asegúrate de que CoreOverrides.json use "VMU" (no "Visual Memory") para las opciones de slot del puerto de dispositivo. Consulta Depuración de Guardados VMU de Dreamcast análisis técnico sobre cómo corregir la detección VMU de Flycast.

Los Estados de Guardado No Cargan

Síntoma: El estado de guardado aparece en el navegador pero falla al cargar.

Solución: Asegúrate de estar usando la misma versión del core que creó el guardado. Los estados de guardado no son compatibles entre diferentes cores. Verifica que el archivo de guardado no esté corrupto comprobando su checksum. Nota: si el Modo Hardcore está activivo, la carga de estados de guardado estará bloqueada.

Reportar Errores

Al reportar problemas en GitHub, por favor incluye:

  • Tu versión de macOS y hardware (Apple Silicon o Intel)
  • Número de versión de TruchiEmu
  • El core de emulación y el juego que estabas usando
  • Pasos para reproducir el problema
  • Cualquier mensaje de error o registro de cuelgues
  • Capturas de pantalla o grabaciones de pantalla si aplica

Los registros de cuelgues se pueden encontrar en: ~/Library/Logs/DiagnosticReports/
