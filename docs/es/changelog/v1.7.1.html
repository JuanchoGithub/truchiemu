Registro de cambios / v1.7.1

v1.7.1

16 de julio de 2026

Corrección crítica: actualizar de v1.6.0 a v1.7.0 podía eliminar por completo la carpeta de datos de usuario de TruchiEmu (saves, BIOS, estados, cheats, base de datos de la biblioteca). v1.7.1 corrige la migración para que los datos de usuario se conserven.

Destacados

  • Corrección de pérdida de datos: Actualizar de v1.6.0 a v1.7.0 eliminaba por completo la carpeta ~/Library/Application Support/TruchiEmu/. v1.7.1 corrige la migración de esquema del campo ROMEntry.hasTitleScreen para que la migración tenga éxito y los datos de usuario se conserven.
  • Defensa en profundidad: La ruta de recuperación de respaldo del almacén ya no toca la carpeta de datos de usuario — solo los tres archivos SQLite de SwiftData (TruchiEmu.sqlite, -wal, -shm). Saves, BIOS, configuración, cheats y logs nunca son eliminados por la ruta de recuperación, incluso en una migración fallida.

Cambios detallados

  • Cambiado ROMEntry.hasTitleScreen de Bool no opcional a Bool? opcional para que SwiftData/CoreData pueda migrar automáticamente las filas existentes desde v1.6.0 (las filas existentes obtienen nil, tratado como false por todos los puntos de uso)
  • Restringido SwiftDataContainer.deleteStoreFiles() para que solo elimine la tripleta SQLite (TruchiEmu.sqlite/-wal/-shm) y los archivos heredados default.store* raíz — nunca la carpeta completa de datos de usuario TruchiEmu/
  • Coalescencia de lecturas de ROMEntry.hasTitleScreen a false para los puntos de uso que traducen entre el modelo SwiftData y el struct ROM plano

Si ya actualizaste a v1.7.0 y perdiste datos

v1.7.1 no puede recuperar datos que ya fueron eliminados por v1.7.0 en un lanzamiento anterior. Si fuiste afectado, tus opciones son:

  • Instantáneas locales APFS de macOS: macOS suele retener instantáneas locales de corta duración del disco. Abre Time Machine desde la barra de menús o lanza /System/Applications/Utilities/Time Machine.app y restaura ~/Library/Application Support/TruchiEmu/ desde una instantánea anterior al lanzamiento de v1.7.0.
  • Copia de seguridad de Time Machine: Si tienes una unidad externa de Time Machine, restaura la misma carpeta desde tu copia de seguridad más reciente anterior a la actualización.
  • Instala v1.7.1 primero antes de restaurar: una vez que v1.7.1 esté instalado, los lanzamientos futuros ya no eliminarán la carpeta, por lo que una carpeta restaurada no será borrada en el siguiente relanzamiento.
