Registro de cambios / v1.2.0

v1.2.0

12 de junio de 2026

Versión importante que añade soporte de ROMs comprimidas (ZIP, 7z, RAR), desambiguación MAME/FBNeo, identificación CRC de sistema, identificación de sector de arranque, fusión de sistemas y extensas correcciones de errores.

Destacados

  • Soporte de ROMs comprimidas: Ejecuta ROMs ZIP, 7z y RAR directamente. Los núcleos que soportan archivos reciben el archivo tal cual; otros reciben extracción automática con caché persistente y limpieza configurable por TTL
  • Desambiguación MAME/FBNeo: Las ROMs Arcade ahora se identifican correctamente como conjuntos MAME o FBNeo mediante validación basada en base de datos
  • Desambiguación CRC de sistema: Coincidencia CRC32 completa con bases de datos Libretro DAT cuando los dos candidatos principales están cerca
  • Identificación de sector de arranque: Cabeceras mágicas positivas para Dreamcast, 3DO, Xbox, CD-i, GameCube, Wii, PC Engine CD y Atari 7800
  • Fusión de sistemas: Fusionar GB+GBC en una sola entrada "Game Boy"; fusionar MAME+FBNeo en "Arcade (MAME / FBNeo)" en la barra lateral
  • Mejoras en miniaturas: Investigar todos los nombres de carpeta de la base de datos para un sistema, almacenando en caché las carpetas funcionales

Correcciones detalladas

  • Eliminado .bin de las listas de extensión NES/SNES/N64/GBA/GB/DS/SMS (gran fuente de falsos positivos)
  • Eliminado "/" como extensión en Amiga/C64 (causaba errores de escaneo de directorio)
  • Eliminado .cue de las extensiones de Genesis (identificación falsa de juego CD)
  • Eliminadas extensiones GB/GBC/SGB de NES/SNES/GBA (ROMs del sistema incorrecto filtrándose)
  • MAME ahora valida solo dependencias del núcleo activo
  • Eliminación de categoría ahora funciona (era un no-op antes)
  • ROMs escaneados se auto-seleccionan en la biblioteca después de completarse
  • Metadatos y trucos ahora claveados por runningKey (ruta del archivo + ruta interna)
  • Caché SwiftData descartada automáticamente después de actualizaciones de la app
