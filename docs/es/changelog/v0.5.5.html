v0.5.5 Improved ROM detection

13 de abril de 2026 5 commits

Versión de 150 MB que añade recursos extensivos de identificación de ROMs para uso offline, junto con mejoras en la detección de sistemas.

Cambios

  • Funcionalidad de restablecimiento completo de base de datos añadida
  • Vasta colección de iconos de emuladores, assets de controladores y configuraciones de base de datos de sistemas
  • Detección automática de ROMs mejorada con recursos offline extensivos
  • Corregidas claves duplicadas al reescanear biblioteca completa
  • Corregidos juegos que terminaban en sistemas incorrectos
