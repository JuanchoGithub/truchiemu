Registro de cambios / v1.5.0

v1.5.0

1 de julio de 2026

Versión importante que presenta streaming y grabación, amplio soporte de controles SDL, alrededor de 1800 nuevos shaders slang, mejoras del modo de práctica con nuevos datos de frames y selección de región para el arte de caja.

Destacados

  • Streaming y grabación: transmite y graba tu juego directamente desde TruchiEmu — sin herramientas externas. Compatible con Twitch, YouTube, endpoints RTMP personalizados y grabación local (con shaders o sin procesar)
  • Soporte de controles SDL: compatibilidad ampliada de controles — cualquier cosa que se pueda conectar a un Mac ahora debería aparecer
  • Slang shaders: alrededor de 1800 nuevos slang shaders compatibles. Algunos aún pueden fallar; el trabajo continúa en esto
  • Mejoras del modo de práctica: visualización mejorada de la lista de movimientos y funcionalidad de superposición con nuevos datos de frames para Eternal Champions, Clay Fighter, Dragon Ball Z, TMNT Tournament Fighters, Virtua Fighter 2 vs Tekken 2 y Yu Yu Hakusho: Sunset Fighters
  • Selección de región de arte de caja: descarga el arte de caja con selección de región para las portadas de juego
  • macOS Game Mode: activado automáticamente durante el juego en pantalla completa
  • Mejoras de configuración: mejoras de configuración en general, además de muchas mejoras internas de estabilización y UI/UX

Cambios detallados

  • Añadido servicio de streaming con soporte para Twitch, YouTube y RTMP personalizado
  • Añadida grabación local con salida de shaders o sin procesar
  • Añadida UI de streaming a la configuración
  • Añadida funcionalidad de botón de compartir para streaming
  • Ampliado el soporte de controles SDL con mappings para dispositivos previamente no compatibles
  • Añadido soporte para ~1800 slang shaders vía la canalización librashader
  • Mejorada la superposición del modo de práctica con visualización refinada de la lista de movimientos
  • Añadidos nuevos datos de frame para modo de práctica: Eternal Champions, Clay Fighter, Dragon Ball Z, TMNT Tournament Fighters, Virtua Fighter 2, Tekken 2, Yu Yu Hakusho: Sunset Fighters
  • Añadida funcionalidad de descarga de arte de caja con selección de región
  • Añadida activación automática de macOS Game Mode durante juego en pantalla completa
  • Actualizadas las traducciones al portugués con nuevos ajustes y funciones
  • Refactorizadas las especificaciones de shaders para mayor claridad
  • Mejorada la documentación de shaders con nuevas funciones y descripciones mejoradas
  • Mejoras internas de estabilización, rendimiento y UI/UX en toda la app
