v1.5.1

2 de julio de 2026

Parche de emergencia que corrige el embedding del dylib de librashader en builds de release y añade funcionalidad de prueba de notificaciones, borrado masivo del gestor de guardados y pulido de documentación.

Destacados

  • Corrección de emergencia de librashader: el dylib ahora se copia a Frameworks/ con el install name correcto, ARCHS bloqueado a arm64 — los builds de release ya no fallan al iniciar
  • Notificaciones: añadida funcionalidad de prueba de notificaciones y manejo mejorado de autorización
  • Gestor de guardados: acción "Borrar todos los guardados" con confirmación de UI mejorada
  • Shaders: se eliminaron especificaciones de shaders para mayor claridad y concisión
  • Documentación: eliminadas secciones de solución de problemas en todos los idiomas; docs de características mejoradas con soporte de control, streaming y guía de juego actualizada

Cambios detallados

  • Corregido el embedding del dylib de librashader: ahora se copia a la carpeta Frameworks con el install name correcto
  • Bloqueado ARCHS a arm64 (librashader es solo arm64)
  • Añadida acción de prueba de notificación y mejor manejo de autorización en NotificationPill
  • Implementada funcionalidad "Borrar todos los guardados" con mejora en la confirmación de UI en el gestor de guardados
  • Refactorizados shaders: se eliminaron especificaciones para mayor claridad y concisión
  • Actualizada la documentación de shaders con nuevas funciones y descripciones mejoradas
  • Eliminadas secciones de solución de problemas en todas las variantes de idioma y eliminadas las páginas dedicadas de solución de problemas
  • Mejorada la documentación de características con nuevas secciones para soporte de control, streaming y guía de juego actualizada
  • Simplificadas las docs de características y reorganizados los enlaces de navegación
