v0.5 First public version!

13 de abril de 2026 251 commits (desde el inicio)

Versión pública inicial de TruchiEmu — un emulador de juegos retro nativo para macOS construido con SwiftUI y Metal, con un sistema completo de gestión de biblioteca, motor avanzado de shaders y amplio soporte de sistemas.

Destacados

Arquitectura principal

  • Aplicación nativa macOS con interfaz SwiftUI
  • Motor de shaders avanzado basado en Metal con ajuste de parámetros en tiempo real
  • Gestión de núcleos múltiples con detección y descarga automática
  • Puente Libretro completo con ejecutores específicos por sistema

Sistemas compatibles

  • NES, SNES, Nintendo 64, Game Boy/Color, Game Boy Advance, Nintendo DS
  • PlayStation, PlayStation Portable, PlayStation 2
  • Sega Genesis, Sega Saturn, Sega Dreamcast, Sega 32X, Sega CD, Game Gear, Master System
  • Atari Jaguar, Atari 2600/5200/7800, Lynx
  • DOS (via DOSBox), ScummVM

Características destacadas

  • Gestión automatizada de biblioteca con sincronización de metadatos y descarga de carátulas
  • Asistente de configuración guiado
  • Integración con RetroAchievements
  • Configuración avanzada de entrada con soporte para controladores (hasta 4 jugadores)
  • Gestión de estados guardados con compresión
  • Sistema de trucos con servicios de descarga y gestión
  • Soporte de bezels para presentación visual mejorada
  • Soporte CLI para operación headless
