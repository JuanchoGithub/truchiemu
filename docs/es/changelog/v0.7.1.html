v0.7.1 More improvements

8 de mayo de 2026 60 commits

Versión rica en funciones que introduce la integración de RetroAchievements, emulación de Saturn, una base masiva de trucos y el lanzamiento del sitio de documentación.

Destacados

Integración de RetroAchievements

  • Soporte completo de RetroAchievements con hash de ROMs, caché de juegos e interfaz de comparación de hash
  • Decodificación flexible de enteros para condiciones de logros
  • Modelos SwiftData expandidos para soporte de RetroAchievements

Mejoras de emulación

  • Emulación de Saturn mejorada con soporte de BIOS
  • Identificación de ROMs mejorada con análisis de nombres más inteligente
  • Distorsión de barril del shader CRT mejorada

Sistema de trucos

  • Base masiva de trucos cubriendo más de 40 plataformas
  • Nueva interfaz de gestión de trucos fácil de usar
  • Archivos de trucos añadidos a los recursos del proyecto Xcode

Lanzamiento del sitio de documentación

  • Sitio de documentación completo en GitHub Pages con más de 21 páginas HTML
  • Flujo de trabajo de GitHub Actions para despliegue automatizado de Jekyll
  • Estructura de documentación multilingüe
