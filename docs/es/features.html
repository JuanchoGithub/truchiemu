Colección de Shaders

Transforma tu experiencia de juego con nuestra colección curada de 11 shaders Metal de alta calidad. Cada shader está optimizado para macOS y diseñado para mejorar o reproducir auténticamente los visuales clásicos de gaming.

La interfaz del selector de shaders permite vista previa y ajuste en tiempo real

Passthrough

El shader predeterminado que renderiza los píxeles exactamente como el hardware original lo pretendía. Perfecto para puristas que desean visuales auténticos sin filtrar con bordes de píxeles nítidos.

Sin Procesamiento Píxeles Nítidos Bajo CPU

Caso de Uso: Desarrollo, reproducción pixel-perfect, speedrunning

Scale Smooth

Escalado bicúbico de alta calidad que suaviza los bordes de los píxeles preservando los detalles. Ideal para pantallas modernas donde los píxeles crudos aparecen demasiado bloqueados.

Suavizado Bicúbico Universal

Caso de Uso: Juego general, pantallas modernas, menor pixelación

Sharp Bilinear

Combina filtrado bilineal con detección de bordes para crear gradientes suaves manteniendo los bordes importantes nítidos. Perfecto para juegos con arte mixto de sprites y fondos.

Preserva Bordes Adaptativo Equilibrado

Caso de Uso: RPGs con fondos detallados, estilos de arte mixtos

CRT Multipass

Simulación CRT multipasada con brillo de fósforo, líneas de escaneo y curvatura. Nuestra recreación CRT más auténtica para usuarios que buscan la verdadera experiencia retro.

Multipasada Auténtico Pesado

Caso de Uso: Experiencia retro auténtica, entusiastas del CRT, nostalgia

Lite CRT

Simulación CRT ligera que añade líneas de escaneo sutiles y efectos de fósforo sin el coste de rendimiento del renderizado multipasado completo.

Líneas de Escaneo Ligero Rendimiento

Caso de Uso: Estética CRT en hardware de menor potencia, efecto sutil

CRT Lottes

Simulación CRT avanzada usando el algoritmo de Lottes con efectos de máscara, curvatura y bloom. Crea la apariencia de monitor CRT más realista disponible.

Máscara de Fósforo Bloom Premium

Caso de Uso: Simulación CRT profesional, creación de contenido, preservación

Dot Matrix

Simula la distintiva pantalla de matriz de puntos de sistemas portátiles clásicos como el Game Boy. Presenta el patrón de cuadrícula característico y la disposición de subpíxeles.

Portátil Patrón de Cuadrícula Nostálgico

Caso de Uso: Juegos de Game Boy, emulación portátil, experiencia portátil auténtica

Pantalla Original de Game Boy

Fiel simulación LCD del Game Boy DMG (Dot Matrix Game) con la icónica pantalla monocromática con tinte verde, persistencia de píxeles y el característico desenfoque de movimiento.

Game Boy Monocromático Auténtico

Caso de Uso: Juegos de Game Boy original, pura nostalgia, reproducción auténtica

Game Boy Color

Reproducción precisa del LCD del Game Boy Color con la paleta de colores correcta, disposición de píxeles y características de retroiluminación del hardware original.

Color Portátil Preciso

Caso de Uso: Juegos de Game Boy Color, representación precisa de color

Game Boy Advance

Simulación LCD fiel al Game Boy Advance con la temperatura de color distintiva, estructura de píxeles y características de movimiento de la pantalla GBA.

GBA Retroiluminado Portátil

Caso de Uso: Juegos de GBA, experiencia de juego portátil precisa

CRT Filter

Una simulación CRT equilibrada que proporciona líneas de escaneo clásicas y un sutil brillo de fósforo. Optimizada para alto rendimiento en todos los sistemas.

Equilibrado Líneas de Escaneo Rápido

Caso de Uso: Juego retro general, aspecto consistente entre múltiples sistemas

Personalización de Shaders

Cada shader incluye parámetros ajustables para afinar el efecto:

  • Controles de Intensidad: Ajusta la fuerza de cada efecto
  • Presets de Parámetros: Configuraciones rápidas para diferentes tipos de pantalla
  • Vista Previa en Tiempo Real: Ve los cambios instantáneamente mientras ajustas
  • Configuración por Juego: Guarda preferencias de shader para juegos individuales
  • Predeterminados Globales: Establece preferencias de shader para todo el sistema

Impacto en el Rendimiento: Passthrough, Scale Smooth y Vignette tienen un impacto mínimo en el rendimiento. Los shaders CRT y simulaciones LCD usan más recursos de GPU. La mayoría de los Mac modernos pueden ejecutar cualquier shader a velocidad completa.

Gestión de Biblioteca

Organiza tu colección de juegos con potentes funciones de gestión de biblioteca diseñadas para coleccionistas serios y jugadores casuales por igual.

Tus juegos se organizan automáticamente con carátulas y metadatos

Organización Automática

  • Detección Inteligente: Identifica automáticamente juegos a partir de hashes de archivos ROM
  • Obtención de Metadatos: Descarga descripciones de juegos, fechas de lanzamiento y detalles
  • Carátulas: Descarga automáticamente carátulas de alta calidad y capturas de pantalla
  • Categorización por Sistema: Agrupa juegos por consola/sistema original
  • Detección de Logros: Identifica juegos con soporte de RetroAchievements

📊 Vista de Cuadrícula

Cuadrícula visual con miniaturas de carátulas. Perfecta para explorar colecciones grandes.

  • Tamaño de cuadrícula ajustable mediante control deslizante de zoom
  • Ordenar por nombre, último jugado o último agregado
  • Búsqueda rápida y filtrado

📋 Vista de Lista

Lista detallada con metadatos y estadísticas. Ideal para ordenar y organizar.

  • Visualización compacta para bibliotecas grandes
  • Indicadores rápidos de estado

Colecciones y Listas de Reproducción

Organiza tus juegos con categorías personalizadas y filtros integrados:

  • Colecciones Manuales: Crea categorías personalizadas para agrupar tus juegos favoritos
  • Favoritos: Acceso rápido a tus títulos imprescindibles mediante el filtro de favoritos
  • Jugados Recientemente: Rastrea y muestra automáticamente tus sesiones más recientes

Búsqueda y Filtrado

Encuentra juegos al instante con potentes capacidades de búsqueda:

  • Búsqueda de Texto: Busca por nombre de juego o metadatos
  • Filtro de Sistema: Muestra solo juegos de consolas específicas
  • Soporte de Logros: Muestra juegos con RetroAchievements
  • Estado de Juego: Filtra por favoritos o jugados recientemente

Importar y Exportar

Integración con RetroAchievements

¡Gana logros mientras juegas clásicos! TruchiEmu se integra perfectamente con RetroAchievements.org para añadir caza de logros moderna al gaming retro.

Rastrea tu progreso y compárate con amigos en la tabla de clasificación global

Comenzando con los Logros

Paso 1: Crear una Cuenta en RetroAchievements

Visita RetroAchievements.org y crea una cuenta gratuita.

Paso 2: Vincular Cuenta en TruchiEmu

Navega a Configuración → Logros e ingresa tu nombre de usuario y clave API de RetroAchievements.

Paso 3: Probar Conexión

Usa el botón "Conectar" para verificar tus credenciales y sincronizar tu perfil.

Paso 4: Jugar Juegos Soportados

Inicia cualquier juego con soporte de logros. Tu progreso se sincronizará con tu perfil global.

Tipos de Logros

TruchiEmu soporta la variedad de tipos de logros definidos por la comunidad de RetroAchievements, incluyendo hitos de progreso, desafíos basados en habilidad y objetivos de completista.

Sistemas Soportados

El soporte de RetroAchievements varía según el sistema. TruchiEmu proporciona mapeo para todas las consolas principales, incluyendo:

Sistema Soporte de Logros Juegos Soportados

Game Boy / Color / Advance ✅ Soporte Completo 1,000+ juegos
Genesis / Mega Drive ✅ Soporte Completo 500+ juegos
Nintendo 64 / PS1 ✅ Limitado / Experimental 100+ juegos

Funciones de Integración

  • Presencia Enriquecida: Actualiza automáticamente tu perfil para mostrar a tus amigos qué juego estás jugando actualmente
  • Tablas de Clasificación: Envía y compara puntuaciones y tiempos en tablas de clasificación globales
  • Modo Hardcore: Opción de rastrear logros sin usar estados de guardado para una experiencia purista

💡 Consejos sobre Logros:

  • Asegúrate de usar archivos ROM verificados que coincidan con los hashes de la base de datos de RetroAchievements.
  • Revisa las listas de logros en el sitio web de RA para planificar tu enfoque para trofeos difíciles.
  • Únete a la comunidad de RetroAchievements para rastrear tu progreso contra otros jugadores.
  • Modo Hardcore: Habilita el Modo Hardcore desde la configuración para desactivar los estados de guardado, lo cual es requerido para ganar logros de nivel Hardcore.

⚠️ Importante: Los logros solo funcionan con archivos ROM verificados que coincidan con los hashes de la base de datos de RetroAchievements. Usa volcados verificados de No-Intro para la mejor compatibilidad.

Cores de Emulación

TruchiEmu está impulsado por libretro, una API de emulación universal. Cada sistema funciona en un core dedicado — piensa en ellos como motores de plug-in. Los cores se descargan, actualizan y configuran automáticamente a través del Descargador de Cores integrado.

Para una referencia completa sobre qué cores impulsan cada sistema, ajuste de rendimiento y la arquitectura técnica, consulta la Guía del Desarrollador.

Funciones de Estados de Guardado

Los estados de guardado te permiten capturar y restaurar tu posición exacta en un juego al instante, proporcionando una red de seguridad moderna para el gaming retro.

📸 Estados de Guardado Visuales

  • Captura automática de miniaturas para cada slot de guardado
  • Navegador visual de cuadrícula para selección rápida de estados
  • Hasta 10 slots de guardado por juego
  • Marcas de tiempo para cada estado capturado

📦 Almacenamiento Optimizado

  • Compresión LZ4 para todos los archivos de estado
  • Cabecera TCS2 personalizada para integridad de estados
  • Bajo uso de disco para bibliotecas grandes
  • Velocidades rápidas de carga/guardado

🔋 Soporte de Guardado de Batería

  • Almacenamiento dedicado para guardados de batería tradicionales
  • Compatibilidad con archivos de guardado de hardware original
  • Gestión automática por los cores de emulación
  • Separados de los archivos de estados de guardado

Administrador de Estados de Guardado

El navegador de estados de guardado integrado proporciona una forma visual de gestionar tu progreso:

  • Cuadrícula de Miniaturas: Navega tus posiciones guardadas visualmente mediante vistas previas de 320x240
  • Gestión de Slots: Acceso fácil a los slots 0 al 9
  • Metadatos: Ve exactamente cuándo se creó cada estado
  • Rutas Automatizadas: Estructura de carpetas consistente para fácil copia de seguridad y migración

Haz TruchiEmu tuyo con 17 temas de color acentuado inspirados en leyendas del gaming—desde Samus hasta Doom—más colores personalizados, modos de apariencia claro/oscuro y superficies tintadas.

Los 17 temas de color acentuado inspirados en gaming en TruchiEmu

  • 17 Temas Nombrados: Paletas de acento curadas organizadas en categorías Estándar (Samus, Chocobo, Protoss, Joker, Geralt, Mega Man, Custom) y Gaming (Mario, Luigi, Sonic, Half-Life, Kratos, Kirby, Zelda, Pikachu, Doom, Master Chief)

Gestión Arcade Profesional (MAME)

La emulación arcade puede ser compleja. TruchiEmu simplifica el proceso con herramientas especializadas para la gestión de ROMs de MAME.

Verificación de ROMs

Verifica automáticamente la integridad de las ROMs contra bases de datos oficiales usando hashes CRC32 para asegurar reproducción sin corrupción.

Seguimiento de Dependencias

Detección inteligente de relaciones de ROMs padre e hijo. TruchiEmu te alerta si falta una ROM padre requerida antes de que intentes iniciar un juego.

Automatización de Metadatos

Se integra con LaunchBox Games DB y archivos DAT para poblar automáticamente descripciones de juegos, fechas de lanzamiento y géneros.
