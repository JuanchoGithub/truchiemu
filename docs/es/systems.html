Soporte Universal

TruchiEmu está construido sobre la API de libretro, lo que significa que soporta una amplia gama de sistemas de gaming retro. Seis sistemas NES, SNES, N64, DOS, ScummVM y Saturn tienen runners dedicados con optimizaciones específicas por sistema. La mayoría de los otros cores de libretro funcionan con el runner predeterminado, aunque algunos pueden requerir BIOS o configuración manual.

La Regla General: Si existe un core de libretro para un sistema de gaming, TruchiEmu probablemente puede ejecutarlo. Esto incluye todo desde las primeras consolas de 8 bits hasta sistemas 3D más complejos y máquinas arcade. No todos los cores son igualmente compatibles los sistemas con runners dedicados generalmente ofrecen la mejor experiencia.

Gestión de Cores

Los cores son los motores de emulación que hacen el trabajo pesado. TruchiEmu facilita la gestión de estos motores sin salir de la aplicación.

El Descargador de Cores

No necesitas buscar archivos de core en internet. Usa el Descargador de Cores integrado para:

  • Descubrir: Explora una lista completa de cores disponibles. Tras la descarga, TruchiEmu asigna automáticamente cada core a sus sistemas compatibles.
  • Instalar: Instalación con un clic que gestiona la ubicación y configuración automáticamente.
  • Actualizar: Mantén tus motores de emulación al día con las últimas mejoras de la comunidad.

Elegir el Core Correcto

Algunos sistemas tienen múltiples cores disponibles, desde emuladores precisos por ciclos que priorizan la fidelidad hasta cores más rápidos optimizados para rendimiento. Puedes cambiar entre ellos en los detalles del juego o configuración del sistema para encontrar el mejor ajuste para tu hardware y preferencias:

Cores de Precisión

Priorizan emulación precisa por ciclos. Mejores para preservación y Macs de gama alta.

Cores de Rendimiento

Priorizan velocidad y eficiencia. Mejores para hardware antiguo o títulos extremadamente exigentes.

BIOS y Archivos de Sistema

Muchas consolas requieren un archivo BIOS (Basic Input/Output System) para arrancar. TruchiEmu elimina el dolor de cabeza de buscar BIOS manualmente.

BIOS Pre-Incluidas

TruchiEmu viene pre-empaquetado con archivos BIOS para la Sega Saturn (sega_101.bin y mpr-17933.bin), asegurando que estos sistemas funcionen justo después de la instalación. Para otros sistemas que requieren archivos BIOS (como PlayStation, 3DO y Dreamcast), necesitarás proporcionar los tuyos propios.

BIOS Personalizada

Si tienes archivos BIOS de regiones específicas o necesitas actualizar un archivo de sistema, puedes colocarlos en ~/Library/Application Support/TruchiEmu/System/. TruchiEmu priorizará tus archivos personalizados sobre las versiones incluidas.

Consejos de Optimización

Para sacar el máximo provecho de tu experiencia de emulación, considera estos ajustes:

  • Sobreescrituras de Core: Establece un core específico para un juego específico si el predeterminado no rinde bien.
  • Verificación de BIOS: Si un juego no arranca, asegúrate de que tu directorio de sistema esté correctamente mapeado en Configuración.
  • Aceleración por Hardware: TruchiEmu usa Metal para renderizado acelerado por hardware en todos los Mac. Asegúrate de que tus controladores gráficos estén actualizados para el mejor rendimiento en Apple Silicon.
