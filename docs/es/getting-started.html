Requisitos del Sistema

🖥️ Compatibilidad con macOS

Mínimo: macOS 14.0 (Sonoma) o posterior con Swift 5.9+

Recomendado: macOS 15.0 (Sequoia) o posterior para un rendimiento óptimo

Dependencias de Compilación

  • Xcode: Última versión estable (Requerido para compilar)
  • Herramientas de Línea de Comandos de Xcode: xcode-select --install
  • xcodegen: Usado para generar el proyecto Xcode desde project.yml
  • GPU compatible con Metal: Para renderizado de shaders y aceleración por hardware

⚠️ Importante: TruchiEmu usa funciones modernas de SwiftUI y shaders Metal que no son compatibles con versiones de macOS anteriores a 14.0.

Compilar desde el Código Fuente

TruchiEmu se compila usando XcodeGen para mantener una estructura de proyecto limpia. Sigue estos pasos para compilar la aplicación localmente.

1. Instalar Herramientas de Compilación

brew install xcodegen

2. Clonar y Generar el Proyecto

git clone https://github.com/JuanchoGithub/truchiemu.git
cd truchiemu
xcodegen generate # Esto crea el archivo TruchiEmu.xcodeproj

3. Compilar la Aplicación

Puedes compilar desde la línea de comandos o abriendo el proyecto en Xcode.

# Método CLI:
xcodebuild -project TruchiEmu.xcodeproj -scheme TruchiEmu -configuration Debug build

Alternativamente: Ejecuta open TruchiEmu.xcodeproj y presiona ⌘+B.

💡 Nota: Si modificas project.yml, debes ejecutar xcodegen generate nuevamente para actualizar el proyecto Xcode.

Primer Inicio y Configuración

Cuando inicies TruchiEmu por primera vez, se te guiará a través de un proceso de configuración inicial para preparar tu entorno.

Configuración del Entorno

Ubicación de Biblioteca y Datos

TruchiEmu separa tu biblioteca de juegos de sus datos internos de la aplicación. Aunque puedes elegir cualquier carpeta para tus ROMs, la aplicación almacena su configuración, estados de guardado y archivos de sistema en el directorio estándar de Application Support de macOS: ~/Library/Application Support/TruchiEmu/.

Dentro de la carpeta de Application Support, TruchiEmu organiza automáticamente los datos técnicos en:

  • Saves/ - Tus estados de guardado y archivos de guardado de batería
  • Cores/ - Los cores de libretro usados para la emulación
  • Thumbnails/ - Arte de juegos y capturas de pantalla en caché
  • System/ - Archivos BIOS y de sistema requeridos

Configuración de Controladores

Mapea tus entradas al emulador. TruchiEmu soporta de forma nativa controladores de teclado, Xbox, PlayStation y Nintendo Switch en macOS.

Agregar Tu Primer Juego

TruchiEmu soporta métodos simples de importación para tener tu biblioteca lista.

Importar Juegos

  1. Arrastrar y Soltar: Arrastra archivos o carpetas de ROMs desde Finder directamente a la ventana de la biblioteca de TruchiEmu.
  2. Importación Manual: Usa el botón de importación en la barra de herramientas de la biblioteca para buscar archivos.

Gestión de Archivos y Compatibilidad

TruchiEmu aprovecha la API de libretro, lo que significa que soporta prácticamente cualquier formato de archivo aceptado por el core de emulación activo. En lugar de depender de simples extensiones de archivo, la app usa hashes CRC32 y bases de datos DAT para identificar juegos con precisión.

📦 ROMs Comprimidos

Para sistemas arcade como MAME, .zip es el formato principal esperado y se gestiona nativamente por la biblioteca.

💿 Imágenes de Disco

Gestión inteligente de imágenes de disco. Cuando se detecta un archivo .cue, TruchiEmu lo prioriza y oculta automáticamente los archivos .bin asociados de la biblioteca para evitar entradas duplicadas.

🛠️ Filtrado de Biblioteca

Para mantener tu colección limpia, la aplicación filtra automáticamente los archivos BIOS del sistema y recursos de metadatos, mostrando solo entradas de juegos jugables en la vista de biblioteca.

⚠️ Aviso Legal: TruchiEmu no proporciona ROMs. Por favor usa copias de seguridad obtenidas legalmente de juegos que poseas.

Soporte de Controladores

TruchiEmu detecta automáticamente la mayoría de los controladores populares cuando se conectan vía USB o Bluetooth a través del framework nativo GameController de macOS:

  • Controladores Xbox: Soporte nativo para Xbox One y Series X|S
  • Controladores PlayStation: DualShock 4 y DualSense (PS5) soportados
  • Nintendo Switch: Joy-Cons y Pro Controller soportados
  • USB Genérico: La mayoría de los controladores MFi y XInput funcionan directamente

💡 Consejo sobre Controladores: TruchiEmu usa una plantilla de mapeo global basada en la configuración moderna de Xbox/PlayStation. Esto garantiza una sensación consistente entre diferentes sistemas, pero se puede personalizar por sistema en la configuración.

Personalización por Sistema

Cada core de emulación puede tener su propio mapeo de controles para adaptarse mejor al hardware original:

  1. Abre un juego del sistema que deseas configurar
  2. Navega a la configuración de Controladores en el menú principal
  3. Ajusta los mapeos de botones según tu preferencia
  4. Los mapeos se guardan por sistema y se aplican automáticamente la próxima vez que inicies un juego de ese sistema

Estados de Guardado

TruchiEmu proporciona una gestión robusta de estados de guardado junto con los guardados de batería tradicionales.

Estados de Guardado

  • Instantánea de la memoria del emulador
  • Gestión visual basada en slots (Slots 0-9 + Auto)
  • Gestionados desde la vista de Detalle del Juego con vistas previas en miniatura

Guardados de Batería

  • Funciona como el hardware original
  • Compatible con cartuchos reales
  • Gestionado automáticamente por el core del juego
