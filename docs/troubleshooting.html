Troubleshooting

Most issues can be diagnosed from the logs. If you need further help, check GitHub Issues.

Check the Logs

TruchiEmu writes detailed logs to help diagnose problems:

  • App Logs: ~/Library/Logs/TruchiEmu/ — general application and emulation logs
  • Crash Reports: ~/Library/Logs/DiagnosticReports/ — system crash logs

Enable verbose logging in Settings → Advanced → Log Level to capture more detail.

GitHub Issues

Search existing issues or file a new one at github.com/JuanchoGithub/truchiemu/issues.

When filing a bug report, include your macOS version, TruchiEmu version, and relevant log output.
