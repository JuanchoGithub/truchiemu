TV Mode

TV Mode is TruchiEmu's couch-friendly, full-screen library experience. Flip to TV Mode from the View → TV Mode menu (or a button on the game-toolbar) to browse your entire collection without a mouse.

TV Mode browsing with animated backgrounds, box-art focus effects, and gamepad navigation

What You Get

  • Gamepad Navigation: D-pad / analog stick scrolls through games, A selects, B backs out, R3/L3 toggles the sidebar — full traversal without ever touching the keyboard or mouse
  • Animated Backgrounds: Backdrops derived from each game's box art and system artwork, with auto-repeat navigation and dynamic delay scheduling
  • Box-Art Focus: Focused entries scale up with cleaner visuals and pin the background fill to the image size to prevent halo clipping
  • Short-List Mode: Compact title-only stack for very large libraries, with smooth item duplication
  • Filter & Sort: TV Mode maintains your filter and ROM selections on state restoration; reset filters at any time
  • Resolution-Adaptive Scaling: Auto-scales the UI relative to your screen resolution for a consistent feel on 1080p, 1440p, and 4K displays
  • Core Download Overlay: Trigger core downloads directly from TV Mode — no need to drop back to the desktop
  • Auto-Fullscreen: Optionally restore the previous fullscreen state when you exit TV Mode

Shader Collection

Transform your gaming experience with our curated collection of high-quality Metal shaders. Each shader is optimized for macOS and designed to enhance or authentically reproduce classic gaming visuals.

The shader picker interface allows real-time preview and adjustment

Built-in Metal Shaders

TruchiEmu ships with 14 built-in Metal shaders that work out of the box — no downloads, no setup:

Passthrough

No post-processing. Integer-scaled raw pixels rendered exactly as the original hardware intended. Perfect for purists who want unfiltered, authentic visuals with sharp pixel edges.

8b Game Boy

High-fidelity Game Boy DMG simulation with a customizable bezel, dynamic lighting, grid pattern, and the characteristic monochrome display feel.

8b Game Boy Color

Game Boy Color LCD simulation with temporal feedback, ghosting, iridescent effects, and customizable shell colors (Berry, Grape, Onyx, Glacier, and more).

GBA (Advanced LCD)

Advanced Game Boy Advance LCD simulation with ghosting, grid pattern, metallic reflections, and configurable light position.

CRT Classic

Classic CRT scanlines with barrel distortion, vignette, chromatic aberration, phosphor masking, and color bleed. Highly customizable with over 20 parameters.

Slang Shader Presets

Beyond the built-in Metal shaders, TruchiEmu also runs RetroArch .slangp presets via librashader. Hundreds of community-made presets from the libretro slang-shaders project are bundled and discovered automatically. Browse them in the All and Slang tabs of the shader picker. Drop new .slangp files into ~/Library/Application Support/TruchiEmu/SlangPresets/ and they appear automatically.

Shader Customization

Each shader includes adjustable parameters to fine-tune the effect:

  • Intensity Sliders: Adjust the strength of each effect
  • Parameter Presets: Quick settings for different display types
  • Real-time Preview: See changes instantly as you adjust
  • Per-Game Settings: Save shader preferences for individual games
  • Global Defaults: Set system-wide shader preferences

Learn more about the Shader System →

Performance Impact: Passthrough and Scale Smooth have minimal performance impact. CRT shaders (Multipass, Lottes, Classic) and LCD simulations use more GPU resources. Most modern Macs can run any shader at full speed.

Library Management

Organize your game collection with powerful library management features designed for serious collectors and casual gamers alike.

Your games are automatically organized with cover art and metadata

Automatic Organization

  • Smart Detection: Automatically identifies games from ROM file hashes (CRC32 hardware-accelerated via zlib, with DAT databases and a rejection-tracking scorer for MAME)
  • Metadata Fetching: LaunchBox Metadata Service downloads game descriptions, release dates, publisher, genre with platform overrides and match scoring
  • Cover Art Sources: ScreenScraper and Libretro CDN with configurable priority; interactive Box Art Picker lets you swap alt artwork per game; PPSSPP asset downloads are auto-applied
  • System Categorization: Groups games by original console/system
  • Achievement Detection: Identifies games with RetroAchievements support and shows the RA hash in the Game Detail view
  • iCloud Materialization: iCloud dataless-placeholders are materialized on access so ROMs stored in iCloud appear correctly when they would otherwise be displayed as zero-byte stubs
  • Removal Notifications: When ROMs are removed from a watched folder, TruchiEmu posts a notification and updates the library automatically

Grid View

Visual grid with cover art thumbnails. Perfect for browsing large collections.

  • Adjustable grid size via zoom slider
  • Sort by name, last played, or last added
  • Quick search and filter

List View

Detailed list with metadata and stats. Great for sorting and organizing.

  • Compact display for large libraries
  • Quick status indicators

RetroAchievements Integration

Earn achievements while playing classic games! TruchiEmu integrates seamlessly with RetroAchievements.org to add modern achievement hunting to retro gaming.

Track your progress and compare with friends on the global leaderboard

Achievement Tips:

  • Ensure you are using verified ROM files that match the RetroAchievements database hashes.
  • Check the achievement lists on the RA website to plan your approach for difficult trophies.
  • Join the RetroAchievements community to track your progress against other players.
  • Hardcore Mode: Enable Hardcore Mode via settings to block save states, rewind, slow motion, and cheats, which is required for earning Hardcore-tier achievements.
  • First-Run Enable Prompt: TruchiEmu offers to enable RetroAchievements (and Hardcore Mode) during the Setup Wizard, with cache-import progress for offline achievement data.
  • Game Detail View: The Game Detail page shows the game's RA hash and progress on already-unlocked achievements, sourced via accurate RomHasher console-ID mapping (CDI supported on PS1).

Important: Achievements only work with verified ROM files that match the RetroAchievements database hashes. Use No-Intro verified dumps for best compatibility.

Controller Support

Plug in a gamepad and it just works. TruchiEmu supports both Apple's GCController framework and SDL2 for broad controller compatibility.

What You Get

  • Plug and Play: USB and Bluetooth controllers are recognized the moment you connect them
  • Dual Driver Support: Works with GCController-compatible gamepads (Xbox, PlayStation, MFi, Switch Pro) and SDL2-compatible controllers for broader hardware support
  • Smart Defaults: TruchiEmu picks a sensible button layout based on the controller type and the system you're playing
  • Per-Controller Profiles: Each controller you connect gets its own mapping, remembered for next time
  • Per-System Overrides: A PlayStation pad can be SNES-style on one system and Genesis-style on another
  • Multi-Player Keyboard Mapping: Refactored keyboard input supports multiple players from a single physical keyboard — combine a gamepad for P1 and keyboard for P2 (or vice-versa)
  • Gap-Slot Prioritization: When a new controller connects, TruchiEmu prioritizes the first empty slot before substituting a keyboard player — your P2 stays P2
  • SDL Disable & Reset: Disable a stuck SDL controller or reset the SDL controller list without quitting the app; keyboard controllers can also be disabled/reset independently
  • Replace Keyboard with Controller: Toggle whether a freshly-connected controller should automatically take over a keyboard-assigned slot
  • Deadzone & Sensitivity: Tune stick response so drift doesn't wander the character
  • Remap Anything: Swap any button to any other button, including face, shoulder, and stick clicks
  • Analog Mouse Mode: Use a stick to control the mouse in DOS and ScummVM games — see the Analog Mouse section for full details
  • Keyboard Shortcuts: System hotkeys for save states, screenshots, and other common actions

Learn more about Controller Support →

Analog Mouse Support

TruchiEmu lets you use your gamepad's analog sticks to control the mouse cursor in DOS and ScummVM games, with configurable buttons for mouse clicks and D-pad for keyboard inputs.

Analog mouse settings with sensitivity, dead zone, and button mapping

Key Features

  • Analog Stick to Mouse: The primary analog stick (left or right) controls the cursor at 60fps with configurable sensitivity
  • Secondary Stick for Fine Control: The secondary analog stick moves the mouse at 1/5 speed for precise cursor placement
  • D-Pad as Keyboard: D-pad sends arrow keys, Start sends Enter, Select sends Space
  • Configurable Button Mapping: Assign left, right, and middle click to any gamepad button
  • Per-System & Per-Game: Independent settings for DOS and ScummVM, with per-game overrides

Comfort Tip: Adjust sensitivity and dead zone in Settings → Analog Mouse. Use the secondary stick for precise pixel targeting, and map mouse buttons to comfortable gamepad buttons for your preferred play style.

Point & Click Guide

Stuck on a puzzle? The built-in Game Guide sidebar brings progressive hints and full walkthroughs directly into your game window. It automatically appears for adventure and point-and-click games, pulling content from the Universal Hint System (UHS) and GameFAQs.

Key Features

  • Progressive Hints (UHS): Spoiler-free hints that reveal one at a time — get just enough help without ruining the puzzle
  • Full Walkthroughs (GameFAQs): Complete text walkthroughs as a fallback when UHS hints aren't available
  • Gamepad Navigation: Browse the guide with your controller — analog sticks scroll, A/B buttons navigate, R3/L3 toggles the sidebar
  • 387+ Game Mappings: Pre-matched UHS guides for classic adventures including Monkey Island, Broken Sword, Grim Fandango, and more
  • Automatic Detection: Adventure and point-and-click games are identified by genre or system (ScummVM games always qualify)

Quick Access: Press Cmd+J or click the guide toolbar button to open the sidebar. For DOS and ScummVM games, input capture is automatically released when the guide opens and resumed when it closes.

Time Machine

TruchiEmu's Time Machine brings rewind, fast-forward, and slow-motion controls directly to the game toolbar. The Setup Wizard offers an optional Time Machine step on first launch, and the controls stay available during gameplay for the ultimate sandbox.

Key Features

  • Rewind: Step backward through recent frames to retry a missed jump, a botched combo, or a fatal hit without reaching for a save state
  • Fast Forward: Skip slow dialogue, grinding, or long cutscenes while keeping audio pitched to playback speed
  • Slow Motion: Study frame-perfect sequences at reduced speed — ideal for fighting game combo practice or tricky platformer setups
  • Hardcore-Aware: When RetroAchievements Hardcore Mode is active, Time Machine controls are disabled alongside save states and cheats
  • Per-Core Compatibility: The Time Machine uses save-state deltas; some cores (e.g. Dolphin) with known crash issues are gracefully excluded, and Play! (PS2) save-state warnings surface clearly

Where to find it: Time Machine controls appear on the in-game overlay toolbar. Build them into the Setup Wizard during first launch from Settings → Time Machine, where you can also configure rewind buffer depth, slow-motion ratio, and hotkeys.

Stream Recording

Record your gameplay sessions or stream live to Twitch, YouTube, or a custom RTMP server — all without leaving the game. The entire encode/RTMP pipeline runs in-process via HaishinKit, so there are no external processes, FIFOs, or silent frame drops under backpressure.

Key Features

  • Local Recording: Capture gameplay to local files in H.264, HEVC, or lossless ProRes 422/4444
  • Live Streaming: Stream directly to Twitch or YouTube, or point to any custom RTMP endpoint with stream-key verification (Twitch/YouTube give immediate success/failure feedback)
  • Resolutions: Native / 720p / 1080p / 1440p / 4K via the StreamResolution picker; ProRes encoders are demoted to H.264 for streaming
  • VideoToolbox Encoding: Hardware-accelerated H.264/HEVC encode and AAC audio encode via macOS VideoToolbox for minimal performance impact
  • Rolling Video Buffer: Tap a "save last moments" hotkey to write the past few seconds to disk — perfect for clip-worthy plays you didn't see coming
  • Share Button: Single-press and long-press share actions, configurable per game
  • Record With or Without Shaders: Choose whether the recording captures the post-shader drawable or the raw core frame
  • In-Game Controls: Start/stop recording from the game toolbar without breaking your flow; visibility of the record button adapts to your current recording state and settings

Where to find it: Configure streaming in Settings → Streaming & Media — separate tabs for Twitch, YouTube, custom RTMP, and the share button behavior.

Learn more about Stream Recording →

Netplay — Roadmap

Netplay (multiplayer over the network) is documented as an implementation plan and is not yet shipped. The complete design — infrastructure, matchmaking, and rollback netcode integration — lives in Netplay_Implementation_Plan.md in the repository root.

Roadmap High-Level

  • Core integration: Wrap libretro's netplay API in a Swift-friendly SwiftPM module reusing existing LibretroBridge
  • Transport: Initial peer-to-peer via STUN, with optional relay for restrictive NATs
  • Matchmaking: Optional centralized matchmaking with room codes — no requirements on local discovery
  • Lobby UI: SwiftUI lobby shown as a tab/window; Brawl-style host/join/codes
  • Savestate sync: Pull the existing save-state & Time Machine pipeline to seed initial state for retro games that support it

Status: Netplay is a documented roadmap, not a shipped feature. Track progress in Netplay_Implementation_Plan.md.
