Changelog / v1.17.2

v1.17.2

November 12, 2026

This release fixes two input problems: the recording hotkey no longer triggers a library rescan, and the Settings and game-info windows no longer send gamepad presses to the library behind them.

Highlights

  • Recording hotkey works in a game window: The recording hotkey (⇧⌘R by default) was the same shortcut as the Rescan Library menu item, and macOS gives menu shortcuts the first chance to handle a key press. Pressing the hotkey in a game window started a library rescan instead of a recording. Because a full rescan clears every library entry before it scans again, and scanning skips folders while a game runs, each press emptied the library. The game window now handles the media hotkeys (screenshot, share button, recording) before the menu, and a full rescan is refused while a game runs.
  • Recording results are visible: A finished recording shows a Recording saved notice with Show in Finder, and a recording that cannot start shows a notice with the reason. Before, both cases were silent.
  • Settings and game-info windows keep their own gamepad input: Both windows claimed gamepad navigation before macOS made them the key window, so they were bound to the library window. The library handled the presses, and during button-mapping capture a press of A or B also moved through the library behind the window (for example, it entered TV Mode). Each window now binds to its real window after it appears.

Detailed Changes

  • Input — FocusableMTKView dispatches the media hotkeys (screenshot, share button, recording) from performKeyEquivalent, so the game window wins over the menu key equivalent; keyDown uses the same dispatcher.
  • Library — ROMLibrary.fullRescan() refuses to clear the library while a game is running.
  • Recording — StreamRecordingService announces finished user recordings and reports start failures (folder creation, writer creation, writer start) instead of failing without a message.
  • Game window — StandaloneGameWindowController shows a Recording saved pill and a Notification Center entry with Show in Finder, and a failure pill with the reason.
  • Controls — a new gamepadNavWindowOwner(_:) modifier binds ownedWindow to the real hosting window of the view after the view attaches; the Settings and game-info gamepad navigation contexts use it.
  • Localization — new strings for the recording notices in English, Spanish, Portuguese, and Japanese.
  • Bump marketing version to 1.17.2 and build number to 45 across project.yml, both Info.plists, and docs/_config.yml.
