Changelog / v1.15.0

v1.15.0

September 26, 2026

This release adds custom core import with Switch/suyu support and vendored MoltenVK, ships a 3D Pittman cabinet with fitted camera and TV toggle, brings CRTSim parity with pixel ratio and cabinet reflection controls, and tightens holo rainbow foil with light-spot confinement and matched foil strength.

Highlights

  • Custom core import: Import generic zip/dylib cores with companion library handling, binary signing, and system mapping. Adds a Switch database entry, per-system import entry points, suyu keys/firmware checks, and MoltenVK provisioning via LIBVULKAN_PATH for headless Vulkan cores.
  • Pittman 3D cabinet: Mesh screen and frame with fitted camera and a TV toggle for a cabinet-style presentation.
  • CRTSim parity: Pixel ratio control, cabinet reflection controls, split bloom, and stable NTSC fields.
  • Holo foil polish: Rainbow foil confined to the light spot with full dark hiding the foil, and image foils matched to generated foil strength.

Detailed Changes

  • Cores — custom core import with Switch/suyu support and vendored MoltenVK (companion libs, binary signing, system mapping, Switch database entry, per-system import entry points, suyu keys/firmware checks, LIBVULKAN_PATH provisioning)
  • Shaders — CRTSim parity: pixel ratio, cabinet reflection controls, split bloom, stable NTSC fields
  • Cabinet — Pittman 3D cabinet: mesh screen and frame with fitted camera and TV toggle
  • Holo FX — rainbow foil confined to light spot with full dark hiding foil; image foils matched to generated foil strength
  • Bump marketing version to 1.15.0 and build number to 38 across project.yml, both Info.plists, and docs/_config.yml.
