Changelog / v1.8.7

v1.8.7

August 3, 2026

Graphics and shader release: live in-game shader editor with unsaved-change confirmation, bezel reflection now blurring into the CRT scanlines/phosphor for Famicom and RF displays, Slang preset grouping with stable hashed IDs, and an overscan default that keeps the full frame visible in RGBA conversion.

Highlights

  • Live shader editor sidebar: Open an in-game sidebar from the game window to tweak shader parameters live. Unsaved edits are guarded with a confirmation overlay, and changes persist via shader preset parameter handling with refreshing SwiftUI state.
  • Bezel reflection blur: Bezel reflections now add a blur tailored to the CRT look. FamicomRF and RfDisplay shaders blend the reflected bezel into the scanline/phosphor result for a more realistic CRT-on-flat-panel effect.
  • Slang preset grouping & stable IDs: Slang presets are grouped and disambiguated by a SHA-256–derived stable ID so same-name presets no longer collide, with improved discovery error handling and a cached final-pass __absolute flag to drive scaling decisions.
  • Overscan & frame fit adjustments: The RGBA conversion path defaults overscan to zero so the full source image remains visible, and MetalCoordinator caches system recognition for consistent aspect-ratio handling across supervisor strategies.
  • Rendering performance pass: A generation-gated uniform cache in the RF decoder avoids needless dictionary copies during gameplay, and drawable alpha is reset after Slang renders to prevent transparency artifacts.

  • feat: enhance bezel mask handling for improved visual fidelity and stability in RF display

  • Enhance Slang Compiler and Metal Coordinator for Improved Rendering — cached _finalPassIsAbsolute flag accessed without the main actor, aspect-ratio/viewport scaling types based on the preset's final pass, drawable alpha handling fix, and SHA-256–based preset ID disambiguation
  • Enhance shader and rendering performance — generation-gated uniform cache for the RF decoder, phosphor mask/scanline alignment to source pixels in CRTFilter.metal, cached aspect ratio in XPCBridgeAdapter to cut Hz sync rounds, optimized audio resampling with UnsafeBufferPointer, and efficient GameTimeBarOverlay timer management
