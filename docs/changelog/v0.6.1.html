v0.6.1 Stability and UI/UX

April 21, 2026 44 commits

UI/UX refinement release with significant improvements to the shader system, core options management, and overall app stability.

Highlights

  • Game Boy Shader: Greatly improved Game Boy shader, now working core options for all cores and games
  • Core Options: Working core options with search functionality, category browser, and persistent configuration
  • Shader Management: Major updates to shader configuration, application, and setting interfaces
  • App Architecture: Big refactor moving files around for better project clarity
  • MAME Identification: Several improvements to the MAME identification system
  • ROM Scanning: Faster ROM identification and improved MAME BIOS detection
  • Notifications: Initial notification system v1.0
  • RetroAchievements: Improvements to RetroAchievements integration
  • Cheats: Improved cheat interface
  • Controllers: Improved controller settings
  • Settings Management: Updated settings management system

Breaking Changes

  • Major file reorganization: GameDetailView split into smaller files, SharedPlayerComponents split, LibretroBridge split into dedicated files
