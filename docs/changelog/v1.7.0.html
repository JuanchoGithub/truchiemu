Changelog / v1.7.0

v1.7.0

July 15, 2026

Time Machine playback controls, Famicom RF NTSC decoder shader, LaunchBox metadata enrichment, an Update Wizard, a redesigned grid/sidebar, and broad build-warning cleanup.

Highlights

  • Time Machine: Rewind, fast-forward, and slow-motion playback controls added to the Setup Wizard and game toolbar
  • Famicom RF Shader: New NTSC-decoding Famicom RF shader with customizable parameters and grayscale output, based on GOROman/famicom-rf-hackrf-decoder
  • Update Wizard: In-app wizard for managing app updates with user interaction and a dedicated About view entry
  • LaunchBox Metadata: Metadata enrichment and box art retrieval via a new LaunchBox Metadata Service with platform overrides
  • Grid & Sidebar Redesign: New GridCollectionView, sidebar redesign, category management with deletion, and improved search
  • Game Detail Enhancements: Title screen support, category chips, and refined GameCardView hover/press interactions
  • Recording & Streaming: Recording hotkey, improved share/record button visibility, even-dimension stream resolution handling
  • Netplay Plan: Comprehensive Netplay implementation plan documented with infrastructure and matchmaking details

Detailed Changes

  • Added Time Machine controls (rewind, fast-forward, slow motion) wired into Setup Wizard and game overlay toolbar
  • Added Famicom RF shader with NTSC decoding, additional parameters, grayscale conversion, and localization support
  • Integrated GOROman/famicom-rf-hackrf-decoder dependency into AboutView with description and license details
  • Implemented Update Wizard for managing app updates with user interaction
  • Added LaunchBox Metadata Service for metadata enrichment and box art retrieval with platform overrides and match scoring
  • Added GridCollectionView for displaying ROMs in a grid layout with launching state management
  • Redesigned the sidebar with category deletion, confirmation alerts, and improved system search
  • Integrated CategoryManager into GameDetailView with category chips in the header
  • Added title screen support and enhanced game detail view
  • Added screenshot capture functionality in MetalCoordinator for enhanced image saving
  • Added streaming improvements: recording hotkey, toolbar compact mode, and even-dimension stream resolution handling
  • Added CDI support for RetroAchievements hash generation
  • Added support for per-system hotkey configurations and a new guide sidebar toggle
  • Added controller identity management and enhanced button mapping functionality
  • Refactored shader management to streamline preset activation and uniform handling, including slang preset support
  • Improved aspect ratio handling, viewport calculations, and texture/pixel buffer management in Metal rendering
  • Extensive build-warning cleanup across concurrency modifiers, unused variables, and type safety
  • Updated localization files with new translation keys for Time Machine, Update Wizard, and Famicom RF shader
