Changelog / v1.17.1

v1.17.1

November 11, 2026

This release fixes a crash at launch on Macs that do not have Homebrew installed. The app now carries its own copy of SDL2 instead of loading it from a Homebrew folder.

Highlights

  • The app opens again on Macs without Homebrew: v1.17.0 asked macOS to load libSDL2-2.0.0.dylib from the Homebrew folder (/opt/homebrew/opt/sdl2/lib/). Homebrew is not part of macOS, so on a Mac that does not have it, macOS stopped the app before the first window appeared (crash report: Library not loaded, namespace DYLD). The app now contains its own copy of SDL2 and loads that copy from inside the app bundle. No Homebrew install is needed.
  • Requires macOS 26 or later: The SDL2 build inside the app targets macOS 26.0, so this version runs on macOS 26 and macOS 27 only. v1.17.0 was already limited to these versions at runtime, because the same SDL2 build had to load.

Detailed Changes

  • Build — the Embed SDL2 dylib phase now also rewrites the app's own dependency on SDL2 to @rpath/libSDL2-2.0.0.dylib. Before, only the copied dylib got a new ID while the app still pointed at the absolute Homebrew path, which works on a developer Mac and fails everywhere else. No /opt/homebrew reference remains in any binary inside the bundle.
  • Build — deployment target raised to macOS 26.0 in project.yml and xpc_target.yml, to match the minimum OS of the bundled libSDL2-2.0.0.dylib.
  • Shaders — ShaderManager.getUniformSnapshot(), getUniformSnapshotIfChanged(cachedGeneration:), and getCurrentFragmentFunctionName() are now nonisolated static, so renderer threads read them without the main-actor-isolated singleton; call sites in MetalCoordinator, BaseRunner, and the cabinet bezel check updated.
  • Controls — GamepadNavigationManager.toolbarComboMembers is now a nonisolated static set, so the SDL, DOS, ScummVM, and base gamepad input paths check toolbar combos without touching the main-actor instance.
  • Box art — BoxArtService.resolveLocalBoxArt(for:) and isValidImageFile(at:) moved to nonisolated static; the instance method remains as a wrapper for existing callers.
  • Recording — finalized AVAssetWriter and input references are handed to background queues as nonisolated(unsafe), and MetalCoordinator resolves StreamRecordingService.shared before the command-buffer completion handler instead of inside it.
  • Scroll performance audit — the deprecated CVDisplayLink is replaced by CADisplayLink on a dedicated thread, so the audit keeps sampling while the main thread is blocked.
  • Main-actor correctness — the grid and sidebar scroll debounce timers and the external-display full-screen observer now use MainActor.assumeIsolated, because they always run on the main run loop.
  • Cleanups — removed unused PI, lineR2, latestOnError, and duplicate holo size constants, and the unused CoreVideo import; replaced the deprecated String(contentsOf:) with the usedEncoding: form; discarded unused results, changed var to let, used Range(rows) instead of rows.toRange(), and marked the frame pointer in rf_decoder_bridge.h as nullable.
  • Bump marketing version to 1.17.1 and build number to 44 across project.yml, both Info.plists, and docs/_config.yml.
