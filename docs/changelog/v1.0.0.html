Changelog / v1.0.0

v1.0.0

June 10, 2026

First stable release! Full RetroAchievements integration, game guide sidebar, controller deadzone settings, Jaguar BIOS service, ISO scanning overhaul, and more.

Highlights

  • RetroAchievements Integration: Full rcheevos runtime with achievement tracking, rich presence, and exclusive achievement handling
  • Game Guide Sidebar: Built-in progressive hints (UHS) and walkthroughs (GameFAQs) for adventure and point-and-click games, with full gamepad navigation
  • Achievement Display Settings: New view mode settings and enhanced achievement sections in GameDetailView
  • Jaguar BIOS Service: Automatic BIOS extraction for Atari Jaguar games
  • Controller Deadzone Settings: Per-controller deadzone configuration with UI sliders
  • Escape Toast Overlay: Visual feedback during keyboard/mouse input capture
  • ISO Scanning Improvements: Sector format detection, LBN size retrieval, CUE/MDS/CCD descriptor file support
  • Notification Pill Improvements: Tap-to-dismiss and configurable auto-dismiss delay
  • Progressive Save State Expansion: Expandable save state slots in GameDetailView

Detailed Changes

  • Fixed: proper ISO9660 directory record parser (replaces heuristic)
  • Fixed: correct PSP ROM hashing for RetroAchievements
  • Fixed: handle CD-ROM Mode 2 subheader and PC-FX sector offsets
  • Fixed: ISO9660 data length offset and PSP version suffix handling
  • Fixed: default shader presets for Game Boy and Game Boy Color
  • Fixed: enhanced local box art resolution with file existence check
  • Switched to MD5 hashing for ROM identification in RetroAchievements (replaces CRC32)
  • Enhanced RA game auto-detection with notification handling
  • Achievement badge prefetching improvements
  • Game Boy colorization settings compatibility
  • Hotkey settings layout simplification and search
  • Help settings search functionality
  • Logging system refactored to use LoggerService
  • Analog mouse settings refactored
  • Training mode overlay improvements
  • Localization updates for English, Spanish, and Portuguese
  • Game Guide documentation added in all three languages
