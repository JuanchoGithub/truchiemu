Changelog / v1.10.0

v1.10.0

August 22, 2026

This release brings the Holo card effects — a liquid-glass sheen and glass-orb play button — alongside a new hue-cycles setting that controls how many rainbow rotations play across a card as the cursor moves, with effects suppressed during scrolling for smoothness. Custom cheats are now persisted to the per-game file and can be deleted per row, surviving reload and restart.

Highlights

  • Holo effects: A new liquid-glass sheen view modifier and a glass-orb play button bring a dimensional, glassy look to library cards and controls.
  • Hue cycles setting: A new Holo setting controls how many rainbow hue rotations sweep across a card as the cursor moves, with translations in English, Spanish, Japanese, and Portuguese.
  • Smoother scrolling: Holo effects are now suppressed while the library is scrolling, keeping interaction fluid on large collections.
  • Persistent custom cheats: Custom cheats are written to the per-game .cht file and survive reload and app restart, and each cheat row now has a delete button.

Detailed Changes

  • Add Holo feature support and UI enhancements — LiquidGlassSheen view modifier and GlassOrbPlayButton, Holo settings wired into Spanish/Japanese/Portuguese translations, BoxArtService resets holo masks when box art updates, the BoxArtLayers dependency added to the project, plus a bounding-box analysis script
  • feat: add hue cycles setting for Holo effects — HoloSettingsStore and HoloSettingsSnapshot gain a hueCycles value; HoloGameCardView suppresses effects during scrolling; HoloBumpRenderer handles invalid texture sizes gracefully; translations added across languages
  • fix: persist and allow deletion of custom cheats — CheatManagerService.addCheat/removeCheat persist to the per-game custom .cht file so custom cheats survive reload and restart; a delete (trash) button added to each cheat row; CheatAutoLoader.saveCustomCheats simplified to write a single canonical .cht per game (fixes #34)
  • Bump marketing version to 1.10.0 and build number to 33 across project.yml, both Info.plists, and docs/_config.yml
