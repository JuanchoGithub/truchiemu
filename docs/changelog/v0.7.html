Changelog / v0.7

v0.7 Getting closer to full vision

May 3, 2026 92 commits

Large release focused on performance optimizations, MAME gaming improvements, genre categorization, and core options management. Some changes may be breaking, but most add speed, options, and quality-of-life improvements.

Highlights

  • MAME Improvements: Better MAME gaming with genre identification, improved ROM handling, and identification upgrades
  • Genre Categorization: Full genre support with metadata extraction from .rdb files
  • Save System: Implemented save location management, improved SRAM and save state handling
  • Shader Pipeline: Fixed how shaders get parameterized, added GBA and CRT Multipass shaders with temporal feedback
  • Game Boy Color: New 8-bit GB Color shader with initial version
  • Input Capture: Keyboard and mouse capture for game windows with Accessibility permissions
  • Core Options: Fixed core overrides bugs, improved headless core detection for downloads
  • Toolbar: Enhanced main toolbar with hints and improved menus
  • ScummVM: Improved game detection and mouse support
  • Cheat Management: Improved cheat management interface
  • Testing: Added initial test suite

Bug Fixes

  • Over 100 bug fixes across the release
  • Fixed DOSBox crashes
  • Fixed race condition on new core install
  • Fixed PPSSPP stability (still WIP)
  • Fixed Wii game identification
  • Fixed Enter key launching games
