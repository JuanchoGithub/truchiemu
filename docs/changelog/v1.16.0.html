Changelog / v1.16.0

v1.16.0

October 22, 2026

This release adds smart categories, a grouped library view, six new shader presets, a redesigned game toolbar, and a large performance overhaul across startup and library scrolling.

Highlights

  • New shaders — with props where props are due: The built-in shader library grows to 23 presets with three new families.
    • Morph CRT — physical CRT simulation with a full analog signal path (composite encode/decode, NTSC/PAL carrier artifacts), dynamic scanlines, phosphor glow, curvature, and convergence. Inspired by PixelFX Morph 4K v4.
    • CRT Shader pack (Reference, Clean, Soft, Photo Soft) — Metal port of crt-shader by Brooklyn (OutThisLife), a multi-pass CRT reconstruction with horizontal beam spread, phosphor mask, and optics passes (live demo). Credit lives in Settings → About.
    • Glyph Text — in-house shader that renders your game as a grid of monospaced glyphs (ASCII, Extended Latin/Greek/shading, or Blocks); density follows luminance, with source colors or a phosphor tint.
  • Smart categories: Save any library search as a dynamic category. Rules cover search terms, systems, filter chips, genres, and per-game include/exclude overrides, with a live match preview (game count, systems, sample names). Multi-system categories follow newly active systems; a bolt marks smart categories in the sidebar, and removing a game from a smart category reverts it to automatic membership.
  • Grouped library: Two new sorts — System (A–Z) and System (by year) — render collapsible per-system section headers showing icon, launch year, and game count. Merged systems (GB+GBC, MAME+FBNeo) form one section, and each category remembers its own sort and view mode.
  • Redesigned game toolbar: Configurable layout with a rebuilt save/load cluster — Save writes to the active slot in one click (badge shows the slot), and Load opens a compact 5×2 save-state browser with previews, an Auto row, and Save Here/Load actions. The active slot persists across launches.
  • Performance overhaul: Warm startup on a 2000+ ROM library is roughly 4× faster (async launch pipeline, byte-packed display cache, network and disk work deferred past first paint). Scroll jank is eliminated across grid, holo, list, and row modes via cell recycling, zero synchronous image I/O, and hover gating; row mode now uses NSTableView-backed cells; slang shader chains compile off the main thread.
  • Sharper screenshots: Screenshot capture crops to the centered game area, so black bars are no longer baked into the image. Bezel-style slang chains keep their full-frame layout for screenshots, recordings, and streams.

Detailed Changes

  • Smart categories — smart rules on GameCategory (query, system scope, chips, genres, per-game include/exclude), sidebar save-search card, live preview, "Searching in" banner with quick exit, fields persisted, backed up, and localized in 4 languages
  • Grouped library — new sorts with section headers, merged-system sections, card subtitles hidden while grouped, launch years filled for 96 systems in SystemDatabase.json
  • Shaders — Morph CRT (single-pass analog path, amplifier blur, composite YIQ, PAL support), CRT Shader pack (four presets, multi-pass), Glyph Text (three glyph sets), shader descriptions credited in all languages
  • Toolbar — two-button save/load, 5×2 save-state browser, unified EmulatorRunner.selectSlot, gamepad focus indices updated
  • Performance — display cache (~10 ms full-library round-trip), off-main library load with art-preserving publishes, deferred update check/core-info/controller mappings, NSCollectionView cell recycling, NSCache-only thumbnail fast paths, scroll-activity hover gates, O(1) category membership index
  • Slang — frame count, direction, FPS, aspect, and frametime uniforms; parameter detection in legacy structs and includes; ISO-8859-1 shader reading; bundled patched librashader runtime for final-pass feedback and scaling; shader history cleared on reset and save-state load
  • Input fixes — toolbar-close press swallowed, toolbar combo killed at the input so START never reaches the core, A+B soft reset fixed after gamepad toolbar use
  • Library fixes — single-system cores no longer lend extensions to other systems (NES no longer claims .gb), boxart no longer leaks between recycled cards, boxart shows after manual add, game titles keep their spaces, renames refresh the grid immediately, double-launch debounced per ROM
  • Holo fixes — hover freeze after scroll (artwork frame re-measured on hover), pinch-zoom no longer shuffles cards (layout invalidated instead of full reload)
  • macOS 27 — menu item icons restored via titleAndIcon labels
  • Bump marketing version to 1.16.0 and build number to 41 across project.yml, both Info.plists, and docs/_config.yml.
