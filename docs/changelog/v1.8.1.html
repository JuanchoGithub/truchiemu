Changelog / v1.8.1

v1.8.1

July 23, 2026

Patch release focused on controller management improvements and TV Mode refinements. Overhauls keyboard mapping to support multiple players, adds priority-based controller slot allocation, and introduces SDL controller disable/reset controls. TV Mode gains fullscreen exit handling, filter/sort modes, gamepad navigation improvements, resolution-adaptive scaling, and integrated core download overlay.

Highlights

  • Multi-player keyboard mapping: Refactored keyboard input to support multiple players with simplified controller settings.
  • Controller slot management: Gap-slot prioritization over keyboard replacement when connecting new controllers.
  • SDL controller controls: Added disable and reset functionality for SDL and keyboard controllers.
  • TV Mode enhancements: Filter sync on state restoration, reset filters action, sort mode, short-list mode with smooth item duplication, and core download overlay for seamless core management.
  • TV Mode quality-of-life: Fullscreen exit via keyboard/gamepad, resolution-adaptive scaling, and improved gamepad navigation.
  • RetroAchievements fixes: Cache pre-load condition check and RA Hash display in game detail view.

Detailed Changes

  • Updated controller management to prioritize gap slots over keyboard replacement and adjusted default setting
  • Added option to replace keyboard input with newly connected controllers
  • Enhanced controller management with disable and reset functionality for SDL and keyboard controllers
  • Refactored keyboard mapping to support multiple players and simplify controller settings
  • Improved TV Mode fullscreen exit handling and gamepad navigation support
  • Added TV Mode functionality with controller bindings and UI updates
  • Enhanced TV Mode state restoration by syncing filter and ROM selections
  • Added reset filters action and sort mode functionality in TV Mode
  • Implemented short-list mode with smooth item duplication for TV Mode
  • Enhanced RetroAchievements integration with cache pre-load condition check
  • Improved error handling in StandaloneGameWindowController to surface specific runner errors
  • Updated TV Mode to maintain user's filter selection when entering TV mode
  • Implemented auto-fullscreen restoration in TVModeSettingsManager when exiting TV mode
  • Enhanced TV Mode view to manage keyboard input more effectively during gameplay
  • Added new translations for core download actions and game info in English, Spanish, and Portuguese
  • Introduced TVModeCoreDownloadOverlay for better core management in TV mode
  • Updated GameDetailView to display RA Hash and improved achievement loading logic
  • Implemented resolution-adaptive scaling for TV Mode
  • Enhanced controller settings with SDL support and live axis observation
