v1.1.0

June 10, 2026

Minor release updating foreground colors for accessibility with the new Mega Man default accent theme.

Highlights

  • Accessibility: Updated foreground colors to use AppColors.textOnAccent for better contrast and readability across all themes
  • Default Theme: Updated default accent theme to Mega Man and adjusted related color values

Detailed Changes

  • Updated foreground colors across the app to use AppColors.textOnAccent
  • Changed default accent theme from Samus to Mega Man
  • Adjusted color values for the new default theme
  • Improved accessibility with better text contrast on accent backgrounds
