Changelog / v1.17.0

v1.17.0

November 3, 2026

This release rebuilds the Per-System settings page as a three-column tree, adds user-ordered filter and sort pills, completes the system icon sets, and fixes several TV mode and library issues.

Highlights

  • Per-System settings as a three-column tree: The page now shows a page list, a system list, and an options column. Entering the section opens both columns expanded; each click collapses the column you drill past, and clicking a system icon in the rail slides its list back out. The selected system and option are remembered for the session and persisted across launches.
  • User-ordered filter and sort pills: Right-click any pill and choose Edit... to toggle visibility and drag pills into your own order. The chip bar measures its real width, moves pills that do not fit into the Other popover instead of scrolling, and never pushes or compresses the library layout.
  • Every system now has an icon: Both system-icon sets cover all 142 systems, including high-resolution variants, dot-art fallbacks, and monogram badges for systems without colored art. GameCube and Virtual Boy controller icons no longer fail to match.
  • TV mode stability and correctness: The boxart backdrop no longer flashes the raw image before the blur is ready, detail entry is staggered over the dimmed rows, and row selection, per-entry positions, and category tiles stay in sync. Animation and synchronous image decodes no longer stall the main thread, so game video no longer freezes while a game runs.
  • Menu icons restored on macOS 27: Item icons appear again in the sidebar, context menus, and popup menus.
  • Shader editor and Morph CRT: Save As now appears only when parameters changed, and Cancel closes the editor when nothing changed. Morph CRT built-in defaults now match the Morph CRT Custom saved preset.

Detailed Changes

  • Settings — Per System is a three-column tree (page list, system list, options column) with sliding sidebar rails; the system list, rail, and detail header use the library system icons with an SF Symbol fallback; the options column carries the system name as its title; the RetroAchievements override uses a content-sized segmented picker
  • Settings — the navigation columns keep fixed widths so a wide page (such as Controls) no longer steals space from the options column or breaks the window toolbar; the Controls page also uses less width
  • Library — added a unified FilterPill model and FilterPillPreferences in AppSettings for pill order and visibility; the width-aware chip bar measures pills in a hidden background row and moves overflow into the Other popover; the pill editor supports in-place drag reordering with a visible drop position
  • Library — wired icons for every system that has art in both EmulatorIcons and ControllerIcons, generated the missing 132/600 variants, added dot-art and monogram fallbacks, fixed the gc.ico/virtualboy.ico id mismatches, credited RetroArch dot-art in About, and added scripts/build_emulator_icons.py
  • TV mode — the boxart backdrop blur and saturation are baked with CoreImage once per cover (ImageCache.blurredBackdropImage) and crossfade as a plain bitmap, removing the full-strength sharp-image flash; detail entry is staggered so rows blur first and the detail fades in over dimmed rows
  • TV mode — animation pauses while a game runs; the holo settings snapshot is built once per ROM and the foil subtree is equatable; the holo timeline runs at 20 fps instead of 33 fps; main-thread thumbnail decodes were replaced with cache/pregen lookup plus async fill
  • TV mode — CurvedRowLayout derives the animated center from centerIndex and snaps when the item count changes, so coalesced input steps no longer open the neighbouring game; the selected game is remembered per row-1 entry; category entries use the category's real name, icon, and colour
  • Fixes — smart category counts, sort configuration writes, launch debounce, HowLongToBeat search after a token-only auth handshake, category sort via the chip bar not re-sorting the game list, and the redundant PICO-8 file extension in SystemDatabase.json
  • Bump marketing version to 1.17.0 and build number to 43 across project.yml, both Info.plists, and docs/_config.yml.
