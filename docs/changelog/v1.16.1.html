Changelog / v1.16.1

v1.16.1

October 23, 2026

This release fixes shader settings reverting across app updates (issue #41), plus an input fix for XPC-hosted cores and a smart-category display fix.

Highlights

  • Shader settings now survive app updates: The per-system shader selection (and per-system core default, visibility, and custom names) is no longer wiped when the app updates. Previously, any release that shipped an updated system database deleted the local settings cache, and every system fell back to its bundled default — shader selections quietly reverted to CRT Classic (issue #41). Note: if v1.16.0 already reset your selections, set them once more — from now on they persist.
  • Slang shader selections are more resilient: Slang presets are stored as absolute paths, which stopped resolving when the app bundle moved or the bundled slang-shaders tree changed between versions. The launcher now re-resolves those paths against the current install, so a stored slang selection keeps working after an update or a move of the app.
  • Input fix for XPC-hosted cores: When a core runs in the XPC service without shared memory, opening the game toolbar could leave analog sticks and analog buttons stuck at their last value (the same stuck-input class the toolbar combo fix in v1.16.0 addressed). All inputs are now fully released for that configuration too.
  • Smart categories — Systems sheet matches real membership: In a multi-system smart category that follows newly activated systems, a system that became active after the category was saved showed as disabled in the Systems sheet even though its games were members. The sheet now shows its true state.

Detailed Changes

  • Systems database — the local SystemDatabase.json cache is merged with the bundled database on every launch instead of being deleted when the bundled copy changes; the merge keeps bundled data as the source of truth and preserves user choices (per-system shader preset, default core, visibility, custom name and icon)
  • Slang — added a stored-path resolver that falls back to matching the path under the slang-shaders root when the exact stored path no longer exists; applied to game launch, saved custom presets, and display names
  • ShaderManager — resetting to the default shader now invalidates any in-flight slang chain prepare, so a stale background compile can no longer install over a freshly launched game's shader
  • XPC input — clearAllJoypadInputs now also zeroes analog sticks and analog buttons through the XPC proxy, matching the shared-memory and in-process paths
  • Smart categories — smartSystemEnabled mirrors smartMember for categories with smartFollowsNewSystems: only the disabled list rules a system's state
  • Bump marketing version to 1.16.1 and build number to 42 across project.yml, both Info.plists, and docs/_config.yml.
