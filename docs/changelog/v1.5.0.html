Changelog / v1.5.0

v1.5.0

July 1, 2026

Major release introducing streaming and recording, broad SDL controller support, ~1800 new slang shaders, training mode improvements with new frame data, and box art region selection.

Highlights

  • Streaming & Recording: Stream and record gameplay directly from TruchiEmu — no external tools needed. Supports Twitch, YouTube, Custom RTMP endpoints, and local recording (with shaders or raw)
  • SDL Controller Support: Expanded controller compatibility — anything that can connect to a Mac should now show up
  • Slang Shaders: About 1800 new slang shaders supported. Some may still fail; work continues on this
  • Training Mode Improvements: Improved move list display and overlay functionality with new frame data for Eternal Champions, Clay Fighter, Dragon Ball Z, TMNT Tournament Fighters, Virtua Fighter 2 vs Tekken 2, and Yu Yu Hakusho: Sunset Fighters
  • Box Art Region Selection: Download box art with region selection for game covers
  • macOS Game Mode: Activated automatically during full-screen gameplay
  • Settings Improvements: Settings improvements all around, plus many under-the-hood stabilization and UI/UX improvements

Detailed Changes

  • Added streaming service with Twitch, YouTube, and Custom RTMP support
  • Added local recording with shader or raw output
  • Added streaming UI to settings
  • Added share button functionality for streaming
  • Expanded SDL controller support with mappings for previously unsupported devices
  • Added support for ~1800 slang shaders via the librashader pipeline
  • Improved training mode overlay with refined move list display
  • Added new training mode frame data: Eternal Champions, Clay Fighter, Dragon Ball Z, TMNT Tournament Fighters, Virtua Fighter 2, Tekken 2, Yu Yu Hakusho: Sunset Fighters
  • Added box art download functionality with region selection
  • Added macOS Game Mode auto-activation during full-screen gameplay
  • Updated Portuguese translations with new settings and features
  • Refactored shader specifications for clarity
  • Enhanced shader documentation with new features and improved descriptions
  • Under-the-hood stabilization, performance, and UI/UX improvements throughout
