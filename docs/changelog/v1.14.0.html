Changelog / v1.14.0

v1.14.0

September 23, 2026

This release makes save states survive database loss and re-adding games with stable game identity and orphan repair, turns TV mode fast scroll into a smooth carousel with an icon-only system row and external-display prompt, adds reverse-holo foil parity with a hue control, ships a new CRT Pittman shader, and adds a titlebar notification ticker with contrast-safe playful buttons.

Highlights

  • Stable game identity: Save states now survive database loss and re-adding games. A stable key (content hash first, filename stem fallback) replaces the random UUID, legacy keys merge on read, orphans auto-relink with manual repair, a new Orphaned Saves section in Save Manager offers single and bulk delete, and favorites/playtime/core choice/categories get an external metadata backup with a versioned one-shot migration.
  • TV mode carousel + icon row: L1/R1 and L2/R2 fast scroll runs as chained unit steps with overlapping linear motion and continuous center focus, the systems row goes icon-only with an enlarged center icon, system flights defer the games refresh to the drain with a fade-in, and TV mode prompts to move to an external display.
  • Reverse holo parity + hue slider: Denser rainbow foil with random-mode hue parity, corrected rainbow transparency and punch, and solid/background visibility, plus a hue slider control.
  • CRT Pittman shader: New CRTSim port with composite, mask, and bloom passes.
  • Titlebar notification ticker: Queued notification pills with icon spin in the titlebar.
  • Contrast-safe playful buttons: Computed button text for contrast safety, playful hover states, and deep selected fills; plus a playful delete confirm with instant box art, shake and bounce on arm.

Detailed Changes

  • Saves — stable game identity: save states survive database loss and re-add (content-hash key with filename-stem fallback, legacy key merge, orphan auto-relink plus manual repair, Orphaned Saves section with single and bulk delete, external metadata backup for favorites/playtime/core choice/categories, versioned one-shot migration)
  • TV mode — fast scroll as smooth carousel with edge-faded holo (chained unit steps, continuous center focus, deferred games refresh with fade-in, memoized counts, warmed-up icons); system row goes icon-only with enlarged center icon; prompt external display move while in TV mode
  • Holo FX — reverse foil parity: denser rainbow foil, random mode hue parity and slider, corrected rainbow transparency and punch, solid/background visibility
  • Shaders — new CRT Pittman shader: MinorKeyGames CRTSim port with composite, mask, and bloom passes
  • Notifications — titlebar notification ticker with queued pills and icon spin
  • UI — contrast-safe buttons with computed text, playful hover, deep selected fills; playful delete confirm with instant box art, shake and bounce on arm
  • Reliability — backup SwiftData store only on version or schema change; count XPC host logs in total log size and clear-all
  • Build fix — Release overload of TVPerfTrace.time now accepts the thresholdMs label so Release builds compile
  • Bump marketing version to 1.14.0 and build number to 37 across project.yml, both Info.plists, and docs/_config.yml.
