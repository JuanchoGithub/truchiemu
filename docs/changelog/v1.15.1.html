Changelog / v1.15.1

v1.15.1

September 28, 2026

This patch release groups Switch base games with their updates and DLC, fixes a game info hang, and logs Metal validation errors in the XPC service instead of aborting under suyu/MoltenVK.

Highlights

  • Switch updates and DLC grouping: Switch files are classified as base, update, or DLC via the suyu core's own FileSys classes (exact title IDs, including XCI), with ticket and filename fallback. Updates and DLC group under one library card with enable toggles in the detail view; direct launch of add-ons is blocked.
  • Game info hang fix: Adds an O(1) ROM index and moves save-state scans to the background after sampling showed a 17s main-thread burn when opening game info.
  • Metal validation in XPC service: Metal validation errors are logged instead of aborting, fixing crashes under suyu/MoltenVK.

Detailed Changes

  • Switch — group base games with updates and DLC (suyu FileSys title-ID classification with ticket and filename fallback, per-content enable toggles, blocked add-on launch)
  • Library — fix game info hang (O(1) ROM index, background save-state scans)
  • XPC — log Metal validation errors instead of aborting (suyu/MoltenVK)
  • About — credit CRTSim by J. Kyle Pittman
  • Bump marketing version to 1.15.1 and build number to 39 across project.yml, both Info.plists, and docs/_config.yml.
