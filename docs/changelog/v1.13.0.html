Changelog / v1.13.0

v1.13.0

September 11, 2026

This release adds a fourth Adaptive box art style that fits mixed portrait and landscape covers without cropping, keeps the guide sidebar position in memory with GameCube and SDL pad support, fixes TV mode to restore the previous grid/list/holo view mode, and fixes core download sheet selection and refresh errors.

Highlights

  • Adaptive box art style: A new fourth BoxType fits each game's art inside the card with a blurred fill, so mixed portrait/landscape covers are no longer trimmed by the forced per-system aspect. Card frames keep the system default aspect to preserve the uniform grid layout. Labels are localized across en/es/pt/ja.
  • Guide sidebar memory + GC/SDL pads: The guide sidebar keeps its position in memory, with support for GameCube and SDL pads.
  • TV mode restores view mode: TV mode now saves and restores the previous grid/list/holo mode instead of resetting it.
  • Core download sheet fixes: Core selection now works when no external binding exists, and refresh no longer shows a false noCoresFound error when cores are available.

Detailed Changes

  • Library grid — new Adaptive box art style for mixed-orientation covers (#36): system views offer a fourth BoxType that renders each game's art fitted inside the card with a blurred fill; card frames keep the system default aspect; box type labels in the toolbar, per-system settings, and macOS menu are localized (en/es/pt/ja)
  • Guide — keep guide sidebar position in memory; add support for GC and SDL pads
  • TV mode — fix view mode save to restore previous grid/list/holo mode
  • Core download sheet — fix selection not working when no external binding exists (changed @Binding to @State with optional external binding sync); fix noCoresFound error after refresh by selecting a real available core from the refreshed list
  • Bump marketing version to 1.13.0 and build number to 36 across project.yml, both Info.plists, and docs/_config.yml.
