Move List & Fight Data

On-screen move notations and an extensive curated Fight Data library covering over 200 fighting games across NES, SNES, Genesis, Arcade, PlayStation, and more.

Overview

The Move List overlay is the on-screen quick-reference for fighting games. It displays each character's moves, special inputs, and combos as visual tokens — directional arrows, button glyphs, and special condition markers. Moves are automatically loaded based on the game being played, so you don't need to leave the screen or dig through a wiki.

What You Get

  • On-Screen Display: Move notations overlay the gameplay, categorized by type (specials, supers, command normals, throws)
  • Visual Tokens: Directional inputs, button combinations, and special conditions render as crisp visual tokens for at-a-glance reading
  • Fight Data Library: Over 200 curated fight data sets — Street Fighter II, Mortal Kombat, King of Fighters, Tekken, Samurai Shodown, Eternal Champions, Clay Fighter, Dragon Ball Z, Yu Yu Hakusho: Sunset Fighters, TMNT Tournament Fighters, and dozens more
  • Per-Game Move Sets: Moves auto-load based on the running game; no manual lookup needed
  • Search & Filter: Quickly find specific moves by name, input type, or character. Suffix-filter protocol narrows the matching set as you type
  • Move Names Toggle: Optionally show human-readable move names alongside the notation tokens — toggle from the overlay header
  • MoveForest Evaluation: An intelligent evaluator tracks moves and logic, so the overlay can flag which moves match what you just input

How to Use

  1. Launch a Fighting Game

    Start any supported fighting game. The Move List icon appears on the game overlay toolbar if fight data is available for the game.

  2. Open the Overlay

    Click the Move List icon or press the bound hotkey. The overlay appears beside the gameplay.

  3. Choose a Character

    Select the character you're playing from the overlay's character picker.

  4. Browse, Search, and Filter

    Browse the move list; click a move to highlight it; use the search field to filter by name. Toggle "Show Move Names" in the overlay header.

  5. Link to Training Mode

    Drop any move directly into a Training Mode sequence to drill it against a controllable dummy.

Configuration

Settings for the Move List overlay — default visibility, move-name display, font size — live under Settings → Move List. Per-system hotkeys are configurable in Settings → Hotkeys.
