Move List Overlay

The Move List Overlay displays fighting game move notations on-screen during gameplay, with per-game move sets, visual tokens for directional inputs, and search functionality to quickly find any special move.

Service Overview

The Move List Overlay provides a heads-up display of move notations while you play fighting games. Move sets are defined per game using a visual token system that maps to standard arcade notation. The overlay supports multiple characters, common move categories, and instant search, so you never have to alt-tab to look up a move again.

Core Features

  • Visual Tokens: Directional inputs are displayed as arcade-style arrows and button tokens for instant recognition
  • Per-Game Move Sets: Move data is defined per game with character-specific move lists
  • Common Movesets: Shared move categories like throws, target combos, and universal mechanics are grouped together
  • Search & Filter: Type to search for any move by name, or filter by move type (specials, supers, normals, throws)
  • On-Screen Display: Overlay appears within the game window without disrupting gameplay
  • Character Selection: Switch between character move sets when using games with multiple fighters

For implementation details, see the Developer Guide.

How to Use

Opening the Move List

  1. Launch a Fighting Game

    Start any supported fighting game from your library.

  2. Open Move List

    From the game toolbar, click the Move List icon or press the configured hotkey to open the overlay.

  3. Browse by Character

    If the game supports multiple characters, select the character you are playing from the dropdown at the top of the overlay.

  4. Search Moves

    Type in the search bar to filter moves by name. Results update in real-time as you type.

Move Notation Guide

The overlay uses standard fighting game notation with visual arrow tokens:

  • Directionals: Arrow icons for quarter-circle, dragon punch, charge, and 360 motions
  • Buttons: Labeled by the game's button names (LP, MP, HP, LK, MK, HK or A, B, C, X, Y, Z)
  • Modifiers: Hold, tap, charge, and simultaneous button press indicators
  • Categories: Special Moves, Super Arts, Target Combos, Throws, and Universal Mechanics
