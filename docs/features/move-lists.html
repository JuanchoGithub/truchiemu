Move List Overlay

The Move List Overlay displays fighting game move notations on-screen during gameplay, with per-game move sets, visual tokens for directional inputs, and search functionality to quickly find any special move.

Overview

The Move List Overlay puts each fighting game's move set right on top of the game window, in standard arcade notation, with arrow tokens and a search box. No more alt-tabbing to a guide mid-match — pick a character, scan the list, and get back to the fight.

What You Get

  • Visual Tokens: Directional inputs render as arcade-style arrows; button names use the game's own labels (LP, MP, A, B, etc.)
  • Per-Game Move Sets: Each game has its own move data, broken down by character
  • Grouped Categories: Specials, Supers, Throws, Target Combos, and Universal Mechanics are grouped so you can scan to the part you want
  • Search & Filter: Type a move name to find it instantly, or filter the list to a single category
  • On-Screen, Not Intrusive: The overlay sits over the game window without blocking the action
  • Character Switching: For games with multiple fighters, swap between character move sets from the dropdown

How to Use

Opening the Move List

  1. Launch a Fighting Game

    Start any supported fighting game from your library.

  2. Open Move List

    From the game toolbar, click the Move List icon or press the configured hotkey to open the overlay.

  3. Browse by Character

    If the game supports multiple characters, select the character you are playing from the dropdown at the top of the overlay.

  4. Search Moves

    Type in the search bar to filter moves by name. Results update in real-time as you type.

Move Notation Guide

The overlay uses standard fighting game notation with visual arrow tokens:

  • Directionals: Arrow icons for quarter-circle, dragon punch, charge, and 360 motions
  • Buttons: Labeled by the game's button names (LP, MP, HP, LK, MK, HK or A, B, C, X, Y, Z)
  • Modifiers: Hold, tap, charge, and simultaneous button press indicators
  • Categories: Special Moves, Super Arts, Target Combos, Throws, and Universal Mechanics
