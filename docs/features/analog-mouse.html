Analog Mouse Support

Use your gamepad's analog sticks to control the mouse cursor in DOS and ScummVM games — with D-pad as arrow keys, configurable button mapping for clicks, and per-system/per-game overrides.

Overview

DOS and ScummVM games often need a mouse: point and click, drag, drop, or drop objects. With Analog Mouse, you don't need a real mouse at hand — the left analog stick moves the cursor; the right stick gives you precise 1/5-speed control; the D-pad sends arrow keys; Start sends Enter; Select sends Space.

What You Get

  • Analog Stick to Mouse: The primary analog stick (left or right — configurable handedness) moves the cursor at 60fps with adjustable sensitivity
  • Secondary Stick for Fine Control: The secondary analog stick moves the mouse at 1/5 speed for precise pixel targeting
  • D-Pad as Keyboard: D-pad sends arrow keys; Start sends Enter; Select sends Space
  • Configurable Button Mapping: Assign left, right, and middle mouse click to any gamepad button
  • Per-System & Per-Game: Independent settings for DOS and ScummVM, with per-game overrides
  • Auto-Release with Game Guide: Input capture releases when you open the Game Guide sidebar (so you can use the mouse in hints/walkthroughs) and resumes when it closes

How to Use

  1. Enable Analog Mouse

    Open Settings → Analog Mouse. Toggle per-system enable for DOS, ScummVM, or both.

  2. Set Stick Handedness

    Choose whether the left or right stick is the "primary" (fast) cursor; the other becomes the "fine" control stick.

  3. Tune Sensitivity & Deadzone

    Adjust sensitivity multiplier and stick dead-zone in the same panel. Use the secondary stick for fine targeting.

  4. Map Mouse Buttons to Gamepad

    Click a mouse-button field, then press a gamepad button to assign. Repeat for left, right, and middle click.

  5. Per-Game Overrides

    From the Game Detail view, click Game → Analog Mouse Override to set per-game settings that override the system default.

Tips

Comfort tip: Use the secondary stick for precise pixel targeting, and map mouse buttons to comfortable gamepad buttons for your preferred play style. If you're stuck in a puzzle, open the Game Guide via Cmd+J — mouse capture auto-releases so you can interact with the guide, and re-engages when you close it.

Related Features

Controller Support

Analog Mouse integrates with the controller driver layer (GCController + SDL2).
