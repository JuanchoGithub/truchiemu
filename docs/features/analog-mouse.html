Analog Mouse Support

TruchiEmu provides analog mouse and keyboard capture for DOS and ScummVM games, enabling classic point-and-click adventures and DOS titles with full mouse control and configurable sensitivity.

Service Overview

The analog mouse system captures physical mouse and keyboard input and translates it for DOS and ScummVM emulation cores. When a game window is active, the mouse is captured and decoupled from the system cursor, delivering raw delta movement directly to the emulated environment. Keyboard input is also routed through the capture layer to support adventure game hotkeys and text entry.

Core Features

  • Full Mouse Capture: Mouse is captured within the game window with pointer hiding and raw delta tracking for precise cursor control
  • Keyboard Input: Full keyboard input routing for DOS commands, ScummVM hotkeys, and text entry fields
  • Sensitivity & Acceleration: Adjustable pointer speed and acceleration curves to match your preferred feel
  • Per-Game Configuration: Save sensitivity and mapping settings on a per-game basis for different titles
  • Automatic Detection: Mouse capture is automatically enabled when a DOS or ScummVM game is launched
  • Escape to Release: Press Escape to release mouse capture, click inside the game window to re-capture

For implementation details, see the Developer Guide.

How to Use

Basic Usage

  1. Launch a DOS or ScummVM Game

    Mouse capture activates automatically when you launch a supported game. The system cursor is hidden and mouse movements are routed to the emulated environment.

  2. Adjust Sensitivity

    Go to Settings → Analog Mouse and use the sensitivity slider to adjust pointer speed. Changes take effect immediately and can be tested in-game.

  3. Release Capture

    Press Escape to release the mouse cursor back to the system. Click inside the game window to re-capture the mouse.

Per-Game Configuration

  1. Open Game Settings

    While a game is running, access the game toolbar and select Input → Analog Mouse Settings to configure per-game overrides.

  2. Adjust Sensitivity

    Set the horizontal and vertical sensitivity independently. Some adventure games benefit from different X/Y ratios.

  3. Enable Acceleration

    Toggle mouse acceleration for faster cursor movement at higher physical speeds. Disable for pixel-perfect precision in point-and-click adventures.

  4. Save Profile

    Your settings are automatically saved and restored the next time you launch the same game.
