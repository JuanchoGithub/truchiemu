Analog Mouse Support

TruchiEmu lets you use your gamepad's analog sticks to control the mouse cursor in DOS and ScummVM games, with configurable buttons for mouse clicks and D-pad for keyboard inputs.

Service Overview

The analog mouse system translates your controller's thumbstick deflection into mouse cursor movement for point-and-click games in DOS and ScummVM. This lets you navigate menus, click on objects, and interact with game worlds using a gamepad instead of a physical mouse. The feature is configurable per system (DOS, ScummVM) and supports per-game overrides.

How It Works

  • Analog Stick to Mouse: The primary analog stick (left or right, user-selectable) is sampled at 60fps and its deflection is translated into mouse delta values
  • Secondary Stick for Fine Control: The secondary analog stick moves the mouse at 1/5 speed for precise cursor placement
  • D-Pad as Keyboard: D-pad sends arrow key inputs (Up/Down/Left/Right), Start sends Enter, Select sends Space
  • Configurable Button Mapping: Assign left click, right click, and middle click to any gamepad button (A, B, X, Y, L1, R1, L2, R2, L3, R3, Start, Select)

Core Features

  • Sensitivity Control: Adjust pointer speed from 0.1x to 5.0x to match your preferred feel
  • Dead Zone Adjustment: Set the dead zone threshold (0.00–0.50) to eliminate stick drift
  • Stick Selection: Choose which analog stick (left or right) controls the mouse
  • Per-System Settings: Independent configuration for DOS and ScummVM
  • Per-Game Override: Toggle analog mouse on or off for individual ROMs
  • Live Visualizer: Real-time stick position display with dead zone overlay in settings

For implementation details, see the Developer Guide.

How to Use

Basic Setup

  1. Open Analog Mouse Settings

    Go to Settings → Analog Mouse to configure system-level preferences for DOS and ScummVM.

  2. Enable the Feature

    Toggle analog mouse on for DOS, ScummVM, or both. The feature is disabled by default.

  3. Adjust Sensitivity

    Use the sensitivity slider (0.1x–5.0x) to set how fast the cursor moves in response to stick deflection.

  4. Set Dead Zone

    Adjust the dead zone to prevent unwanted cursor movement from stick drift. The live visualizer shows your current stick position relative to the dead zone.

  5. Choose Your Stick

    Select which analog stick (left or right) controls the mouse. The other stick provides fine control at reduced speed.

  6. Map Mouse Buttons

    Assign left click, right click, and middle click to your preferred gamepad buttons.

Per-Game Override

  1. Open Game Detail

    Select a DOS or ScummVM ROM in your library and open its detail view.

  2. Toggle Analog Mouse

    Use the Analog Mouse toggle to override the system default for this specific game.

  3. Reset to Default

    Use the Reset button to clear the per-game override and revert to the system setting.

During Gameplay

  • The analog stick moves the cursor — push gently for precise movement, full deflection for quick navigation
  • The secondary stick offers 1/5 speed for pixel-perfect placement
  • D-pad sends arrow keys (useful for menu navigation in DOS games)
  • Start acts as Enter, Select acts as Space
  • Mapped buttons perform left/right/middle click actions
