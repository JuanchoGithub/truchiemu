Analog Mouse Support

TruchiEmu lets you use your gamepad's analog sticks to control the mouse cursor in DOS and ScummVM games, with configurable buttons for mouse clicks and D-pad for keyboard inputs.

Overview

Analog Mouse Support lets you play DOS and ScummVM point-and-click adventures with a gamepad instead of a mouse. The left stick moves the cursor, the right stick does fine adjustment, the D-pad sends arrow keys, and you can map click actions to any face button. Settings can be tuned per system and overridden per game.

How It Works

  • Analog Stick to Mouse: The primary analog stick (left or right, your choice) moves the cursor based on how far you push it
  • Secondary Stick for Fine Control: The other stick moves the cursor at 1/5 speed for precise placement
  • D-Pad as Keyboard: D-pad sends arrow keys, Start sends Enter, Select sends Space — handy for menu navigation in DOS games
  • Configurable Button Mapping: Assign left, right, and middle click to any face or shoulder button (A, B, X, Y, L1, R1, L2, R2, L3, R3, Start, Select)

Tuning Options

  • Sensitivity: Adjust pointer speed from 0.1x to 5.0x to match your preferred feel
  • Dead Zone: Set a threshold (0.00–0.50) to filter out stick drift
  • Stick Selection: Choose which analog stick controls the mouse
  • Per-System Settings: Configure DOS and ScummVM independently
  • Per-Game Override: Enable or disable analog mouse for an individual game without changing the system default
  • Live Visualizer: See your stick position and dead zone in real time while you adjust

How to Use

Basic Setup

  1. Open Analog Mouse Settings

    Go to Settings → Analog Mouse to configure system-level preferences for DOS and ScummVM.

  2. Enable the Feature

    Toggle analog mouse on for DOS, ScummVM, or both. The feature is disabled by default.

  3. Adjust Sensitivity

    Use the sensitivity slider (0.1x–5.0x) to set how fast the cursor moves in response to stick deflection.

  4. Set Dead Zone

    Adjust the dead zone to prevent unwanted cursor movement from stick drift. The live visualizer shows your current stick position relative to the dead zone.

  5. Choose Your Stick

    Select which analog stick (left or right) controls the mouse. The other stick provides fine control at reduced speed.

  6. Map Mouse Buttons

    Assign left click, right click, and middle click to your preferred gamepad buttons.

Per-Game Override

  1. Open Game Detail

    Select a DOS or ScummVM ROM in your library and open its detail view.

  2. Toggle Analog Mouse

    Use the Analog Mouse toggle to override the system default for this specific game.

  3. Reset to Default

    Use the Reset button to clear the per-game override and revert to the system setting.

During Gameplay

  • The analog stick moves the cursor — push gently for precise movement, full deflection for quick navigation
  • The secondary stick offers 1/5 speed for pixel-perfect placement
  • D-pad sends arrow keys (useful for menu navigation in DOS games)
  • Start acts as Enter, Select acts as Space
  • Mapped buttons perform left/right/middle click actions
