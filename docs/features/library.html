Library Management

TruchiEmu's library management system organizes your game collection with metadata enrichment, multi-source box art, DAT/CRC32 identification, and post-scan automation — including iCloud dataless-placeholder materialization and ROM-removal notifications.

Overview

The Library is where your games live. Point TruchiEmu at your ROM folders and it does the rest: it figures out which system each file belongs to, identifies the game, pulls in a title and description, and grabs the box art. Browse by system, favorite, recently played, or any of the saved categories you've made.

What It Does For You

  • CRC32 Identification: Hardware-accelerated CRC32 hashing (via zlib) against DAT databases — not just file extensions — so ROMs are accurately identified regardless of filename
  • MAME Rejection Tracking: MAME identification uses rejection tracking and a refined scoring algorithm; non-game MAME entries are filtered out automatically
  • LaunchBox Metadata Service: Background metadata enrichment pulls in descriptions, release dates, publisher, player count, and genre. Platform overrides improve match scoring across systems
  • Box Art Priority: Box art is fetched from ScreenScraper and Libretro CDN with configurable priority; an interactive Box Art Picker lets you swap alternative artwork per game
  • PPSSPP Asset Downloads: PPSSPP-specific assets are downloaded and applied automatically when a PSP ROM is detected
  • Box Art Region Selection: Pick preferred region for box art per game or system-wide; thumbnails are generated, cached, and resampled efficiently
  • iCloud Materialization: iCloud dataless-placeholders are materialized on access so ROMs stored in iCloud display correctly — no more zero-byte stubs in your library list
  • ROM-Removal Notifications: When ROMs are removed from watched folders, the library updates automatically and posts a notification so you don't have to manually rescan
  • Organized Your Way: Browse by system, favorites, recently played, last added, custom categories, or RetroAchievements-support
  • Grid or List: Switch between the cover-art grid (with zoom slider) and the compact list view
  • Search & Filters: Type-to-search in the main window (multi-term search); quick filter chips for "no box art", "never played", "unidentified", "multiplayer", "genre"
  • Search-Aware Sidebar: Smart collection rows in SystemSidebarView respect the active search query — hidden systems stay hidden when you filter
  • RetroAchievements Aware: Games with achievements are flagged and can be filtered to just those

Post-Scan Automation

TruchiEmu doesn't just scan — after the scan, LibraryAutomationCoordinator runs a post-scan pipeline: identify → enrich metadata → download art. Pipeline respects RunningGamesTracker so heavy post-scan work pauses during gameplay.

Background performance: The pipeline runs serially with a 2-second warm-up delay so it never competes with active gameplay CPU. A separate MetadataSyncCoordinator handles background LaunchBox sync with 1-at-a-time concurrency; it also pauses during gameplay.

Identification Pipeline

  1. Scan

    ROMScanner (a Swift actor) scans directories recursively, filters by extension, and bulk-identifies MAME files in one pass.

  2. Hash & Match

    ROMIdentifierService computes CRC32 in parallel (4-way semaphore for I/O throttling) and matches against DAT databases. ROMIdentifier uses weighted scoring: magic headers > unique extensions > filename patterns > path context.

  3. Metadata Enrichment

    LaunchBox Metadata Service enriches identified games with description, release date, publisher, player count, and genre.

  4. Box Art Download

    BoxArtService fetches art from ScreenScraper and Libretro CDN per your priority. Honor region preferences. BoxArtThumbnailService generates and caches thumbnails for fast grid rendering.

  5. Genre Categorization

    Genres are populated from the metadata and exposed as filter chips in the library sidebar.

Managing Library Folders

Adding Folders

  • Setup Wizard: Add one or more folders during first-launch setup
  • Library Toolbar: Click the folder.badge.plus button at the top of your library
  • Menu Bar: Games → Add ROM Folder (Shift+Cmd+O)
  • Settings: Settings → Library → Library Folders, click "Add Folder"

Rescanning & Rebuild

  • Full Rescan: Settings → Library → Maintenance → "Full Library Rescan" (or Shift+Cmd+R)
  • Per-Folder Refresh: Each folder has a "Refresh" button (and a "Rebuild" option with multiple strategies)
  • Per-System Refresh: Right-click a system in the sidebar and choose "Refresh"
  • Hidden MAME Files: Filtered non-game MAME entries live under a "Hidden MAME Files" sidebar entry, not in your main grid

Genres & Categories

Browse by genre using the genre filter chip (powered by LaunchBox metadata), or create custom categories with names, SF Symbol icons, custom uploaded icons, and per-category colors.

  • Custom Categories: Drag-and-drop games into custom categories, or use the right-click context menu
  • Favorites: Right-click → "Add to Favorites" for quick access
  • Recently Played: Auto-tracked based on launch history
  • Hidden Games: Right-click → "Hide Game" to keep main grid uncluttered
  • Genre Management: Settings → Genres provides per-genre controls

Related Features

Save State System

Save states can be viewed and managed from the game detail view as a visual grid.

RetroAchievements

Games with RetroAchievements support are flagged in the library and filterable via the RA sidebar entry. The Game Detail view shows the RA hash for the game.

TV Mode

TV Mode uses the same library — your categories, filters, and box art apply identically.
