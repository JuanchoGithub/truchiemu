Library Management

TruchiEmu's library management system organizes your game collection with metadata enrichment, artwork downloads, and system-based categorization.

Service Overview

The Library Management service helps organize and discover your game collection. It identifies games using libretro DAT databases, then enriches metadata from multiple sources including LibretroMetadataLibrary, Progetto-SNAPS, and LaunchBox GamesDB. It downloads box art and groups titles by system.

Library data flow from ROM scanning to metadata enrichment and UI display

Core Features

  • Automatic Game Detection: ROM system identification using weighted scoring of magic headers, file extensions, filename patterns, and path context, followed by CRC32-based game matching against libretro DAT databases
  • Metadata Enrichment: Game info sourced from multiple providers: local games.xml, libretro DAT databases, LibretroMetadataLibrary, Progetto-SNAPS, and LaunchBox GamesDB
  • Artwork Management: Automatic download of box art from Libretro Thumbnails CDN, with optional fallback to ScreenScraper and LaunchBox GamesDB
  • Library Organization: Games organized by system, favorites, recently played, last added, hidden games, custom categories, and RetroAchievements. Filter chips and genre filtering provide additional refinement.
  • Grid and List Views: Switch between card-based grid and compact list views
  • Search and Filters: Multi-term search, filter chips (no box art, never played, unidentified, multiplayer), genre filtering, and sort options
  • RetroAchievements Integration: Games matched with RetroAchievements are flagged in the library and filterable via the RetroAchievements view

For implementation details, see the Developer Guide.

Step-by-Step Configuration Guide

Initial Library Setup

  1. Add ROM Directories

    Add ROM directories from the Library sidebar (button folder.badge.plus) or the initial onboarding wizard. TruchiEmu supports recursive scanning of subdirectories.

  2. Start Library Scan

    Initiate a scan from the Library view. The scanner identifies ROM systems, then automatically runs post-scan automation: CRC32-based game identification, metadata enrichment, and box art downloads. No manual scan configuration is needed — scanning automatically filters non-ROM file types and identifies systems by extension and file headers.
