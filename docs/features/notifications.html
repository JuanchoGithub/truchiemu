Notification System

TruchiEmu's notification system delivers non-intrusive in-game pills and maintains a history panel for controller connection alerts, achievement unlocks, save confirmations, and other important events.

Overview

TruchiEmu shows you what's happening without getting in the way. Small notification pills pop up briefly in the corner when something matters (a controller connects, a save state is captured, an achievement unlocks), then quietly disappear. The bell icon in the library toolbar holds a full history of recent notifications, in case you missed one.

What Gets Notified

  • Controller Events: Connect, disconnect, and low-battery warnings
  • Game Actions: Save state saved, screenshot taken, and other confirmations so you know a hotkey worked
  • System Alerts: Background checks like updates and core downloads

How They Look

  • Corner Pills: Rounded, color-coded notifications that appear briefly and auto-dismiss
  • Color Coding: Info, success, warning, and error types each have their own color so you can tell at a glance
  • Localized Text: Notification copy follows your UI language
  • Full History: Click the bell icon in the library toolbar to browse everything that fired recently, with timestamps

How to Use

Automatic Notifications

  1. Connect a Controller

    When a controller is connected or disconnected, a notification pill appears in the game window showing the controller name and connection status.

  2. Perform Game Actions

    Save states, screenshots, and other actions trigger confirmation notifications. For example, saving a state shows "Save state saved to slot 3" briefly.

Notification History

  1. Open History Panel

    Click the bell icon in the library toolbar to open the history panel.

  2. Browse Past Notifications

    The history panel displays all recent notifications with timestamps, categorized by type. Click any entry to see details.

  3. Clear History

    Use the Clear button to dismiss all notifications from the history panel.

Related Features

Controller Support

Controller connection and disconnection events trigger notification pills.

RetroAchievements

Achievement unlock events are displayed as notifications during gameplay.
