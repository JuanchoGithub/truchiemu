Notification System

TruchiEmu's notification system delivers non-intrusive in-game pills and maintains a history panel for controller connection alerts, achievement unlocks, save confirmations, and other important events.

Service Overview

The notification system provides a consistent way to surface information to the user without interrupting gameplay. Notifications appear as small, auto-dismissing pills overlaid on the game window and are also recorded in a centralized history panel for later review. Messages are fully localized through the app's translation system, and notification types include controller events, game state changes, and system alerts.

Core Features

  • Non-Intrusive Pills: Small, rounded notifications appear briefly in the corner of the game window and auto-dismiss
  • Controller Alerts: Notifications when a controller connects, disconnects, or has low battery
  • Game Action Confirmations: Visual feedback for save state operations, screenshot captures, and other in-game actions
  • Notification History: Browse a chronological list of all recent notifications from the bell icon in the library toolbar
  • Localized Messages: All notification text is fully translated and respects the current UI language
  • Categorized Display: Notifications are color-coded by type: info, success, warning, and error

For implementation details, see the Developer Guide.

How to Use

Automatic Notifications

  1. Connect a Controller

    When a controller is connected or disconnected, a notification pill appears in the game window showing the controller name and connection status.

  2. Perform Game Actions

    Save states, screenshots, and other actions trigger confirmation notifications. For example, saving a state shows "Save state saved to slot 3" briefly.

Notification History

  1. Open History Panel

    Click the bell icon in the library toolbar to open the history panel.

  2. Browse Past Notifications

    The history panel displays all recent notifications with timestamps, categorized by type. Click any entry to see details.

  3. Clear History

    Use the Clear button to dismiss all notifications from the history panel.

Related Services

Controller Support

Controller connection and disconnection events trigger notification pills.

RetroAchievements

Achievement unlock events are displayed as notifications during gameplay.
