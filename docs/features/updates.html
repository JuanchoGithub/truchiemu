Update Checker

TruchiEmu includes a built-in update checker that periodically checks for new versions in the background, displays in-app changelogs, and notifies you when updates are available.

Service Overview

The Update Checker monitors GitHub releases for new versions of TruchiEmu. It performs periodic background checks without interrupting your workflow and displays a notification when a new version is available. The integrated changelog viewer lets you read release notes before deciding to update, and a version history panel shows all past releases. The checker respects your privacy by only connecting to GitHub's public API and performing checks at configurable intervals.

Core Features

  • Periodic Background Checks: Automatically checks for updates at configurable intervals without disrupting gameplay
  • In-App Changelog: View detailed release notes for any available or past version directly in the app
  • Update Notifications: A notification pill appears when a new version is detected, with a link to download
  • Version History: Browse all past releases with dates, version numbers, and changelogs
  • Manual Check: Trigger an immediate update check at any time from the app menu
  • Current Version Display: See the currently installed version alongside the latest available version

For implementation details, see the Developer Guide.

How to Use

Checking for Updates

  1. Manual Check

    Select TruchiEmu → Check for Updates from the menu bar to manually trigger an update check. The checker contacts GitHub and displays the result immediately.

  2. Automatic Check

    Updates are checked automatically on launch and periodically in the background. When a new version is found, a notification appears with update details.

Viewing the Changelog

  1. Open Updates Panel

    Navigate to Settings → About to open the update checker panel.

  2. View Changelog

    The panel shows the current version and latest available version. Click "View Changelog" to read release notes for the latest version.

  3. Version History

    Scroll down to see the full version history with release dates, version numbers, and changelogs for all past releases.

Related Services

The Update Checker is a standalone service with no direct dependencies on other features.
