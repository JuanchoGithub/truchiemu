Update Checker

TruchiEmu includes a built-in update checker that periodically checks for new versions in the background, displays in-app changelogs, and notifies you when updates are available.

Overview

TruchiEmu quietly keeps an eye out for new versions. It checks for releases in the background and pops up a notification when there's something new. You can read the changelog right in the app before deciding to update, and browse a version history to see what changed over time. The checker only talks to GitHub's public release API no analytics, no tracking.

What You Get

  • Background Checks: TruchiEmu checks for updates on launch and periodically, without interrupting your play session
  • In-App Changelog: Read release notes for the current version or any past release without leaving the app
  • Update Notifications: A pill appears when a new version is out, with a link straight to the download
  • Version History: Browse all past releases with their dates and changelogs
  • Manual Check: Want to know right now? Pull up the menu and trigger a check on demand
  • Current vs. Latest: The About panel shows your installed version alongside the latest available

How to Use

Checking for Updates

  1. Manual Check

    Select TruchiEmu → Check for Updates from the menu bar to manually trigger an update check. The checker contacts GitHub and displays the result immediately.

  2. Automatic Check

    Updates are checked automatically on launch and periodically in the background. When a new version is found, a notification appears with update details.

Viewing the Changelog

  1. Open Updates Panel

    Navigate to Settings → About to open the update checker panel.

  2. View Changelog

    The panel shows the current version and latest available version. Click "View Changelog" to read release notes for the latest version.

  3. Version History

    Scroll down to see the full version history with release dates, version numbers, and changelogs for all past releases.

Related Features

The Update Checker stands on its own and works the same for every install.
