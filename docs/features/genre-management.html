Genre Management

Organize your game library by genre with granular visibility controls, automatic genre detection from metadata, and fully localized genre names.

Overview

Genre Management helps you slice your library by what kind of game each title is. Genres are read from the game metadata automatically, displayed in your current UI language, and you control which ones show up in the sidebar and library views. Click any genre to filter the library to just that category.

What You Can Do

  • Show or Hide Genres: Toggle any genre to control which categories appear in your library
  • Filter the Library by Genre: Click any genre in the sidebar to see only those games
  • Automatic Detection: Genres are picked up from game metadata as the library is scanned — no manual tagging needed
  • Localized Names: Genre labels follow your UI language
  • Genre Groups: Related genres (e.g., Action, Beat-em-up, Hack and Slash) can be grouped under a parent for a tidier sidebar
  • Game Counts: Each genre shows how many games it contains, so you can see at a glance where the bulk of your collection sits

How to Use

Managing Genres

  1. Open Genre Settings

    Navigate to Settings → Library → Genre Management to view all detected genres.

  2. Toggle Visibility

    Use the toggle switch next to each genre to show or hide it in the library sidebar. Hidden genres still apply to games but are not displayed as filter options.

  3. Reorder Genres

    Drag and drop genres to reorder them in the sidebar display.

Browsing by Genre

  1. Open Library

    Navigate to the Library view. The sidebar shows all visible genres.

  2. Select a Genre

    Click any genre in the sidebar to filter the library to show only games matching that genre.

  3. Clear Filter

    Click the active genre again or select "All Games" to remove the filter and show the full library.
