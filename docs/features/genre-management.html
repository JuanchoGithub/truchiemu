Genre Management

Organize your game library by genre with granular visibility controls, automatic genre detection from metadata, and fully localized genre names.

Service Overview

The Genre Management system allows you to organize your game library by genre categories. Genres are automatically detected from game metadata during library scanning, and you can control which genres appear in the library sidebar and browse views. Genre names are fully localized and display in the current UI language. This system integrates with the library's category filtering to provide a complete organizational workflow.

Core Features

  • Show/Hide Genres: Toggle individual genres on or off to control which categories appear in your library
  • Filter by Genre: Click any genre in the sidebar to filter the library to only games matching that category
  • Automatic Detection: Genres are assigned automatically from metadata during the library scan and enrichment pipeline
  • Localized Names: Genre display names are translated and shown in the current UI language
  • Genre Groups: Related genres can be grouped under parent categories for cleaner organization
  • Game Count: Each genre displays the number of games it contains for at-a-glance browsing

For implementation details, see the Developer Guide.

How to Use

Managing Genres

  1. Open Genre Settings

    Navigate to Settings → Library → Genre Management to view all detected genres.

  2. Toggle Visibility

    Use the toggle switch next to each genre to show or hide it in the library sidebar. Hidden genres still apply to games but are not displayed as filter options.

  3. Reorder Genres

    Drag and drop genres to reorder them in the sidebar display.

Browsing by Genre

  1. Open Library

    Navigate to the Library view. The sidebar shows all visible genres.

  2. Select a Genre

    Click any genre in the sidebar to filter the library to show only games matching that genre.

  3. Clear Filter

    Click the active genre again or select "All Games" to remove the filter and show the full library.
