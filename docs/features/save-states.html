Save State System

TruchiEmu's save state system captures and restores emulator state at any point, with an organized slot-based interface and visual management.

Service Overview

The Save State system captures the emulator's internal state (RAM, CPU registers, and core-specific data) so you can save and restore gameplay at any moment. Not all cores support save states. Save states are managed through the game window interface.

Save state capture and restore pipeline with thumbnail generation and backup

Core Features

  • Instant Captures: Save and load at any point during gameplay
  • Slot Banking: 10 numbered save slots (0–9) plus an auto-save slot (load-only)
  • Automatic Naming: Save states are organized by game and timestamp
  • Thumbnail Previews: Each save state captures a 320×240 PNG screenshot for visual browsing
  • Progressive Save States: When enabled, each slot maintains a rotating history of up to 5 versions (default: 3). Disabled by default.
  • LZ4 Compression: Save states can be compressed using LZ4 (enabled by default). Compressed files use a TCS2 magic header.
  • Undo Load: After loading a save state, press Cmd+Z to undo and return to the state before the load
  • Auto-Save on Exit: Saves to the auto-save slot when closing a game (disabled by default)
  • Auto-Load on Start: Loads the auto-save slot on game launch (disabled by default)

For implementation details, see the Developer Guide.

Step-by-Step Configuration Guide

Basic Save State Usage

  1. Save During Gameplay

    While playing a game, access the save state menu from the game window toolbar or use the configured keyboard shortcut to save to the current slot. Progressive save states automatically cycle through available slots for quick consecutive saves.

  2. Load a Save State

    Open the save state browser to see all saved states for the current game. Click any entry to restore gameplay from that point.

  3. Manage Save Slots

    Use different save slots to maintain multiple save points for different playthroughs or challenges. Each slot stores a separate emulator state.
