Time Machine

Rewind, fast-forward, and slow-motion controls directly from the game toolbar. Retry that missed jump in an instant or study a frame-perfect sequence at any speed.

Overview

Time Machine captures short save-state deltas in a circular buffer and replays them on demand, giving you the same kind of "scrub" you'd expect from a video editor or a modern arcade-rerelease — all without ever leaving the game window.

What You Get

  • Rewind: Step backward through recent frames to retry a missed jump, a botched combo, or a fatal hit without reaching for a save state
  • Fast Forward: Skip slow dialogue, grinding, or long cutscenes while keeping audio pitched to playback speed
  • Slow Motion: Study frame-perfect sequences at reduced speed — ideal for fighting game combo practice or tricky platformer setups
  • Hardcore-Aware: When RetroAchievements Hardcore Mode is active, Time Machine is disabled alongside save states and cheats
  • Per-Core Compatibility: Some cores (e.g. Dolphin) with known crash issues on the rewind pipeline are gracefully excluded; Play! (PS2) save-state warnings surface clearly so you know before you trigger one

How to Use

  1. Enable Time Machine

    Open Settings → Time Machine and toggle Time Machine on. The Setup Wizard also offers this on first launch.

  2. Choose Buffer Depth

    Set the rewind buffer depth in seconds. Larger buffers consume more memory but let you rewind further back.

  3. Set Slow-Motion Ratio

    Choose a slow-motion playback speed like 0.5×, 0.25×, or 0.1×.

  4. Bind Hotkeys

    Bind rewind / fast forward / slow motion hotkeys in Settings → Hotkeys. Both keyboard and gamepad bindings are supported.

  5. Use It During Gameplay

    Trigger rewind / fast-forward / slow-motion during gameplay via the toolbar buttons or the bound hotkeys. The overlay shows the current Time Machine state and scrub position.

Restrictions

Hardcore Mode: Time Machine is blocked while RetroAchievements Hardcore Mode is active, just like save states, cheats, and rewind-specific slow motion.

Cores that aren't supported: The Time Machine pipeline requires savestate deltas; cores that the libretro ecosystem has warned against using with save states are gracefully excluded from the rewind pipeline, and the Play! (PS2) core surfaces an explicit warning before triggering save-state capture so you can back out.

Related Features

Save States

Time Machine reuses the same savestate pipeline that powers the visual Save State grid.

RetroAchievements

Hardcore Mode disables Time Machine alongside save states and cheats.
