Training Mode

TruchiEmu's Training Mode provides P2 automation tools for fighting games, letting you control the dummy player with configurable stance, guard, wake-up tech, reversal actions, sequence programming, and input recording.

Service Overview

The Training Mode system adds an on-screen overlay to fighting games with tools designed for practice and experimentation. It works by automatically injecting inputs for player 2, letting you configure the dummy's behavior to practice specific scenarios. The system integrates with the Move List overlay so you can select character moves and assign them to training sequences.

Core Features

  • Dummy Control: Configure P2 control mode (standby, human, stance guard, sequence), stance (stand, crouch, jump), guard (no block, all block, random block, first-hit block), wake-up tech (none, quick recovery, back roll), and reversal actions
  • Sequence Programming: Build a sequence of frame data cards for P2 to execute. Choose trigger conditions (continuous loop, on block, on hit), adjust frame profiles (1–5 frame leniency), and toggle auto-invert for facing direction
  • Input Recording (Tape Deck): Record P1 inputs into one of 4 tape slots and play them back as P2. Includes countdown before recording and full slot management
  • Input Display: Real-time visualization of P1 and P2 inputs rendered as move notation tokens with frame index tracking
  • FMD Monitor: Live progress tracking of active frame data sequences showing move name, frame progress, and trigger state
  • Reset Positions: Reset P2 to round start, left corner, right corner, or a custom save point with hotkey support
  • Move List Integration: Browse available characters and their moves directly from the training overlay, with one-tap linking to the Move List overlay

For implementation details, see the Developer Guide.

How to Use

Enabling Training Mode

  1. Launch a Fighting Game

    Start any supported fighting game from your library.

  2. Open Training Overlay

    From the game toolbar, click the Training Mode icon or press the configured hotkey to open the overlay panel.

  3. Enable Training

    Click the Enable Training button at the top of the overlay. Training mode will automatically join P2 into the game.

  4. Configure Dummy Behavior

    Use the Dummy tab to set P2's control mode, stance, guard, wake-up tech, and reversal action. Settings take effect immediately.

Programming Sequences

  1. Open the Sequence Tab

    Navigate to the Sequence tab in the training overlay.

  2. Add Cards

    Click the + button to add FMD moves (from the move list), delay cards (pause for a set number of frames), or tape blocks (play back a recorded input).

  3. Set Trigger Condition

    Choose when the sequence plays: continuously loop, on block, or on hit.

  4. Adjust Frame Profile

    Set the frame leniency (1 = strict, 5 = very lenient) to control how precisely P2 executes the sequence.

Recording Inputs

  1. Select a Tape Slot

    In the Recording tab, choose one of 4 tape slots to record into.

  2. Start Recording

    Press the record button. A 3-second countdown will appear, then recording begins.

  3. Play Back

    Assign the recorded tape to a tape block in the Sequence tab, or trigger playback via hotkey. P2 will replicate your recorded inputs.

Related Services

Move List Overlay

Character move data feeds directly into training mode for sequence programming and reversal actions.

Save State System

Custom reset positions use save state data to restore P1 and P2 to specific training scenarios.

Controller Support

Configure hotkeys for training mode controls like reset, record, and playback.
