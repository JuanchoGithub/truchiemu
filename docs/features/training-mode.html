Training Mode

TruchiEmu's Training Mode provides a dedicated practice overlay for fighting games with health regen, infinite meter, save state hotkeys, input display, and per-game profiles to help you level up your skills.

Service Overview

The Training Mode system adds an on-screen overlay to fighting games with tools designed for practice and experimentation. It works by hooking into emulated memory addresses to manipulate game state in real-time, giving you full control over the training environment. Per-game profiles store the memory addresses and settings for each title, so everything works automatically once configured.

Core Features

  • Health Regen: Automatically restore both player and opponent health bars when they reach zero, keeping practice sessions uninterrupted
  • Infinite Meter: Keep super, EX, and special meters maxed out for unlimited special move practice
  • Save State Hotkeys: Bind one-button save and load hotkeys for instant reset to practice positions
  • Input Display: On-screen visual showing your current directional and button inputs in real-time
  • Per-Game Profiles: Memory addresses and settings are saved per game for automatic detection on launch
  • Frame Data Display: View frame advantage, hitstun, and blockstun information during training sessions

For implementation details, see the Developer Guide.

How to Use

Enabling Training Mode

  1. Launch a Fighting Game

    Start any supported fighting game from your library.

  2. Open Training Overlay

    From the game toolbar, click the Training Mode icon or press the configured hotkey to open the training overlay.

  3. Configure Settings

    Toggle health regen, infinite meter, input display, and other options. Settings are saved automatically for the current game.

Save State Hotkeys

  1. Set Hotkeys

    Go to Settings → Controllers → Hotkeys and assign buttons for Training Save and Training Load.

  2. Practice

    Use the save hotkey to capture your current position, then the load hotkey to instantly reset to that point after attempting a combo or setup.
