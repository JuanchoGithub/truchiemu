Changelog

Complete release history for TruchiEmu. Each release includes notable changes, bug fixes, and new features.

v0.8.5
June 4, 2026
Analog mouse support, training mode & move lists, notification system, genre management, progressive save states, update checker, box art improvements.
v0.8.0
May 25, 2026
XPC service architecture, game loading overlay, core options override hierarchy, Portuguese localization.

May 21, 2026
16 accent color themes, MAME input mapping, 8 new systems, Portuguese language support.

Fixed broken analog triggers on Dreamcast.
v0.7.3 Multiligual
May 14, 2026
Full English and Spanish localization, zoomable box art, Dolphin stability fixes, settings refactoring.

May 10, 2026
GBC shader improvements, ROM identification fixes, system rename, Dreamcast BIOS handling, mGBA core stability.

May 8, 2026
RetroAchievements integration, Saturn emulation, massive cheat database, CRT shader improvements, documentation site launch.
v0.7 Getting closer to full vision
May 3, 2026
Performance optimizations, core options improvements, MAME gaming improvements, genre categorization.
v0.6.1 Stability and UI/UX
April 21, 2026
UI/UX refinements, Game Boy shader improvements, app speed optimizations, core options management.
v0.6 The slim Shady

CRT and Game Boy shaders, right-click library menus, PS1/PS2/MAME stability, Game Boy Color shader.
