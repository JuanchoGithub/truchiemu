Changelog

Complete release history for TruchiEmu. Each release includes notable changes, bug fixes, and new features.

v1.6.0
July 4, 2026
Streaming settings overhaul with Twitch/YouTube/custom stream key verification, share button & save last moments hotkeys, bezel toggle, hash data download, settings navigation rework with scoped sections and back chip.
v1.5.2
July 2, 2026
In-game screenshots (with flash + pill + Reveal in Finder), controller hotkey mapping, save manager bulk-delete, test notification action, notification pill refinements.
v1.5.1
July 2, 2026
Emergency patch: librashader dylib fix for release builds, notification test action, save manager bulk-delete, documentation cleanup.
v1.5.0
July 1, 2026
Streaming & recording, SDL controller support, ~1800 new slang shaders, training mode frame data, box art region selection, macOS Game Mode.
v1.4.0
June 23, 2026
Full gamepad navigation, smart ROM deletion with file restoration, joystick toggle, library grid context menus and scroll state persistence.
v1.3.0
June 19, 2026
Training mode overhaul, region-specific box art, in-app help sheet, system icon improvements, Sega input overrides, extensive fixes.
v1.2.0
June 12, 2026
Compressed ROMs (ZIP/7z/RAR), MAME/FBNeo disambiguation, CRC/ boot-sector identification, system merging, major bug fixes.
v1.1.0
June 10, 2026
Accessibility improvements to text-on-accent contrast, default theme changed to Mega Man.
v1.0.0
June 10, 2026
First stable release! RetroAchievements integration, game guide sidebar, controller deadzone settings, Jaguar BIOS, ISO scanning overhaul.

Analog mouse support, training mode & move lists, notification system, genre management, progressive save states, update checker, box art improvements.
