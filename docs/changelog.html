Changelog

Complete release history for TruchiEmu. Each release includes notable changes, bug fixes, and new features.

v1.8.8
August 6, 2026
A release focused on input, shaders, and library ergonomics. DOS games can now see your joystick, with new configuration options and improved DOSBox-Pure controller-port handling; gamepad and TV Mode fixes make consecutive presses register reliably, the toolbar overlay works while another app is focused, and the Stop dialog can be confirmed with the A button; shader parameters that had no effect are greyed out, shader switching is faster, and composite/NTSC presets render correctly; plus custom box art from a local file, dynamic box art refresh, and pinch-to-zoom with live column reflow in the library grid.
v1.8.7
August 3, 2026
Two-track release. Graphics/shaders: live in-game shader editor with unsaved-change confirmation, bezel reflection blurring into the CRT scanline/phosphor result for Famicom and RF displays, Slang preset grouping with SHA-256 stable IDs, a cached final-pass scaling flag, and an overscan default that keeps the full frame visible in RGBA conversion. Library & TV Mode: box art display modes with a blurred-fill background cache, a new GenreGroupingDiagram with per-genre counts, refreshed card/list-row context menus, clearer TV Mode settings copy across languages, and adjusted TV Mode tile/layout dimensions. Plus a full Japanese UI translation.
v1.8.6
July 29, 2026
Feature release: renamable save state slots, recording sync across Time Machine rewinds, TV Mode screen selection, Wii controller toggle hotkey, RetroAchievements session/ping API, and TCC folder-scope management that stops the repeat Downloads permission prompt at launch.
v1.8.5
July 24, 2026
Hotfix release: stops the launch-time crash introduced in 1.8.4 (libdispatch EXC_BREAKPOINT: trying to lock recursively) by guarding the AppSettingsCache initialization against the lazy-static dispatch_once re-entry when the logger warms up during first-launch SwiftData setup.
v1.8.4
July 24, 2026
Hotfix release: TV Mode now correctly resumes the user's last session state (no more being dumped back into TV Mode after quitting in normal mode), plus bundled controller presets and an export script for default gamepad mappings.
v1.8.3
July 24, 2026
Patch release: fixes silent save-state deletion failures (composite key mismatch, #27) and false-positive update-notifications on the current version (#25), plus a TV-mode game-loading reliability pass and a broad Swift 6 warning cleanup.
v1.8.2
July 24, 2026
Patch release: TV Mode fresh-play on Y for save-state ownership, per-launch auto-load override that preserves the global preference, "game wins over app" gamepad navigation hierarchy for shared combos, and reliable key-window restoration after settings sheet dismissal in fullscreen TV Mode.
v1.8.1
July 23, 2026
Patch release: controller management overhaul with multi-player keyboard mapping, gap-slot prioritization, and SDL disable/reset controls; TV Mode enhancements including filter sync, sort mode, short-list mode, resolution-adaptive scaling, and core download overlay; RetroAchievements cache fix and RA Hash display.
v1.8.0
July 22, 2026
Feature release: TV Mode browsing with animated backgrounds and box-art focus, revamped box-art pipeline, RetroAchievements enable prompt and import progress, rewind & XPC reliability fixes (including #20), type-to-search and smart collections, refactored LCD grid shaders, and ROM-scanning/metadata caching.
v1.7.3
July 17, 2026
Maintenance release: PPSSPP asset downloads, asynchronous inline box art in the core download sheet, cheat crash recovery improvements, library sidebar and grid search with game-card subtitles, and new settings options.
v1.7.2
July 16, 2026
Safety-net release: automatic pre-migration backup of the SwiftData store plus an "App Update Mode" recovery screen, so a future breaking migration can never silently wipe user data. On failure, data is restored from a timestamped backup and the app launches in limited mode.
v1.7.1
July 16, 2026
Critical hotfix: updating from v1.6.0 to v1.7.0 could delete the entire TruchiEmu user-data folder. v1.7.1 fixes the schema migration so user data is preserved and narrows the recovery path so it never touches the data folder.
