O que são Bezels?

Jogos retro foram projetados para telas 4:3 ou outras telas não widescreen. Em monitores modernos, isso deixa grandes barras pretas nas laterais. Bezels são sobreposições de imagem de alta qualidade que emolduram a tela do jogo com arte de fliperama autêntica, bordas de console ou decorações temáticas.

Bezels transformam sua tela de uma janela simples em um gabinete de fliperama virtual ou uma tela de console portátil.

Usando o Navegador de Bezels

O TruchiEmu inclui um poderoso Navegador de Bezels que permite descobrir e baixar molduras sem sair do aplicativo.

1. Abra o Seletor de Bezels

A partir da visualização de Detalhes do Jogo ou da sobreposição do Player, abra as configurações de Bezel.

2. Navegue pelos Recursos

Explore os bezels disponíveis. Os bezels estão organizados por sistema, e você pode pesquisar por temas específicos.

3. Aplique e Baixe

Selecione um bezel para aplicá-lo instantaneamente. Se o recurso não estiver em cache localmente, o TruchiEmu o baixará automaticamente.

Mapeamento Automático

Para economizar seu tempo, o TruchiEmu usa uma cascata de resolução por nome para encontrar o bezel mais adequado automaticamente. Ao iniciar um jogo, o sistema tenta cada nível em sequência:

  • Bezel Selecionado pelo Usuário: Se você definiu manualmente um bezel para este jogo, ele é sempre usado primeiro.
  • Correspondência Exata de Nome: O sistema busca um bezel cujo nome de arquivo corresponda exatamente ao nome da ROM.
  • Nome Limpo: Se não houver correspondência exata, o sistema remove caracteres especiais e sufixos do nome da ROM e tenta novamente.
  • Correspondência Aproximada: Uma busca fuzzy tenta encontrar o melhor bezel com base em similaridade parcial do nome.
  • Sem Bezel: Se nenhuma correspondência for encontrada, o jogo é exibido sem bezel.

Ajustando Seu Enquadramento

O TruchiEmu ajusta automaticamente a área do jogo para se encaixar no bezel selecionado. Bezels são projetados para proporções de tela padrão (4:3 para sistemas horizontais, 3:4 para sistemas verticais) e o enquadramento é calculado automaticamente para melhor ajuste.

Opção "Nenhum": Selecione "Nenhum" a qualquer momento para desativar bezels e exibir o jogo em tela cheia sem moldura.

Bezels Personalizados: Importe seus próprios arquivos de imagem de bezel para usar molduras personalizadas que não estão na coleção integrada.

Fonte de Download: Bezels adicionais podem ser baixados do repositório Bezel Project no GitHub.
