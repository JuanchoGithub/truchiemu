Suporte Universal

O TruchiEmu é construído sobre a API libretro, o que significa que suporta uma ampla gama de sistemas de retro gaming. Seis sistemas — NES, SNES, N64, DOS, ScummVM e Saturn — têm runners dedicados com otimizações específicas por sistema. A maioria dos outros cores libretro funciona com o runner padrão, embora alguns possam exigir BIOS ou configuração manual.

A Regra Geral: Se existe um core libretro para um sistema de jogos, o TruchiEmu provavelmente pode executá-lo. Isso inclui tudo, desde os primeiros consoles 8-bit até sistemas 3D mais complexos e máquinas de fliperama. Nem todos os cores são igualmente compatíveis — sistemas com runners dedicados geralmente oferecem a melhor experiência.

Gerenciamento de Cores

Os cores são os motores de emulação que fazem o trabalho pesado. O TruchiEmu facilita o gerenciamento desses motores sem sair do aplicativo.

O Core Downloader

Você não precisa caçar arquivos de core online. Use o Core Downloader integrado para:

  • Descobrir: Navegue por uma lista abrangente de cores disponíveis. Após o download, o TruchiEmu mapeia automaticamente cada core aos seus sistemas compatíveis.
  • Instalar: Instalação com um clique que gerencia posicionamento e configuração automaticamente.
  • Atualizar: Mantenha seus motores de emulação atualizados com as últimas melhorias da comunidade.

Escolhendo o Core Certo

Alguns sistemas possuem múltiplos cores disponíveis, desde emuladores precisos por ciclo que priorizam a fidelidade até cores mais rápidos otimizados para desempenho. Você pode alternar entre eles nos detalhes do jogo ou nas configurações do sistema para encontrar o melhor para seu hardware e preferências:

Cores de Precisão

Priorizam emulação precisa por ciclo. Melhores para preservação e Macs de alto desempenho.

Cores de Desempenho

Priorizam velocidade e eficiência. Melhores para hardware mais antigo ou títulos extremamente exigentes.

BIOS e Arquivos de Sistema

Muitos consoles requerem um arquivo de BIOS (Basic Input/Output System) para iniciar. O TruchiEmu remove a dor de cabeça de buscar BIOS manualmente.

BIOS Pré-Incluídas

O TruchiEmu vem pré-empacotado com arquivos de BIOS para o Sega Saturn (sega_101.bin e mpr-17933.bin), garantindo que esses sistemas funcionem logo após a instalação. Para outros sistemas que exigem arquivos de BIOS (como PlayStation, 3DO e Dreamcast), você precisará fornecer os seus próprios.

BIOS Personalizada

Se você possui arquivos de BIOS regionais específicos ou precisa atualizar um arquivo de sistema, pode colocá-los em ~/Library/Application Support/TruchiEmu/System/. O TruchiEmu priorizará seus arquivos personalizados sobre as versões incluídas.

Dicas de Otimização

Para aproveitar ao máximo sua experiência de emulação, considere estes ajustes:

  • Substituições de Core: Defina um core específico para um jogo específico se o padrão não tiver bom desempenho.
  • Verificação de BIOS: Se um jogo não iniciar, certifique-se de que seu diretório de sistema está corretamente mapeado nas Configurações.
  • Aceleração por Hardware: O TruchiEmu usa Metal para renderização acelerada por hardware em todos os Macs. Certifique-se de que seus drivers gráficos estão atualizados para o melhor desempenho no Apple Silicon.
