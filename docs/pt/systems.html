Suporte Universal

O TruchiEmu é construído sobre a API libretro, o que significa que ele não suporta apenas alguns consoles—suporta todos os sistemas que possuem um core libretro disponível.

A Regra Geral: Se existe um core libretro para um sistema de jogos, o TruchiEmu pode executá-lo. Isso inclui tudo, desde os primeiros consoles 8-bit até sistemas 3D mais complexos e máquinas de fliperama.

Gerenciamento de Cores

Os cores são os motores de emulação que fazem o trabalho pesado. O TruchiEmu facilita o gerenciamento desses motores sem sair do aplicativo.

O Core Downloader

Você não precisa caçar arquivos de core online. Use o Core Downloader integrado para:

  • Descobrir: Navegue por uma lista abrangente de cores disponíveis categorizados por sistema.
  • Instalar: Instalação com um clique que gerencia posicionamento e configuração automaticamente.
  • Atualizar: Mantenha seus motores de emulação atualizados com as últimas melhorias da comunidade.

Escolhendo o Core Certo

Alguns sistemas possuem múltiplos cores disponíveis. Você pode alternar entre eles nos detalhes do jogo ou nas configurações do sistema para encontrar o melhor para suas necessidades:

Cores de Precisão

Priorizam emulação precisa por ciclo. Melhores para preservação e Macs de alto desempenho.

Cores de Desempenho

Priorizam velocidade e eficiência. Melhores para hardware mais antigo ou títulos extremamente exigentes.

BIOS e Arquivos de Sistema

Muitos consoles requerem um arquivo de BIOS (Basic Input/Output System) para iniciar. O TruchiEmu remove a dor de cabeça de buscar BIOS manualmente.

✅ BIOS Pré-Incluídas

O TruchiEmu vem pré-empacotado com arquivos de BIOS essenciais dos sistemas para os consoles mais populares, garantindo uma experiência "plug-and-play" logo após a instalação.

BIOS Personalizada

Se você possui arquivos de BIOS regionais específicos ou precisa atualizar um arquivo de sistema, pode colocá-los na pasta System/ dentro do seu diretório de salvamento ativo. O TruchiEmu priorizará seus arquivos personalizados sobre as versões incluídas.

Dicas de Otimização

Para aproveitar ao máximo sua experiência de emulação, considere estes ajustes:

  • Substituições de Core: Defina um core específico para um jogo específico se o padrão não tiver bom desempenho.
  • Verificação de BIOS: Se um jogo não iniciar, certifique-se de que seu diretório de sistema está corretamente mapeado nas Configurações.
  • Aceleração por Hardware: Certifique-se de que o Metal está ativado nas suas configurações de exibição para o melhor desempenho no Apple Silicon.
