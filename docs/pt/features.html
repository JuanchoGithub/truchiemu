Coleção de Shaders

Transforme sua experiência de jogo com nossa coleção curada de 14 shaders Metal de alta qualidade. Cada shader é otimizado para macOS e projetado para melhorar ou reproduzir autenticamente os visuais clássicos dos jogos.

A interface do seletor de shaders permite visualização e ajuste em tempo real

Passthrough

O shader padrão que renderiza os pixels exatamente como o hardware original pretendia. Perfeito para puristas que desejam visuais autênticos e sem filtro, com bordas de pixels nítidas.

Sem Processamento Pixels Nítidos Baixo CPU

Caso de Uso: Desenvolvimento, reprodução pixel-perfect, speedrunning

Scale Smooth

Escala bicúbica de alta qualidade que suaviza as bordas dos pixels enquanto preserva os detalhes. Ideal para monitores modernos onde pixels brutos parecem muito blocados.

Suavização Bicúbica Universal

Caso de Uso: Jogos em geral, monitores modernos, redução de pixelação

Smooth Upscale

Escala suave de alta qualidade que proporciona uma imagem limpa e uniforme, removendo artefatos de pixels enquanto mantém a nitidez geral. Alternativa mais leve ao Scale Smooth.

Suavização Leve Universal

Caso de Uso: Jogos em geral, escalonamento suave em monitores modernos

CRT Multipass

Simulação CRT multi-passo com brilho de fósforo, scanlines e curvatura. Nossa recriação CRT mais autêntica para usuários que buscam a verdadeira experiência retro.

Multi-Passo Autêntico Pesado

Caso de Uso: Experiência retro autêntica, entusiastas de CRT, nostalgia

Lite CRT

Simulação CRT leve que adiciona scanlines sutis e efeitos de fósforo sem o custo de desempenho da renderização multipass completa.

Scanlines Leve Desempenho

Caso de Uso: Estética CRT em hardware menos potente, efeito sutil

CRT Lottes

Simulação CRT avançada usando o algoritmo de Lottes com efeitos de máscara, curvatura e bloom. Cria a aparência de monitor CRT mais realista disponível.

Máscara de Fósforo Bloom Premium

Caso de Uso: Simulação CRT profissional, criação de conteúdo, preservação

Dot Matrix LCD

Simula a tela de matriz de pontos distintiva de sistemas portáteis clássicos como o Game Boy. Apresenta o padrão de grade característico e o arranjo de subpixels.

Portátil Padrão de Grade Nostálgico

Caso de Uso: Jogos de Game Boy, emulação portátil, experiência autêntica

Tela de Game Boy Original

Simulação fiel do LCD do Game Boy DMG (Dot Matrix Game) com a icônica tela monocromática com tom esverdeado, persistência de pixels e desfoque de movimento característico.

Game Boy Monocromático Autêntico

Caso de Uso: Jogos do Game Boy original, pura nostalgia, reprodução autêntica

8b Game Boy Color

Reprodução precisa do LCD do Game Boy Color com a paleta de cores correta, arranjo de pixels e características de retroiluminação do hardware original.

Colorido Portátil Preciso

Caso de Uso: Jogos de Game Boy Color, representação precisa de cores

GBA Advanced LCD

Simulação LCD fiel do Game Boy Advance com a temperatura de cor distinta, estrutura de pixels e características de movimento da tela do GBA.

GBA Retroiluminado Portátil

Caso de Uso: Jogos de GBA, experiência autêntica de jogo portátil

PSP Advanced LCD

Simulação LCD do PlayStation Portable com subpixel distinto e características de resposta da tela do hardware PSP original.

PSP Portátil Autêntico

Caso de Uso: Jogos de PSP, experiência autêntica de tela portátil

NDS Advanced LCD

Simulação LCD do Nintendo DS com as características de visualização distinctivas do hardware DS original.

NDS Portátil Autêntico

Caso de Uso: Jogos de Nintendo DS, experiência autêntica de tela

3DS Advanced LCD

Simulação LCD do Nintendo 3DS com as características de visualização do hardware 3DS original.

3DS Portátil Autêntico

Caso de Uso: Jogos de Nintendo 3DS, experiência autêntica de tela

8b Game Boy

Simulação fiel do LCD do Game Boy DMG com a icônica tela monocromática com tom esverdeado, padrão de grade de pixels e desfoque de movimento característico.

Game Boy Monocromático Autêntico

Caso de Uso: Jogos do Game Boy original, pura nostalgia, reprodução autêntica

CRT Classic

Uma simulação CRT equilibrada que fornece scanlines clássicas e um sutil brilho de fósforo. Otimizada para alto desempenho em todos os sistemas.

Equilibrado Scanlines Rápido

Caso de Uso: Jogos retro em geral, aparência consistente em múltiplos sistemas

Personalização de Shaders

Cada shader inclui parâmetros ajustáveis para ajustar o efeito:

  • Controles de Intensidade: Ajuste a força de cada efeito
  • Presets de Parâmetros: Configurações rápidas para diferentes tipos de tela
  • Visualização em Tempo Real: Veja as mudanças instantaneamente ao ajustar
  • Configurações por Jogo: Salve preferências de shader para jogos individuais
  • Padrões Globais: Defina preferências de shader para todo o sistema

Impacto no Desempenho: Passthrough, Scale Smooth e Vignette têm impacto mínimo no desempenho. Shaders CRT e simulações LCD usam mais recursos de GPU. A maioria dos Macs modernos pode executar qualquer shader na velocidade máxima.

Gerenciamento de Biblioteca

Organize sua coleção de jogos com poderosos recursos de gerenciamento de biblioteca projetados para colecionadores sérios e jogadores casuais.

Seus jogos são organizados automaticamente com capas e metadados

Organização Automática

  • Detecção Inteligente: Identifica automaticamente jogos a partir de hashes de arquivos ROM
  • Busca de Metadados: Baixa descrições de jogos, datas de lançamento e detalhes
  • Capas: Baixa automaticamente capas de alta qualidade para sua biblioteca
  • Categorização por Sistema: Agrupa jogos por console/sistema original
  • Detecção de Conquistas: Identifica jogos com suporte a RetroAchievements

📊 Visualização em Grade

Grade visual com miniaturas de capas. Perfeita para navegar por grandes coleções.

  • Tamanho da grade ajustável via controle de zoom
  • Ordenar por nome, último jogado ou último adicionado
  • Busca rápida e filtros

📋 Visualização em Lista

Lista detalhada com metadados e estatísticas. Ótima para classificação e organização.

  • Exibição compacta para grandes bibliotecas
  • Indicadores rápidos de status

Coleções e Playlists

Organize seus jogos com categorias personalizadas e filtros integrados:

  • Coleções Manuais: Crie categorias personalizadas para agrupar seus jogos favoritos
  • Favoritos: Acesso rápido aos seus títulos imprescindíveis através do filtro de favoritos
  • Jogados Recentemente: Rastreia e exibe automaticamente suas sessões mais recentes

Busca e Filtro

Encontre jogos instantaneamente com poderosos recursos de busca:

  • Busca por Texto: Pesquise por nome do jogo ou metadados
  • Filtro por Sistema: Mostre apenas jogos de consoles específicos
  • Suporte a Conquistas: Mostre jogos com RetroAchievements
  • Status de Jogo: Filtre por favoritos ou jogados recentemente

Importação e Exportação

Opções de Importação

  • Verificação recursiva automática de diretórios de ROMs
  • Suporte a arrastar e soltar para gerenciamento da biblioteca

Opções de Exportação

  • Exportação automática de metadados para games.xml
  • Backup de metadados da biblioteca para portabilidade

Integração com RetroAchievements

Ganhe conquistas enquanto joga jogos clássicos! O TruchiEmu integra-se perfeitamente com RetroAchievements.org para adicionar caça a conquistas moderna ao retro gaming.

Acompanhe seu progresso e compare com amigos no ranking global

Começando com Conquistas

Passo 1: Crie uma Conta no RetroAchievements

Visite RetroAchievements.org e crie uma conta gratuita.

Passo 2: Vincule sua Conta no TruchiEmu

Navegue até Configurações → Conquistas e insira seu nome de usuário, senha e chave de API do RetroAchievements.

Passo 3: Conectar

Use o botão "Conectar" para verificar suas credenciais e sincronizar seu perfil.

Passo 4: Jogue Jogos Suportados

Inicie qualquer jogo com suporte a conquistas. Seu progresso será sincronizado com seu perfil global.

Tipos de Conquistas

O TruchiEmu suporta a variedade de tipos de conquistas definidos pela comunidade RetroAchievements, incluindo marcos de progresso, desafios baseados em habilidade e objetivos de completistas.

Sistemas Suportados

O suporte a RetroAchievements varia por sistema. O TruchiEmu fornece mapeamento para todos os principais consoles, incluindo:

Sistema Suporte a Conquistas Jogos Suportados
NES / SNES ✅ Suporte Completo 1.000+ jogos
Game Boy / Color / Advance ✅ Suporte Completo 1.000+ jogos
Genesis / Mega Drive ✅ Suporte Completo 500+ jogos
Nintendo 64 / PS1 ✅ Limitado / Experimental 100+ jogos
PC Engine / TurboGrafx ✅ Suporte Completo 300+ jogos

Recursos de Integração

  • Rich Presence: Atualiza automaticamente seu perfil para mostrar aos amigos qual jogo você está jogando atualmente
  • Rankings: Envie e compare pontuações e tempos nos rankings globais
  • Modo Hardcore: Opção de rastrear conquistas sem o uso de save states, rewind, câmera lenta e cheats para uma experiência purista

💡 Dicas de Conquistas:

  • Certifique-se de usar arquivos ROM verificados que correspondam aos hashes do banco de dados RetroAchievements.
  • Verifique as listas de conquistas no site do RA para planejar sua abordagem para troféus difíceis.
  • Junte-se à comunidade RetroAchievements para acompanhar seu progresso contra outros jogadores.
  • Modo Hardcore: Ative o Modo Hardcore nas configurações para desabilitar save states, rewind, câmera lenta e cheats, o que é necessário para ganhar conquistas do nível Hardcore.

⚠️ Importante: As conquistas só funcionam com arquivos ROM verificados que correspondam aos hashes do banco de dados RetroAchievements. Use dumps verificados No-Intro para melhor compatibilidade.

Cores de Emulação

O TruchiEmu é alimentado pelo libretro, uma API universal de emulação. Cada sistema é executado em um core dedicado pense neles como motores de plug-in. Os cores são baixados, atualizados e configurados automaticamente através do Core Downloader integrado.

Para uma referência completa sobre quais cores alimentam cada sistema, ajuste de desempenho e a arquitetura técnica, consulte o Guia do Desenvolvedor.

Recursos de Save State

Os save states permitem capturar e restaurar sua posição exata em um jogo instantaneamente, fornecendo uma rede de segurança moderna para o retro gaming.

📸 Save States Visuais

  • Captura automática de miniaturas para cada slot de salvamento
  • Navegador visual em grade para seleção rápida de estados
  • Até 10 slots de salvamento por jogo
  • Marcas de data/hora para cada estado capturado

📦 Armazenamento Otimizado

  • Compressão LZ4 para todos os arquivos de estado
  • Cabeçalho TCS2 personalizado para integridade do estado
  • Baixo uso de disco para grandes bibliotecas
  • Velocidades rápidas de carregamento/salvamento

🔋 Suporte a Salvamento por Bateria

  • Armazenamento dedicado para salvamentos por bateria tradicionais
  • Compatibilidade com arquivos de salvamento do hardware original
  • Tratamento automático pelos cores de emulação
  • Separado dos arquivos de estado de snapshot

Gerenciador de Save States

O navegador de save states integrado oferece uma maneira visual de gerenciar seu progresso:

  • Grade de Miniaturas: Navegue por suas posições salvas visualmente através de pré-visualizações de 320x240
  • Gerenciamento de Slots: Acesso fácil aos slots 0 a 9
  • Metadados: Veja exatamente quando cada estado foi criado
  • Caminhos Automatizados: Estrutura de pastas consistente para backup e migração fáceis

Suporte a Mouse Analógico

O TruchiEmu permite usar os analógicos do seu controle para controlar o cursor do mouse em jogos DOS e ScummVM, com botões configuráveis para cliques e o direcional para entradas de teclado.

Recursos Principais

  • Analógico para Mouse: O analógico primário (esquerdo ou direito) controla o cursor a 60fps com sensibilidade configurável
  • Analógico Secundário para Controle Fino: O analógico secundário move o mouse a 1/5 da velocidade para posicionamento preciso
  • Direcional como Teclado: O direcional envia teclas de seta, Start envia Enter, Select envia Espaço
  • Mapeamento de Botões Configurável: Atribua clique esquerdo, direito e do meio a qualquer botão do controle
  • Por Sistema e por Jogo: Configurações independentes para DOS e ScummVM, com substituições por jogo

Guia de Jogos

Travou em um enigma? A barra lateral de Guia de Jogos integrada traz dicas progressivas e soluções completas direto para a janela do seu jogo. Ela aparece automaticamente para jogos de aventura e point-and-click, obtendo conteúdo do Universal Hint System (UHS) e GameFAQs.

Recursos Principais

  • Dicas Progressivas (UHS): Dicas sem spoilers que se revelam uma de cada vez — obtenha apenas a ajuda necessária sem estragar o enigma
  • Soluções Completas (GameFAQs): Soluções de texto completas como alternativa quando dicas UHS não estão disponíveis
  • Navegação por Controle: Navegue pelo guia com seu controle — analógicos rolam, botões A/B navegam, R3/L3 alterna a barra lateral
  • 387+ Mapeamentos de Jogos: Guias UHS pré-mapeados para aventuras clássicas incluindo Monkey Island, Broken Sword, Grim Fandango, e mais
  • Detecção Automática: Jogos de aventura e point-and-click são identificados por gênero ou sistema (jogos ScummVM sempre se qualificam)

Acesso Rápido: Pressione Cmd+J ou clique no botão do guia na barra de ferramentas para abrir a barra lateral. Para jogos DOS e ScummVM, a captura de entrada é liberada automaticamente ao abrir o guia e retomada ao fechá-lo.

Modo de Treinamento

A sobreposição do modo de treinamento do TruchiEmu fornece ferramentas de automação de P2 para jogos de luta, permitindo controlar o dummy para praticar combos, defesa e setups.

Recursos Principais

  • Controle de Dummy: Configure a postura, guarda, técnica de acordar e ações de reversal do P2 para prática realista
  • Programação de Sequências: Construa sequências de frames de movimentos para P2 executar com gatilhos configuráveis
  • Gravação de Entradas: Grave entradas do P1 via tape deck e reproduza como P2 com múltiplos slots
  • Exibição de Entrada: Visualização em tempo real das entradas de P1 e P2 com tokens de notação de movimentos
  • Integração de Movimentos: Navegue pelos movimentos do personagem e vincule a sequências de treinamento diretamente da sobreposição

Saiba mais sobre o Modo de Treinamento →

Sobreposição de Movimentos

Nunca mais esqueça um movimento especial. A sobreposição de movimentos exibe notações de movimentos de jogos de luta diretamente na tela, ajudando você a aprender e executar combos e movimentos especiais específicos de personagens durante o jogo.

Recursos Principais

  • Exibição na Tela: Notações de movimentos são mostradas como sobreposição durante o jogo, categorizadas por tipo
  • Tokens Visuais: Notações usam tokens visuais para entradas direcionais, combinações de botões e condições especiais
  • Conjuntos por Jogo: Movimentos são carregados automaticamente com base no jogo sendo executado
  • Movimentos Comuns: Modelos de movimentos comuns pré-definidos para jogos de luta populares
  • Busca e Filtro: Encontre rapidamente movimentos específicos por nome, tipo de entrada ou personagem

Gerenciamento Profissional de Fliperama (MAME)

A emulação de fliperama pode ser complexa. O TruchiEmu simplifica o processo com ferramentas especializadas para gerenciamento de ROMs MAME.

Verificação de ROMs

Verifique automaticamente a integridade das ROMs contra bancos de dados oficiais usando hashes CRC32 para garantir reprodução com zero corrupção.

Rastreamento de Dependências

Detecção inteligente de relações entre ROMs pai e filho. O TruchiEmu alerta se uma ROM pai necessária está ausente antes de você tentar iniciar um jogo.

Automação de Metadados

Integra-se com o LaunchBox Games DB e arquivos DAT para preencher automaticamente descrições de jogos, datas de lançamento e gêneros.
