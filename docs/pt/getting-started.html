Requisitos do Sistema

🖥️ Compatibilidade com macOS

Mínimo: macOS 14.0 (Sonoma) ou posterior com Swift 5.9+

Recomendado: macOS 15.0 (Sequoia) ou posterior para desempenho ideal

Dependências de Compilação

  • Xcode: Versão estável mais recente (Obrigatório para compilação)
  • Xcode Command Line Tools: xcode-select --install
  • xcodegen: Usado para gerar o projeto Xcode a partir do project.yml
  • GPU compatível com Metal: Para renderização de shaders e aceleração por hardware

⚠️ Importante: O TruchiEmu usa recursos modernos do SwiftUI e shaders Metal que não são compatíveis com versões do macOS anteriores à 14.0.

Compilando a Partir do Código-Fonte

O TruchiEmu é compilado usando XcodeGen para manter uma estrutura de projeto limpa. Siga estes passos para compilar o aplicativo localmente.

1. Instalar Ferramentas de Compilação

brew install xcodegen

2. Clonar e Gerar o Projeto

git clone https://github.com/JuanchoGithub/truchiemu.git
cd truchiemu
xcodegen generate # Isso cria o arquivo TruchiEmu.xcodeproj

3. Compilar o Aplicativo

Você pode compilar via linha de comando ou abrindo o projeto no Xcode.

# Método CLI:
xcodebuild -project TruchiEmu.xcodeproj -scheme TruchiEmu -configuration Debug build

Alternativamente: Execute open TruchiEmu.xcodeproj e pressione ⌘+B.

💡 Nota: Se você modificar o project.yml, deve executar xcodegen generate novamente para atualizar o projeto Xcode.

Primeiro Lançamento e Configuração

Ao iniciar o TruchiEmu pela primeira vez, você será guiado por um processo de configuração inicial para configurar seu ambiente.

Configuração do Ambiente

Local da Biblioteca e Dados

O TruchiEmu separa sua biblioteca de jogos dos dados internos do aplicativo. Embora você possa escolher qualquer pasta para suas ROMs, o aplicativo armazena suas configurações, save states e arquivos de sistema no diretório padrão do macOS Application Support: ~/Library/Application Support/TruchiEmu/.

Dentro da pasta Application Support, o TruchiEmu organiza automaticamente os dados técnicos em:

  • Saves/ - Seus save states e arquivos de salvamento por bateria
  • Cores/ - Os cores libretro usados para emulação
  • Thumbnails/ - Capas de jogos e capturas de tela em cache
  • System/ - BIOS necessárias e arquivos de sistema

Configuração de Controles

Mapeie suas entradas para o emulador. O TruchiEmu suporta nativamente controles de Teclado, Xbox, PlayStation e Nintendo Switch no macOS.

Adicionando Seu Primeiro Jogo

O TruchiEmu suporta métodos simples de importação para deixar sua biblioteca pronta.

Importando Jogos

  1. Arrastar e Soltar: Arraste arquivos ROM ou pastas do Finder diretamente para a janela da biblioteca do TruchiEmu.
  2. Importação Manual: Use o botão de importação na barra de ferramentas da biblioteca para navegar pelos arquivos.

Manipulação e Compatibilidade de Arquivos

O TruchiEmu aproveita a API libretro, o que significa que suporta praticamente qualquer formato de arquivo aceito pelo core do emulador ativo. Em vez de depender de simples extensões de arquivo, o aplicativo usa hashing CRC32 e bancos de dados DAT para identificar jogos com precisão.

📦 ROMs Compactadas

Para sistemas de fliperama como MAME, .zip é o formato principal esperado e é tratado nativamente pela biblioteca.

💿 Imagens de Disco

Tratamento inteligente de imagens de disco. Quando um arquivo .cue é detectado, o TruchiEmu o prioriza e oculta automaticamente os arquivos .bin associados da biblioteca para evitar entradas duplicadas.

🛠️ Filtragem da Biblioteca

Para manter sua coleção limpa, o aplicativo filtra automaticamente arquivos de BIOS do sistema e recursos de metadados, exibindo apenas entradas de jogos jogáveis na visualização da biblioteca.

⚠️ Aviso Legal: O TruchiEmu não fornece ROMs. Por favor, use cópias de segurança obtidas legalmente de jogos que você possui.

Suporte a Controles

O TruchiEmu detecta automaticamente a maioria dos controles populares quando conectados via USB ou Bluetooth através do framework nativo macOS GameController:

  • Controles Xbox: Suporte nativo para Xbox One e Series X|S
  • Controles PlayStation: DualShock 4 e DualSense (PS5) suportados
  • Nintendo Switch: Joy-Cons e Pro Controller suportados
  • USB Genérico: A maioria dos controles MFi e XInput funciona imediatamente

💡 Dica de Controle: O TruchiEmu usa um modelo de mapeamento global baseado no layout moderno Xbox/PlayStation. Isso garante uma sensação consistente entre diferentes sistemas, mas pode ser personalizado por sistema nas configurações.

Personalização por Sistema

Cada core do emulador pode ter seu próprio mapeamento de controles para se adequar melhor ao hardware original:

  1. Abra um jogo do sistema que deseja configurar
  2. Navegue até as configurações de Controle no menu principal
  3. Ajuste os mapeamentos de botões conforme sua preferência
  4. Os mapeamentos são salvos por sistema e aplicados automaticamente na próxima vez que você iniciar um jogo daquele sistema

Save States

O TruchiEmu oferece um gerenciamento robusto de save states junto com os salvamentos por bateria tradicionais.

Save States

  • Instantâneo da memória do emulador
  • Gerenciamento visual baseado em slots (Slots 0-9 + Auto)
  • Gerenciado pela visualização de Detalhes do Jogo com pré-visualizações em miniatura

Salvamentos por Bateria

  • Funciona como o hardware original
  • Compatível com cartuchos reais
  • Tratado automaticamente pelo core do jogo
