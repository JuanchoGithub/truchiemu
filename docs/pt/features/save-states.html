Sistema de Save States

O sistema de save states do TruchiEmu captura e restaura o estado do emulador a qualquer momento, com uma interface organizada baseada em slots e gerenciamento visual.

Visão Geral

Save States permitem capturar o jogo a qualquer momento e recarregá-lo depois perfeito para tentar de novo uma seção difícil, deixar um jogo parado para mais tarde, ou experimentar sem consequências. Cada jogo tem seu próprio banco de 10 slots numerados mais um slot de auto-save. A maioria dos cores suporta isso; alguns não.

Funcionalidades

  • 10 Slots de Salvamento: Numerados de 0 a 9, mais um slot de auto-save que você pode carregar mas não escrever diretamente
  • Captura Instantânea: Salve e carregue a qualquer momento, no meio de uma fase, no meio de uma luta, onde quer que você esteja
  • Pré-visualizações em Miniatura: Cada save captura uma pequena screenshot, para você ver qual quer antes de carregar
  • Organização Automática: Save states são agrupados por jogo e rotulados com data/hora
  • Desfazer Carga: Aperte Cmd+Z logo após uma carga para voltar de onde você estava útil se você escolheu o slot errado
  • Save States Progressivos: Opcionalmente, deixe cada slot manter um histórico rotativo (até 5 versões) para que um save antigo nunca seja realmente sobrescrito
  • Auto-Salvar ao Sair: Opcionalmente, grave no slot de auto-save ao fechar um jogo
  • Auto-Carregar ao Iniciar: Opcionalmente, continue de onde parou ao iniciar um jogo

Guia de Configuração Passo a Passo

Uso Básico de Save States

  1. Salvar Durante o Gameplay

    Enquanto joga, acesse o menu de save states pela barra de ferramentas da janela do jogo ou use o atalho de teclado configurado para salvar no slot atual.

  2. Carregar um Save State

    Abra o navegador de save states para ver todos os estados salvos do jogo atual. Clique em qualquer entrada para restaurar o gameplay daquele ponto.

  3. Gerenciar Slots de Salvamento

    Use slots de salvamento diferentes para manter múltiplos pontos de salvamento para diferentes jogatinhas ou desafios. Cada slot armazena um estado do emulador separado.
