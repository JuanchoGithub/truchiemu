Sistema de Save States

O sistema de save states do TruchiEmu captura e restaura o estado do emulador a qualquer momento, com uma interface organizada baseada em slots e gerenciamento visual.

Visão Geral do Serviço

O sistema de Save States captura o estado interno do emulador (RAM, registradores de CPU e dados específicos do core). Nem todos os cores suportam save states. Os save states são gerenciados através da interface da janela do jogo.

Pipeline de captura e restauração de save states com geração de miniaturas e backup

Recursos Principais

  • Capturas Instantâneas: Salve e carregue a qualquer momento durante o gameplay
  • Banca de Slots: 10 slots numerados (0–9) mais um slot de auto-salvamento (somente carga)
  • Pré-visualizações em Miniatura: Cada save state captura uma captura de tela PNG de 320×240
  • Save States Progressivos: Quando habilitado, cada slot mantém um histórico rotativo de até 5 versões (padrão: 3). Desativado por padrão.
  • Compressão LZ4: Save states podem ser comprimidos usando LZ4 (ativado por padrão). Arquivos comprimidos usam um cabeçalho mágico TCS2.
  • Desfazer Carga: Após carregar um save state, pressione Cmd+Z para desfazer e retornar ao estado anterior à carga
  • Auto-Salvar ao Sair: Salva no slot de auto-salvamento ao fechar um jogo (desativado por padrão)
  • Auto-Carregar ao Iniciar: Carrega o slot de auto-salvamento ao lançar um jogo (desativado por padrão)
  • Nomenclatura Automática: Save states são organizados por jogo e marca de data/hora

Para detalhes de implementação, consulte o Guia do Desenvolvedor.

Guia de Configuração Passo a Passo

Uso Básico de Save States

  1. Salvar Durante o Gameplay

    Enquanto joga, acesse o menu de save states pela barra de ferramentas da janela do jogo ou use o atalho de teclado configurado para salvar no slot atual.

  2. Carregar um Save State

    Abra o navegador de save states para ver todos os estados salvos do jogo atual. Clique em qualquer entrada para restaurar o gameplay daquele ponto.

  3. Gerenciar Slots de Salvamento

    Use slots de salvamento diferentes para manter múltiplos pontos de salvamento para diferentes jogatinhas ou desafios. Cada slot armazena um estado do emulador separado.
