Time Machine

Controles de rebobinamento, avanço rápido e câmera lenta direto da barra do jogo.

Visão Geral

O Time Machine grava seu jogo recente em um buffer curto e o reproduz sob demanda. Segure rebobinar para voltar pelo que acabou de acontecer — como um DVR para seu jogo — sem sair da janela.

Recursos

  • Rebobinamento: Volte pelo jogo recente para refazer um pulo errado, combo errado ou golpe fatal sem recorrer a save state
  • Avanço Rápido: Pule diálogos lentos, grind ou cutscenes longas
  • Câmera Lenta: Estude sequências frame-perfect em velocidade reduzida — ideal para prática de combos ou setups difíceis
  • Compatibilidade: Alguns sistemas não suportam (por exemplo Dolphin). O Play! (PS2) avisa antes de capturar, assim você pode voltar

Como Usar

  1. Habilitar Time Machine: Settings → Time Machine, toggle on (ou pelo Setup Wizard).
  2. Definir Profundidade do Buffer: Profundidade de rebobinamento em segundos (maior = mais memória).
  3. Definir Ratio de Câmera Lenta: 0.5×, 0.25×, 0.1×, etc.
  4. Atribuir Hotkeys: Bind de rebobinamento / avanço rápido / câmera lenta em Hotkeys. Aceita teclado e gamepad.
  5. Usar durante o jogo: Dispare os controles pela barra ou hotkeys. O overlay exibe o estado atual.

Restrições

Modo Hardcore: Time Machine é bloqueado quando o Modo Hardcore do RetroAchievements está ativo.
