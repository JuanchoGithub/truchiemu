Verificador de Atualizações

O Verificador de Atualizações do TruchiEmu mantém seu emulador sempre na versão mais recente com verificações automáticas, changelog integrado e notificações de novas versões.

Visão Geral

O TruchiEmu fica de olho em novas versões discretamente. Ele verifica lançamentos em segundo plano e exibe uma notificação quando há algo novo. Você pode ler o changelog direto no app antes de decidir atualizar e navegar por um histórico de versões para ver o que mudou ao longo do tempo. O verificador só conversa com a API pública de releases do GitHub sem analytics, sem rastreamento.

O Que Você Ganha

  • Verificações em Segundo Plano: O TruchiEmu verifica atualizações na inicialização e periodicamente, sem interromper sua sessão de jogo
  • Changelog no App: Leia as notas de versão da versão atual ou de qualquer versão passada sem sair do app
  • Notificações de Atualização: Uma pílula aparece quando sai uma nova versão, com um link direto para o download
  • Histórico de Versões: Navegue por todos os lançamentos anteriores com suas datas e changelogs
  • Verificação Manual: Quer saber agora? Abra o menu e dispare uma verificação sob demanda
  • Atual vs. Mais Recente: O painel Sobre mostra sua versão instalada ao lado da mais recente disponível

Como Usar

Verificar Atualizações Manualmente

  1. Abrir o Menu

    Selecione TruchiEmu → Verificar Atualizações na barra de menu.

  2. Visualizar Resultado

    Uma caixa de diálogo exibirá a versão atual, a versão mais recente disponível e as notas de versão. Se uma atualização estiver disponível, um link para download será fornecido.

Configurar Verificações Automáticas

  1. Acessar Preferências

    Vá para Configurações → Sobre.

  2. Ajustar Frequência

    Selecione a frequência de verificação: diariamente, semanalmente ou apenas manualmente.

Visualizar Histórico de Versões

  1. Abrir Histórico

    Vá para Ajuda → Histórico de Versões.

  2. Explorar Versões

    Navegue pela lista de versões anteriores e atuais, com detalhes de cada mudança implementada.
