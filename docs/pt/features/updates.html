Verificador de Atualizações

O Verificador de Atualizações do TruchiEmu mantém seu emulador sempre na versão mais recente com verificações automáticas, changelog integrado e notificações de novas versões.

Visão Geral do Serviço

O Verificador de Atualizações consulta automaticamente o repositório oficial do TruchiEmu para identificar novas versões disponíveis. Quando uma atualização é encontrada, uma notificação é exibida com um resumo das mudanças. O changelog completo pode ser visualizado diretamente no aplicativo, permitindo que você decida quando atualizar.

Recursos Principais

  • Verificações Automáticas: O aplicativo verifica periodicamente se há novas versões disponíveis sem intervenção do usuário.
  • Changelog no App: Visualize o histórico completo de mudanças de cada versão diretamente na interface do TruchiEmu.
  • Notificações de Atualização: Alertas visuais não intrusivos informam quando uma nova versão está disponível para download.
  • Histórico de Versões: Acompanhe o histórico de versões instaladas e visualizadas, com detalhes de cada atualização.

Como Usar

Verificar Atualizações Manualmente

  1. Abrir o Menu

    Selecione TruchiEmu → Verificar Atualizações na barra de menu.

  2. Visualizar Resultado

    Uma caixa de diálogo exibirá a versão atual, a versão mais recente disponível e as notas de versão. Se uma atualização estiver disponível, um link para download será fornecido.

Configurar Verificações Automáticas

  1. Acessar Preferências

    Vá para Configurações → Sobre.

  2. Ajustar Frequência

    Selecione a frequência de verificação: diariamente, semanalmente ou apenas manualmente.

Visualizar Histórico de Versões

  1. Abrir Histórico

    Vá para Ajuda → Histórico de Versões.

  2. Explorar Versões

    Navegue pela lista de versões anteriores e atuais, com detalhes de cada mudança implementada.
