Mouse Analógico

Use os sticks analógicos do gamepad como mouse em jogos DOS e ScummVM — com o D-pad como setas e mapeamento configurável de cliques.

Visão Geral

Jogos DOS e ScummVM muitas vezes precisam de mouse. Com o Mouse Analógico, você não precisa de um mouse físico — o stick primário move o cursor a 60fps; o secundário dá controle fino a 1/5 de velocidade; o D-pad envia setas; Start envia Enter; Select envia Espaço.

Recursos

  • Stick Analógico como Mouse: Stick primário configurável (esq/dir) com sensibilidade ajustável
  • Stick Secundário para Controle Fino: 1/5 de velocidade para posicionamento preciso
  • D-Pad como Teclado: Setas, Enter, Espaço
  • Mapeamento de Botões Configurável: Atribua clique esq/dir/meio a qualquer botão
  • Per-System e Per-Game: Overrides independentes para DOS e ScummVM
  • Auto-Release com Game Guide: Captura é liberada ao abrir Game Guide e retomada ao fechar

Como Usar

  1. Settings → Analog Mouse: ative por sistema (DOS, ScummVM, ou ambos)
  2. Set Stick Handedness: esq ou dir como primário; o outro fica fino
  3. Tune Sensitivity e Deadzone
  4. Map Mouse Buttons ao Gamepad: clique em um campo, pressione um botão
  5. Per-Game Overrides: a partir do Game Detail, clique em Game → Analog Mouse Override
