Suporte a Mouse Analógico

O TruchiEmu permite usar os analógicos do seu controle para controlar o cursor do mouse em jogos DOS e ScummVM, com botões configuráveis para cliques e o direcional para entradas de teclado.

Visão Geral

O sistema de mouse analógico traduz a deflexão do analógico do seu controle em movimento do cursor para jogos de apontar e clicar em DOS e ScummVM. Isso permite navegar por menus, clicar em objetos e interagir com mundos do jogo usando um controle em vez de um mouse físico. O recurso é configurável por sistema (DOS, ScummVM) e suporta substituições por jogo.

Como Funciona

  • Analógico para Mouse: O analógico primário (esquerdo ou direito, selecionável pelo usuário) é amostrado a 60fps e sua deflexão é traduzida em valores delta do mouse
  • Analógico Secundário para Controle Fino: O analógico secundário move o mouse a 1/5 da velocidade para posicionamento preciso
  • Direcional como Teclado: O direcional envia teclas de seta (Cima/Baixo/Esquerda/Direita), Start envia Enter, Select envia Espaço
  • Mapeamento de Botões Configurável: Atribua clique esquerdo, clique direito e clique do meio a qualquer botão do controle (A, B, X, Y, L1, R1, L2, R2, L3, R3, Start, Select)

Recursos Principais

  • Controle de Sensibilidade: Ajuste a velocidade do ponteiro de 0.1x a 5.0x para corresponder à sua preferência
  • Ajuste de Zona Morta: Defina o limite da zona morta (0.00–0.50) para eliminar drift do analógico
  • Seleção de Analógico: Escolha qual analógico (esquerdo ou direito) controla o mouse
  • Configurações por Sistema: Configuração independente para DOS e ScummVM
  • Substituição por Jogo: Ative ou desative o mouse analógico para ROMs individuais
  • Visualizador ao Vivo: Exibição em tempo real da posição do analógico com sobreposição de zona morta nas configurações

Para detalhes de implementação, consulte o Guia do Desenvolvedor.

Como Usar

Configuração Básica

  1. Abrir Configurações de Mouse Analógico

    Vá para Configurações → Mouse Analógico para configurar as preferências de sistema para DOS e ScummVM.

  2. Ativar o Recurso

    Ative o mouse analógico para DOS, ScummVM ou ambos. O recurso está desativado por padrão.

  3. Ajustar Sensibilidade

    Use o controle deslizante de sensibilidade (0.1x–5.0x) para definir a velocidade do cursor em resposta à deflexão do analógico.

  4. Definir Zona Morta

    Ajuste a zona morta para evitar movimento indesejado do cursor devido a drift do analógico. O visualizador ao vivo mostra a posição atual do analógico em relação à zona morta.

  5. Escolher seu Analógico

    Selecione qual analógico (esquerdo ou direito) controla o mouse. O outro analógico fornece controle fino em velocidade reduzida.

  6. Mapear Botões do Mouse

    Atribua clique esquerdo, clique direito e clique do meio aos botões do controle de sua preferência.

Substituição por Jogo

  1. Abrir Detalhes do Jogo

    Selecione uma ROM de DOS ou ScummVM em sua biblioteca e abra sua visualização de detalhes.

  2. Ativar Mouse Analógico

    Use o interruptor de Mouse Analógico para substituir a configuração do sistema para este jogo específico.

  3. Restaurar Padrão

    Use o botão Restaurar para limpar a substituição por jogo e reverter para a configuração do sistema.

Durante o Jogo

  • O analógico move o cursor — empurre suavemente para movimento preciso, deflexão total para navegação rápida
  • O analógico secundário oferece 1/5 da velocidade para posicionamento pixel-perfect
  • O direcional envia teclas de seta (útil para navegação de menus em jogos DOS)
  • Start age como Enter, Select age como Espaço
  • Os botões mapeados realizam ações de clique esquerdo/direito/meio
