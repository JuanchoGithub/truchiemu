Modo de Treinamento

O Modo de Treinamento do TruchiEmu fornece ferramentas de automação de P2 para jogos de luta, permitindo controlar o dummy com postura configurável, guarda, técnica de acordar, ações de reversal, programação de sequências e gravação de entradas.

Visão Geral do Serviço

O sistema de Modo de Treinamento adiciona uma sobreposição na tela a jogos de luta com ferramentas projetadas para prática e experimentação. Funciona injetando entradas automaticamente para o jogador 2, permitindo configurar o comportamento do dummy para praticar cenários específicos. O sistema se integra com a sobreposição de Lista de Movimentos para selecionar movimentos de personagens e atribuí-los a sequências de treinamento.

Recursos Principais

  • Controle de Dummy: Configure o modo de controle do P2 (espera, humano, guarda com postura, sequência FMD), postura (em pé, agachado, pulo), guarda (sem bloqueio, bloqueio total, bloqueio aleatório, bloqueio no primeiro golpe), técnica de acordar (nenhuma, recuperação rápida, rolamento para trás) e ações de reversal
  • Programação de Sequências: Construa uma sequência de cartas de dados de frames para P2 executar. Escolha condições de ativação (loop contínuo, ao bloquear, ao acertar), ajuste perfis de frames (1–5 frames de tolerância) e ative a auto-inversão de direção
  • Gravação de Entradas (Tape Deck): Grave as entradas do P1 em um de 3 slots e reproduza como P2. Inclui contagem regressiva antes de gravar e gerenciamento completo de slots
  • Exibição de Entrada: Visualização em tempo real das entradas de P1 e P2 renderizadas como tokens de notação de movimentos com rastreamento de índice de frame
  • Monitor FMD: Acompanhamento ao vivo das sequências de dados de frames ativas mostrando nome do movimento, progresso de frames e estado do gatilho
  • Posições de Reinício: Reinicie P2 para o início da rodada, canto esquerdo, canto direito ou um ponto de salvamento personalizado com suporte a teclas rápidas
  • Integração de Lista de Movimentos: Navegue pelos personagens disponíveis e seus movimentos diretamente da sobreposição de treinamento, com link direto para a sobreposição de Lista de Movimentos

Como Usar

Ativar o Modo de Treinamento

  1. Iniciar um Jogo de Luta

    Carregue qualquer jogo de luta compatível através da biblioteca do TruchiEmu.

  2. Abrir o Painel de Treinamento

    Na barra de ferramentas do jogo, clique no ícone do Modo de Treinamento ou pressione a tecla rápida configurada para abrir o painel.

  3. Ativar o Treinamento

    Clique no botão Ativar Treinamento no topo do painel. O modo de treinamento automaticamente juntará o P2 ao jogo.

  4. Configurar o Comportamento do Dummy

    Use a aba Dummy para configurar o modo de controle, postura, guarda, técnica de acordar e ação de reversal do P2. As alterações entram em vigor imediatamente.

Programar Sequências

  1. Abrir a Aba de Sequências

    Navegue até a aba de Sequências no painel de treinamento.

  2. Adicionar Cartas

    Clique no botão + para adicionar movimentos FMD (da lista de movimentos), cartas de atraso (pausa por um número de frames) ou blocos de fita (reproduzir uma entrada gravada).

  3. Configurar a Condição de Ativação

    Escolha quando a sequência é reproduzida: loop contínuo, ao bloquear ou ao acertar.

  4. Ajustar o Perfil de Frames

    Defina a tolerância de frames (1 = estrito, 5 = muito flexível) para controlar a precisão com que P2 executa a sequência.

Gravar Entradas

  1. Selecionar um Slot de Fita

    Na aba de Gravação, escolha um dos 3 slots para gravar.

  2. Iniciar Gravação

    Pressione o botão de gravar. Uma contagem regressiva de 3 segundos aparecerá, então a gravação começa.

  3. Reproduzir

    Atribua a fita gravada a um bloco de fita na aba de Sequências, ou ative a reprodução via tecla rápida. P2 replicará suas entradas gravadas.

Serviços Relacionados

Sobreposição de Movimentos

Os dados de movimentos dos personagens alimentam diretamente o modo de treinamento para programação de sequências e ações de reversal.

Estados de Salvamento

As posições de reinício personalizadas usam dados de save states para restaurar P1 e P2 a cenários de treinamento específicos.

Suporte a Controles

Configure teclas rápidas para os controles do modo de treinamento como reinício, gravação e reprodução.
