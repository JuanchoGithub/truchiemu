Move List e Fight Data

Notações de golpes na tela e uma extensa biblioteca curada de Fight Data com mais de 200 fighting games.

Visão Geral

O overlay Move List é a referência rápida na tela para fighting games. Mostra os golpes, specials e combos de cada personagem como tokens visuais — setas direcionais, glifos de botões e marcadores de condições especiais.

Recursos

  • Display On-Screen: Overlay durante o gameplay, categorizado por tipo (specials, supers, command normals, throws)
  • Tokens Visuais: Inputs direcionais, combinações de botões e condições especiais renderizam como tokens nítidos
  • Biblioteca de Fight Data: Mais de 200 sets curados — Street Fighter II, Mortal Kombat, KOF, Tekken, Samurai Shodown, Eternal Champions, Clay Fighter, Dragon Ball Z, Yu Yu Hakusho, TMNT Tournament Fighters e mais
  • Per-Game Sets: Carregamento automático com base no jogo em execução
  • Search & Filter: Busca rápida por nome, tipo de input ou personagem
  • Toggle Move Names: Exibe nomes legíveis junto aos tokens
  • MoveForest: Avaliador inteligente que rastreia os golpes
