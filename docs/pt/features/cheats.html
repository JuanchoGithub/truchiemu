Sistema de Cheats

Visão Geral do Serviço

O sistema de cheats permite gerenciar e ativar códigos de cheat para seus jogos. Ele suporta formatos padrão de códigos de cheat e integra-se com cores Libretro para aplicar modificações em tempo real.

Pipeline do sistema de cheats desde a análise de códigos até a injeção de memória

Recursos Principais

  • Suporte Multi-Formato: Game Genie, Pro Action Replay, GameShark e códigos hex brutos
  • Banco de Dados de Cheats: Baixe coleções de cheats pré-feitas do repositório libretro-database no GitHub
  • Estratégia de Download Híbrida: Cheats são baixados por sistema com fallback para download individual de ROMs quando arquivos por sistema não estão disponíveis
  • Auto-Descoberta: Cheats são descobertos e carregados automaticamente com base na ROM carregada. Cheats ativados anteriormente mantêm seu estado; novos cheats são desativados por padrão.
  • Entrada Manual de Cheats: Adicione manualmente seus próprios códigos e descrições

Formatos de Cheat Suportados

O TruchiEmu suporta múltiplos formatos de códigos de cheat: Game Genie (códigos alfanuméricos de 6-8 caracteres), Pro Action Replay (códigos hexadecimais com endereços), GameShark (vários formatos por sistema) e códigos de memória brutos para usuários avançados. Cada formato é detectado e analisado automaticamente de forma correta.

Para detalhes de implementação, consulte o Guia do Desenvolvedor.

Guia de Configuração Passo a Passo

Uso Básico de Cheats

  1. Acesse o Menu de Cheats

    Abra o menu de cheats selecionando Ferramentas → Cheats ou pressionando Cmd+Shift+C. A janela de gerenciamento de cheats exibe os cheats disponíveis para o jogo atual.

  2. Navegue pelo Banco de Dados de Cheats

    Use a barra de pesquisa para encontrar cheats específicos ou navegue por categoria. Categorias incluem Jogabilidade (vidas infinitas, saúde), Itens e Equipamentos (armas, power-ups), Depuração e Testes (seleção de fase) e Códigos Personalizados.

  3. Ative Cheats

    Marque a caixa ao lado de qualquer cheat para ativá-lo imediatamente. Cheats ativados mostram um indicador verde. Múltiplos cheats podem estar ativos simultaneamente.

  4. Teste no Jogo

    Retorne ao seu jogo e verifique se o cheat funciona como esperado. Alguns cheats requerem condições específicas (por exemplo, deve estar na tela de título, requer reset).

  5. Salve a Configuração de Cheats

    Suas seleções de cheats são salvas automaticamente ao ativar/desativar um cheat. Na próxima vez que carregar o jogo, cheats ativados anteriormente serão reativados automaticamente.

Entrada Manual de Cheats

  1. Adicionar Novo Cheat

    No menu de cheats, clique em "Adicionar Cheat" e insira um nome descritivo. Selecione o formato do cheat (Game Genie, Action Replay, etc.) no menu suspenso.

  2. Digite o Código de Cheat

    Digite ou cole o código de cheat no campo de código. O TruchiEmu detecta o formato automaticamente e analisa o código corretamente.

  3. Descrição e Notas

    Adicione uma descrição explicando o que o cheat faz e quaisquer condições especiais. Isso ajuda a organizar grandes coleções de cheats.

  4. Teste e Refine

    Ative o cheat e teste no jogo. Se não funcionar, verifique o formato do código e certifique-se de que corresponde à versão e região do seu jogo.

Solução de Problemas

Cheat Não Funciona

Sintoma: Cheat ativado mas não tem efeito no jogo.

Solução: Verifique se o cheat corresponde à versão e região do seu jogo. Alguns cheats só funcionam na tela de título ou requerem reset do jogo. Verifique se os cheats estão desativados no modo Hardcore do RetroAchievements.

Jogo Fecha com Cheats

Sintoma: O jogo fecha quando cheats específicos estão ativados.

Solução: Desative cheats conflitantes. Alguns cheats modificam endereços de memória críticos que causam instabilidade. Tente ativar cheats um de cada vez para identificar o código problemático.

Banco de Dados de Cheats Não Carrega

Sintoma: O banco de dados de cheats não mostra cheats para jogos suportados.

Solução: Re-baixe o banco de dados de cheats a partir das Configurações. Verifique a conexão com a internet para o download do banco de dados. Verifique se o hash da ROM corresponde a dumps bons conhecidos no banco de dados.

Serviços Relacionados

RetroAchievements

Cheats são automaticamente desativados no modo Hardcore para manter a integridade das conquistas.

Sistema de Save States
