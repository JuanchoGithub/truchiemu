Guia de Jogos

Visão Geral

Travou em um enigma? A barra lateral de Guia de Jogos integrada do TruchiEmu traz dicas e soluções direto para a janela do seu jogo, para que você nunca precise alternar para fora da ação. O guia aparece automaticamente para jogos de aventura e point-and-click, obtendo conteúdo de duas fontes confiáveis.

O Que Você Obtém

  • Detecção Automática: Jogos de aventura e point-and-click são identificados automaticamente por metadados de gênero ou sistema (jogos ScummVM sempre se qualificam)
  • Dicas Progressivas (UHS): Dicas sem spoilers que se revelam uma de cada vez — obtenha apenas a ajuda necessária sem estragar o enigma
  • Soluções Completas (GameFAQs): Soluções de texto completas como alternativa quando dicas UHS não estão disponíveis para seu jogo
  • Navegação por Controle: Navegue pelo guia com seu controle — analógicos rolam, botões A/B navegam, e o mesmo botão R3/L3 que abre a barra lateral a fecha
  • 387+ Mapeamentos de Jogos: Guias UHS pré-mapeados para aventuras clássicas incluindo Monkey Island, Broken Sword, Grim Fandango, Day of the Tentacle, e centenas mais

Como Funciona

Abrindo o Guia

Quando você inicia um jogo de aventura, o botão do guia aparece na barra de ferramentas do jogo. Você pode abrir a barra lateral do guia de três maneiras:

  • Botão da Barra de Ferramentas: Clique no ícone do guia na barra de ferramentas da janela do jogo
  • Atalho de Teclado: Pressione Cmd+J para alternar a barra lateral
  • Alternar por Controle: Pressione R3 ou L3 (o botão do analógico não primário) para abrir/fechar a barra lateral

Fontes do Guia

TruchiEmu usa duas fontes de guias, testadas em ordem:

Dicas UHS Principal

O Universal Hint System fornece dicas progressivas sem spoilers. As perguntas são organizadas em capítulos, e cada pergunta revela dicas uma de cada vez — de uma suave sugestão até a resposta completa.

Soluções GameFAQs Alternativa

Quando nenhum guia UHS está disponível, TruchiEmu busca soluções de texto no GameFAQs. Navegue pela lista de FAQs disponíveis e leia soluções completas dentro do jogo.

Mapeamento de Jogos

TruchiEmu usa múltiplas estratégias para encontrar o guia certo para seu jogo:

  • ID do Jogo ScummVM: Para jogos ScummVM, o ID interno do jogo (ex. tentacle, monkey, sword1) é comparado com um banco de dados curado de mais de 387 mapeamentos de guias UHS
  • Comparação de Título: Para DOS e outros sistemas, o título do jogo é comparado de forma difusa contra títulos de guias UHS conhecidos, incluindo títulos alternativos e variação comuns de nome
  • Detecção de Gênero: Jogos com "Adventure" ou "Point & Click" em seus metadados de gênero obtêm automaticamente a alternativa GameFAQs mesmo sem mapeamento UHS

Usando o Guia

Dicas Progressivas (UHS)

  1. Navegue os Capítulos

    Quando você abrir o guia, verá uma lista de capítulos e tópicos. Navegue com seu mouse, teclado ou controle.

  2. Selecione uma Pergunta

    Toque em uma pergunta para ver suas dicas. Perguntas são marcadas com um ícone de interrogação; tópicos com um ícone de pasta.

  3. Revele Dicas Uma a Uma

    Clique em "Mostrar próxima dica" para revelar a próxima dica. Cada dica dá progressivamente mais ajuda. Use "Revelar tudo" se quiser a resposta completa imediatamente.

  4. Navegue para Trás

    Use o botão voltar ou Esc para retornar à lista de capítulos. A trilha de navegação mantém registro de onde você está.

Soluções GameFAQs

  1. Navegue a Lista de FAQs

    Quando dicas UHS não estão disponíveis, você verá uma lista de soluções GameFAQs para seu jogo.

  2. Leia uma Solução

    Selecione um FAQ para ler seu conteúdo de texto completo. O texto é exibido em fonte monoespaçada com seleção de texto habilitada para copiar.

Navegação por Controle

Quando a barra lateral do guia está aberta, a entrada do seu controle é redirecionada automaticamente:

  • Analógicos: Mova o cursor para navegar pela barra lateral. O analógico primário move em velocidade completa, o secundário em velocidade reduzida
  • Botão A: Funciona como clique esquerdo (selecionar itens, revelar dicas)
  • Botão B: Funciona como clique direito
  • R3/L3: Alternar a barra lateral aberta/fechada
  • Rolagem: Mova o analógico além da zona morta para rolar pela lista do guia

Captura de Entrada: Quando a barra lateral do guia abre para jogos DOS ou ScummVM, a captura de teclado e mouse é liberada automaticamente para que você possa interagir com a barra lateral. Ao fechar a barra lateral, a captura é retomada automaticamente.
