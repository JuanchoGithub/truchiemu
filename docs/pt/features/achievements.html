Integração com RetroAchievements

O TruchiEmu integra-se com RetroAchievements.org para rastrear e desbloquear conquistas em jogos clássicos.

Visão Geral do Serviço

O serviço RetroAchievements conecta-se ao RetroAchievements.org para rastrear e desbloquear conquistas durante o gameplay. Ele integra-se com o core Libretro para detectar condições de conquistas em tempo real.

Pipeline de detecção de conquistas desde a memória do jogo até a sincronização com RetroAchievements.org

Recursos Principais

  • Desbloqueio em Tempo Real: Conquistas são detectadas e desbloqueadas durante o gameplay
  • Rich Presence: Compartilhe seu jogo atual e atividade com a comunidade RetroAchievements
  • Modo Hardcore: Ganhe conquistas sem save states, rewinds ou cheats para prestígio máximo

Para detalhes de implementação, consulte o Guia do Desenvolvedor.

Guia de Configuração Passo a Passo

Configuração Inicial

  1. Crie uma Conta no RetroAchievements

    Visite RetroAchievements.org e crie uma conta gratuita. Verifique seu endereço de e-mail para desbloquear a funcionalidade completa.

  2. Configure as Credenciais do TruchiEmu

    No TruchiEmu, vá para Configurações → Conquistas → Conta e insira seu nome de usuário e chave de API do RetroAchievements. Gere sua chave de API no site do RetroAchievements em Configurações da Conta.

  3. Teste a Conexão

    Clique em "Testar Conexão" para verificar se suas credenciais funcionam corretamente. Você deve ver uma mensagem de sucesso com suas estatísticas atuais.

  4. Ative a Detecção de Conquistas

    Ative "Ativar Detecção de Conquistas" no painel principal de configurações de Conquistas.

  5. Configure o Rich Presence

    Ative "Mostrar Rich Presence" para compartilhar sua atividade de jogo com o Discord e a comunidade RA. Personalize o formato da mensagem no campo de texto fornecido.

Configuração por Jogo

  1. Carregue um Jogo Suportado

    Abra uma ROM de um sistema suportado. O TruchiEmu detecta automaticamente se o jogo possui conquistas disponíveis.

  2. Visualize a Lista de Conquistas

    Abra a lista de conquistas no menu do jogo para ver todas as conquistas disponíveis para o jogo atual.

  3. Acompanhe o Progresso das Conquistas

    O progresso das conquistas é exibido durante o gameplay com notificações na tela quando as condições são atendidas.

Solução de Problemas

Conquistas Não Estão Sendo Desbloqueadas

Sintoma: Jogando um jogo suportado mas as conquistas não estão sendo detectadas.

Solução: Verifique se sua ROM é a versão correta (geralmente USA/World). Verifique o hash da ROM contra o banco de dados RetroAchievements. Certifique-se de que a detecção de conquistas está ativada nas configurações.

Erros de Conexão

Sintoma: Mensagem de erro "Falha ao conectar ao RetroAchievements.org".

Solução: Verifique sua conexão com a internet e configurações de firewall. Verifique se a chave de API está correta e não expirou. Tente gerar uma nova chave de API no site do RA.

Rich Presence Não Funciona

Sintoma: O Discord ou perfil do RA não mostra o status do jogo atual.

Solução: Ative o rich presence nas configurações. Verifique se você não está no modo Hardcore (algumas plataformas desativam o rich presence para integridade competitiva). Verifique a conexão do Discord nas configurações de Privacidade do macOS.

Restrições do Modo Hardcore

Sintoma: Não é possível usar save states ou rewind após ativar o modo Hardcore.

Solução: Este é o comportamento pretendido. O modo Hardcore desativa esses recursos para justiça competitiva. Desative o modo Hardcore para restaurar a funcionalidade.
