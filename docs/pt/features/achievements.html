Integração com RetroAchievements

O TruchiEmu integra-se com RetroAchievements.org para rastrear e desbloquear conquistas em jogos clássicos.

Visão Geral

RetroAchievements transforma jogos clássicos em um desafio de conclusão. Faça login na sua conta do RetroAchievements.org e o TruchiEmu acompanhará seu progresso, desbloqueará conquistas conforme você as obtiver, e compartilhará o que você está jogando com a comunidade. Um Modo Hardcore está disponível para puristas que querem a execução válida para o leaderboard.

O que Está Incluído

  • Acompanhamento de Conquistas: Desbloqueie troféus por feitos no jogo — derrote o chefe sem morrer, encontre o segredo, maximize o combo, e assim por diante
  • Rich Presence: Seu jogo e atividade atuais são compartilhados com a comunidade RetroAchievements automaticamente
  • Modo Hardcore: Ganhe conquistas da forma como o leaderboard conta — sem save states, sem rebobinar, sem câmera lenta, sem cheats. Desativado por padrão; ative pelo painel de Conquistas
  • Notificações no Jogo: Desbloqueios de conquista aparecem como uma pílula na janela do jogo para você não perder
  • Perfil & Lista de Jogos: Suas conquistas desbloqueadas são sincronizadas com seu perfil no RetroAchievements.org

Guia de Configuração Passo a Passo

Configuração Inicial

  1. Crie uma Conta no RetroAchievements

    Visite RetroAchievements.org e crie uma conta gratuita. Verifique seu endereço de e-mail para desbloquear a funcionalidade completa.

  2. Configure as Credenciais do TruchiEmu

    No TruchiEmu, vá para Configurações → Conquistas → Conta e insira seu nome de usuário, senha e chave de Web API do RetroAchievements. Gere sua chave de Web API no site do RetroAchievements em Configurações (Painel de Controle).

  3. Conecte

    Clique no botão "Conectar" para verificar suas credenciais. Se bem-sucedido, um indicador verde "Conectado" aparecerá ao lado do botão.

  4. Ative o RetroAchievements

    Ative o toggle "RetroAchievements" no painel principal de configurações de Conquistas.

  5. Configure o Rich Presence

    Ative "Mostrar Rich Presence" para compartilhar automaticamente sua atividade de jogo atual com a comunidade RetroAchievements.

Configuração por Jogo

  1. Carregue um Jogo Suportado

    Abra uma ROM de um sistema suportado. O TruchiEmu detecta automaticamente se o jogo possui conquistas disponíveis.

  2. Visualize a Lista de Conquistas

    Abra a lista de conquistas no menu do jogo para ver todas as conquistas disponíveis para o jogo atual.

  3. Acompanhe o Progresso das Conquistas

    O progresso das conquistas é exibido durante o gameplay com notificações na tela quando as condições são atendidas.

Solução de Problemas

Conquistas Não Estão Sendo Desbloqueadas

Sintoma: Jogando um jogo suportado mas as conquistas não estão sendo detectadas.

Solução: Verifique se sua ROM é a versão correta (geralmente USA/World). Verifique o hash da ROM contra o banco de dados RetroAchievements. Certifique-se de que a detecção de conquistas está ativada nas configurações.

Erros de Conexão

Sintoma: Mensagem de erro "Falha ao conectar ao RetroAchievements.org".

Solução: Verifique sua conexão com a internet e configurações de firewall. Verifique se a chave de API está correta e não expirou. Tente gerar uma nova chave de API no site do RA.

Rich Presence Não Funciona

Sintoma: O perfil do RA não mostra o status do jogo atual.

Solução: Ative o rich presence nas configurações. Verifique sua conexão com a internet e se suas credenciais do RA estão corretas.

Restrições do Modo Hardcore

Sintoma: Não é possível usar save states, rewind ou câmera lenta após ativar o modo Hardcore.

Solução: Este é o comportamento pretendido. O modo Hardcore desativa esses recursos para justiça competitiva. Desative o modo Hardcore para restaurar a funcionalidade.
