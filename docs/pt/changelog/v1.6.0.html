Registro de mudanças / v1.6.0

v1.6.0

4 de julho de 2026

Reformulação das configurações de streaming, integração do botão de compartilhar, alternância de bezels, download de dados hash e uma grande reorganização da navegação nas configurações.

Destaques

  • Interface de Streaming e Verificação de Chaves: Nova visualização com abas para Twitch, YouTube e streams personalizados. Botão de verificação com feedback em tempo real
  • Botão Compartilhar e Salvar Últimos Momentos: Novas ações de teclas para compartilhar com pressionamento simples e prolongado, com serviço de buffer de vídeo para capturar jogabilidade recente
  • Reformulação da Navegação em Configurações: IDs de seção focadas, chip de navegação de volta e visibilidade condicional de seções
  • Alternância de Bezels: Ative ou desative bezels por jogo diretamente na visualização de detalhes
  • Download de Dados Hash: Baixe dados hash ausentes com prompts na interface para melhor identificação de ROMs
  • Reestruturação de Opções do Núcleo: Gerenciamento de opções atualizado para usar CoreOptionsContext
  • Otimização de Buffer de Pixel: Cópia de memória mais rápida em capturas para diferentes bytes por linha
  • Correção de Frequências AAC: Removidas frequências de amostragem inválidas da lista de AAC

Mudanças detalhadas

  • Adicionado StreamingTabView com abas para configuração de Twitch, YouTube e streams personalizados
  • Criado VerifyButton com feedback visual para estados de verificação bem-sucedida e falha
  • Adicionado StreamingMediaSettingsView gerenciando comportamento do botão compartilhar e buffer contínuo
  • Adicionadas novas ações de teclas: compartilhar com pressionamento simples e prolongado
  • Atualizado HotkeyConfigManager para lidar com ações de compartilhar
  • Adicionado RollingVideoBufferService para capturar jogabilidade recente
  • Adicionada alternância de bezels na visualização de detalhes do jogo (Bezels.swift)
  • Adicionada funcionalidade de download de dados hash com prompts na interface
  • Refatorada a navegação de configurações com IDs de seção focadas e chip de navegação de volta
  • Refatorado o gerenciamento de opções do núcleo para usar CoreOptionsContext
  • Otimizada a cópia de memória do buffer de pixel para diferentes bytes por linha
  • Removidas frequências de amostragem inválidas da lista de AAC
  • Atualizados en.json, es.json e pt.json com mais de 88 novas chaves de tradução cada
