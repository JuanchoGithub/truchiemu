Registro de alterações / v1.2.0

v1.2.0

12 de junho de 2026

Versão importante adicionando suporte a ROMs compactadas (ZIP, 7z, RAR), desambiguação MAME/FBNeo, identificação CRC de sistema, identificação de setor de boot, mesclagem de sistemas e extensas correções de bugs.

Destaques

  • Suporte a ROMs compactadas: Execute ROMs ZIP, 7z e RAR diretamente. Núcleos que suportam arquivos recebem o arquivo como está; outros recebem extração automática com cache persistente e limpeza configurável por TTL
  • Desambiguação MAME/FBNeo: ROMs Arcade agora identificadas corretamente como conjuntos MAME ou FBNeo via validação baseada em banco de dados
  • Desambiguação CRC de sistema: Correspondência CRC32 completa com bancos de dados Libretro DAT quando os dois principais candidatos estão próximos
  • Identificação de setor de boot: Cabeçalhos mágicos positivos para Dreamcast, 3DO, Xbox, CD-i, GameCube, Wii, PC Engine CD e Atari 7800
  • Mesclagem de sistemas: Mesclar GB+GBC em uma única entrada "Game Boy"; mesclar MAME+FBNeo em "Arcade (MAME / FBNeo)" na barra lateral
  • Melhorias em miniaturas: Investigar todos os nomes de pasta do banco de dados para um sistema, armazenando em cache pastas funcionais

Correções detalhadas

  • Removido .bin das listas de extensão NES/SNES/N64/GBA/GB/DS/SMS (grande fonte de falsos positivos)
  • Removido "/" como extensão em Amiga/C64 (causava bugs de varredura de diretório)
  • Removido .cue das extensões do Genesis (identificação falsa de jogo CD)
  • Removidas extensões GB/GBC/SGB de NES/SNES/GBA (ROMs do sistema errado vazando)
  • MAME agora valida apenas dependências do núcleo ativo
  • Exclusão de categoria agora funciona (era um no-op antes)
  • ROMs escaneados são auto-selecionados na biblioteca após conclusão
  • Metadados e cheats agora chaveados por runningKey (caminho do arquivo + caminho interno)
  • Cache SwiftData descartado automaticamente após atualizações do app
