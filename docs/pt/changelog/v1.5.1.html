Registro de alterações / v1.5.1

v1.5.1

2 de julho de 2026

Patch de emergência que corrige o embedding do dylib librashader em builds de release e adiciona funcionalidade de teste de notificação, exclusão em massa do gerenciador de saves e polimento da documentação.

Destaques

  • Correção de emergência do librashader: dylib agora copiado para Frameworks/ com install name correto, ARCHS bloqueado para arm64 — builds de release não travam mais ao iniciar
  • Notificações: adicionada funcionalidade de teste de notificação e manuseio de autorização melhorado
  • Gerenciador de saves: ação "Excluir todos os saves" em massa com confirmação de UI melhorada
  • Shaders: removidas especificações de shaders para maior clareza e concisão
  • Documentação: removidas seções de solução de problemas em todos os idiomas; docs de recursos melhoradas com suporte a controles, streaming e guia de jogo atualizado

Alterações detalhadas

  • Corrigido o embedding do dylib librashader: agora copiado para a pasta Frameworks com o install name correto
  • Bloqueado ARCHS para arm64 (librashader é somente arm64)
  • Adicionada ação de teste de notificação e manuseio de autorização melhorado no NotificationPill
  • Implementada funcionalidade "Excluir todos os saves" com melhoria na confirmação de UI no gerenciador de saves
  • Refatorados shaders: especificações removidas para maior clareza e concisão
  • Atualizada a documentação de shaders com novos recursos e descrições melhores
  • Removidas seções de solução de problemas em todas as variantes de idioma e deletadas as páginas dedicadas de solução de problemas
  • Melhorada a documentação de recursos com novas seções para suporte a controles, streaming e guia de jogo atualizado
  • Simplificadas as docs de recursos e reorganizados os links de navegação
