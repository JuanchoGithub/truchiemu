Registro de mudanças / v1.7.1

v1.7.1

16 de julho de 2026

Correção crítica: atualizar da v1.6.0 para a v1.7.0 podia excluir toda a pasta de dados de usuário do TruchiEmu (saves, BIOS, estados, cheats, banco de dados da biblioteca). A v1.7.1 corrige a migração para que os dados do usuário sejam preservados.

Destaques

  • Correção de perda de dados: Atualizar da v1.6.0 para a v1.7.0 excluía toda a pasta ~/Library/Application Support/TruchiEmu/. A v1.7.1 corrige a migração de esquema do campo ROMEntry.hasTitleScreen para que a migração seja bem-sucedida e os dados do usuário sejam preservados.
  • Defesa em profundidade: O caminho de recuperação reservado do armazenamento não toca mais na pasta de dados do usuário — apenas os três arquivos SQLite do SwiftData (TruchiEmu.sqlite, -wal, -shm). Saves, BIOS, configurações, cheats e logs nunca são excluídos pelo caminho de recuperação, mesmo em uma migração com falha.

Mudanças detalhadas

  • Alterado ROMEntry.hasTitleScreen de Bool não opcional para Bool? opcional para que o SwiftData/CoreData possa migrar automaticamente as linhas existentes da v1.6.0 (linhas existentes recebem nil, tratado como false por todos os pontos de uso)
  • Restrito SwiftDataContainer.deleteStoreFiles() para que remova apenas a tríplice SQLite (TruchiEmu.sqlite/-wal/-shm) e os arquivos legados default.store* na raiz — nunca toda a pasta de dados do usuário TruchiEmu/
  • Coalescência das leituras de ROMEntry.hasTitleScreen para false nos pontos de uso que convertem entre o modelo SwiftData e a struct ROM simples

Se você já atualizou para a v1.7.0 e perdeu dados

A v1.7.1 não pode recuperar dados que já foram excluídos pela v1.7.0 em uma execução anterior. Se você foi afetado, suas opções são:

  • Instantâneos locais APFS do macOS: O macOS costuma reter instantâneos locais de curta duração do disco. Abra o Time Machine na barra de menu ou execute /System/Applications/Utilities/Time Machine.app e restaure ~/Library/Application Support/TruchiEmu/ a partir de um instantâneo anterior à execução da v1.7.0.
  • Backup do Time Machine: Se você tem um drive externo do Time Machine, restaure a mesma pasta do seu backup mais recente anterior à atualização.
  • Instale a v1.7.1 primeiro antes de restaurar: depois que a v1.7.1 estiver instalada, futuras execuções não excluirão mais a pasta, então uma pasta restaurada não será apagada no próximo lançamento.
