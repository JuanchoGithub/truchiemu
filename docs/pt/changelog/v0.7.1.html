Registro de alterações / v0.7.1

v0.7.1 More improvements

8 de maio de 2026 60 commits

Versão rica em recursos introduzindo integração RetroAchievements, emulação Saturn, uma base massiva de cheats e o lançamento do site de documentação.

Destaques

Integração RetroAchievements

  • Suporte completo RetroAchievements com hash de ROMs, cache de jogos e interface de comparação de hash
  • Decodificação flexível de inteiros para condições de conquistas
  • Modelos SwiftData expandidos para suporte RetroAchievements

Melhorias de emulação

  • Emulação Saturn melhorada com suporte a BIOS
  • Identificação de ROMs melhorada com análise de nomes mais inteligente
  • Distorção de barril do shader CRT melhorada

Sistema de cheats

  • Base massiva de cheats cobrindo mais de 40 plataformas
  • Nova interface de gerenciamento de cheats fácil de usar
  • Arquivos de cheats adicionados aos recursos do projeto Xcode

Lançamento do site de documentação

  • Site de documentação completo no GitHub Pages com mais de 21 páginas HTML
  • Fluxo de trabalho GitHub Actions para implantação automatizada Jekyll
  • Estrutura de documentação multilíngue
