Registro de alterações / v1.0.0

v1.0.0

10 de junho de 2026

Primeira versão estável! Integração completa com RetroAchievements, painel lateral do guia de jogo, configurações de deadzone do controle, serviço de BIOS Jaguar, reformulação do escaneamento ISO e muito mais.

Destaques

  • Integração RetroAchievements: Runtime rcheevos completo com rastreamento de conquistas, rich presence e manuseio de conquistas exclusivas
  • Painel lateral do guia de jogo: Dicas progressivas (UHS) e walkthroughs (GameFAQs) para jogos de aventura e point-and-click, com navegação completa por gamepad
  • Configurações de exibição de conquistas: Novos modos de visualização e seções de conquistas aprimoradas em GameDetailView
  • Serviço de BIOS Jaguar: Extração automática de BIOS para jogos de Atari Jaguar
  • Configurações de deadzone do controle: Configuração de deadzone por controle com controles deslizantes na UI
  • Escape Toast Overlay: Feedback visual durante captura de entrada de teclado/mouse
  • Melhorias no escaneamento ISO: Detecção de formato de setor, recuperação de tamanho LBN, suporte a arquivos descritores CUE/MDS/CCD
  • Melhorias no Notification Pill: Dispensar com toque e atraso de dispensa automática configurável
  • Expansão progressiva de save states: Slots de save state expansíveis em GameDetailView

Alterações detalhadas

  • Corrigido: analisador de registro de diretório ISO9660 adequado (substitui heurística)
  • Corrigido: hashing correto de ROM PSP para RetroAchievements
  • Corrigido: manuseio de subcabeçalho CD-ROM Mode 2 e deslocamentos de setor PC-FX
  • Corrigido: deslocamento de comprimento de dados ISO9660 e manuseio de sufixo de versão PSP
  • Corrigido: presets de shader padrão para Game Boy e Game Boy Color
  • Corrigida: resolução aprimorada de capas locais com verificação de existência de arquivo
  • Trocado para hashing MD5 para identificação de ROM em RetroAchievements (substitui CRC32)
  • Detecção automática de jogo RA aprimorada com manuseio de notificações
  • Melhorias de pré-carregamento de badges de conquistas
  • Localização atualizada em inglês, espanhol e português
  • Documentação do Guia de Jogo adicionada nos três idiomas
