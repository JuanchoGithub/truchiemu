Solução de Problemas

Está tendo problemas com o TruchiEmu? Este guia aborda problemas comuns e suas soluções para instalação, desempenho, controles, shaders e mais.

Obtendo Ajuda

Antes de contatar o suporte, tente estes passos:

  • Verifique o guia de Primeiros Passos para noções básicas de configuração
  • Pesquise nos GitHub Issues por problemas conhecidos
  • Pergunte à comunidade nas GitHub Discussions

Problemas de Instalação

O Aplicativo Não Abre

Sintoma: O TruchiEmu pulsa no dock mas não inicia, ou mostra "TruchiEmu não pode ser aberto porque é de um desenvolvedor não identificado."

Solução: O macOS pode bloquear aplicativos não notarizados pela Apple. Clique com o botão direito (ou Ctrl-clique) no aplicativo e selecione "Abrir" no menu de contexto, depois clique "Abrir" no diálogo. Alternativamente, vá em Ajustes do Sistema > Privacidade e Segurança e procure uma mensagem sobre o TruchiEmu estar bloqueado.

O Aplicativo Fecha ao Iniciar

Sintoma: O TruchiEmu fecha imediatamente após ser iniciado.

Solução: Verifique se sua versão do macOS é 14.0 (Sonoma) ou posterior. Use a ferramenta integrada de Diagnóstico de Ambiente nas Configurações para verificar problemas de compatibilidade de hardware. Se o aplicativo não abrir de todo, tente excluir o arquivo de preferências em ~/Library/Preferences/com.truchiemu.plist.

Dependências Ausentes

Sintoma: Mensagens de erro sobre bibliotecas ou frameworks ausentes ao compilar a partir do código-fonte.

Solução: Certifique-se de que o Xcode Command Line Tools está instalado (xcode-select --install). Instale as dependências necessárias com Homebrew: brew install cmake xcodegen.

Problemas de Desempenho

Taxa de Quadros Baixa / Travamentos

Sintoma: Jogos rodam abaixo da velocidade máxima ou têm travamentos frequentes.

Solução: Tente estes passos em ordem:

  1. Reduza a complexidade do shader ou use o shader Passthrough
  2. Reduza a escala de resolução interna (para sistemas 3D como N64, PSP)
  3. Aumente o buffer de áudio para 128-256ms
  4. Ative o salto de quadros (máximo de 1-2 quadros)
  5. Feche outros aplicativos para liberar recursos do sistema
  6. Para N64: tente um plugin de gráficos diferente (GLideN64 vs Angrylion)

Áudio com Estalos ou Chiados

Sintoma: Áudio distorcido, especialmente durante transições de cena ou sequências de áudio complexas.

Solução: Aumente o tamanho do buffer de áudio em Configurações > Áudio. Tente 128ms ou 256ms. Desative "Reduzir Latência de Áudio" se estiver ativado. Para jogos com DSP pesado (Pilotwings, Super Mario Kart), use o core snes9x com correção de áudio ativada.

Alto Uso de CPU

Sintoma: O TruchiEmu usa CPU excessiva mesmo quando inativo ou em jogos simples.

Solução: Desative a renderização em threads se estiver ativada em sistemas de núcleo único. Use cores de emulação mais leves (fceumm em vez de mesen para NES, snes9x em vez de bsnes para SNES). Desative o recurso de rewind se não for necessário. Reduza os quadros de runahead para 0 ou 1.

Problemas de Controles

Controle Não Detectado

Sintoma: Controle conectado mas não reconhecido pelo TruchiEmu.

Solução: Verifique Ajustes do Sistema do macOS > Privacidade e Segurança > Bluetooth (para sem fio). Certifique-se de que o controle está pareado antes de iniciar o TruchiEmu. Para controles Xbox, tente uma conexão USB com cabo primeiro. Reinicie o TruchiEmu com o controle conectado.

Atraso de Entrada

Sintoma: Atraso entre pressionar um botão e a ação aparecer na tela.

Solução: Use uma conexão com cabo em vez de Bluetooth. Reduza o tamanho do buffer de áudio. Desative o V-Sync ou ative "Hard GPU Sync" com 0-1 quadros. Reduza o runahead para 1-2 quadros para entrada mais responsiva.

Mapeamento de Botões Incorreto

Sintoma: Os botões não correspondem ao layout esperado.

Solução: Abra Configurações > Controles > Mapeamento de Botões e remapeie os botões conforme necessário. Salve como um perfil para reutilização. Verifique se uma substituição por core ou por jogo está ativa.

Desvio do Analógico

Sintoma: O personagem se move sem tocar o controle.

Solução: Aumente a deadzone para 15-20% nas configurações de calibração do controle. Execute o assistente de calibração para detectar a posição central. Limpe os analógicos do controle com ar comprimido.

Problemas de Shaders

Falhas na Compilação de Shaders

Sintoma: "Metal compiler error" ao selecionar um shader.

Solução: Atualize o macOS para a versão mais recente para os recursos Metal mais novos. Verifique se sua GPU suporta o conjunto de recursos Metal necessário (requer macOS 14+).

Nenhum Efeito Visível

Sintoma: O shader está selecionado mas nenhuma mudança visual é perceptível.

Solução: Alguns shaders têm efeitos sutis. Verifique os controles de intensidade do shader nas configurações. Tente um shader mais notável como o CRT-Royale para verificar se o sistema funciona.

Impacto no Desempenho do Shader

Sintoma: A taxa de quadros cai com shaders complexos ativados.

Solução: Use shaders mais simples (Lite CRT em vez de CRT Multipass, ScaleFX em vez de xBRZ). Reduza a complexidade da cadeia de shaders. Considere usar configurações de shader por jogo para usar shaders leves em jogos exigentes.

Problemas de Carregamento de ROMs

ROM Não Reconhecida

Sintoma: O jogo aparece como "Desconhecido" ou não aparece na biblioteca.

Solução: Verifique se o tipo de arquivo ROM é suportado pelo sistema alvo. Confirme se a extensão do arquivo está na lista permitida. Tente um dump de ROM diferente de uma fonte verificada. Identifique manualmente o jogo clicando com o botão direito > Identificar Jogo.

Jogo Não Inicia

Sintoma: O jogo aparece na biblioteca mas fecha ao iniciar.

Solução: Certifique-se de ter o core correto instalado para o sistema. Verifique se o jogo requer arquivos de BIOS (PlayStation, Saturn, Neo Geo). Tente um core de emulação diferente. Verifique se a ROM não está corrompida.

Sistema Errado Detectado

Sintoma: O jogo inicia com o core do emulador errado.

Solução: Clique com o botão direito no jogo e selecione "Editar Metadados", depois corrija a atribuição do sistema. Você também pode definir cores padrão por sistema em Configurações > Cores.

Problemas de Save States

Jogos de Dreamcast Não Salvam

Sintoma: Jogos de Dreamcast não reconhecem nenhum cartão de memória (VMU). Os salvamentos falham silenciosamente sem mensagem de erro.

Solução: Isso é tipicamente causado por opções do core Flycast mal configuradas ou arquivos VMU ausentes/corrompidos. Certifique-se de que o CoreOverrides.json usa "VMU" (não "Visual Memory") para as opções de slot de porta do dispositivo. Veja Depurando Salvamentos VMU do Dreamcast — análise técnica aprofundada sobre como corrigir a detecção VMU do Flycast.

Save States Não Carregam

Sintoma: O save state aparece no navegador mas falha ao carregar.

Solução: Certifique-se de que está usando a mesma versão do core que criou o salvamento. Save states não são compatíveis entre cores diferentes. Verifique se o arquivo de salvamento não está corrompido verificando seu checksum.

Conflitos de Sincronização em Nuvem

Sintoma: Mensagens de erro sobre save states conflitantes entre dispositivos.

Solução: Revise as configurações de resolução de conflitos nas preferências de Save State. Resolva conflitos manualmente no painel de sincronização. Use bancos de slots diferentes para dispositivos diferentes.

Relatando Bugs

Ao relatar problemas no GitHub, por favor inclua:

  • Sua versão do macOS e hardware (Apple Silicon ou Intel)
  • Número da versão do TruchiEmu
  • O core de emulação e jogo que você estava usando
  • Passos para reproduzir o problema
  • Quaisquer mensagens de erro ou logs de crash
  • Capturas de tela ou gravações de tela, se aplicável

Logs de crash podem ser encontrados em: ~/Library/Logs/DiagnosticReports/
