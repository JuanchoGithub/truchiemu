Solução de Problemas

A maioria dos problemas pode ser diagnosticada pelos logs. Se precisar de mais ajuda, consulte as Issues do GitHub.

Verifique os Logs

O TruchiEmu escreve logs detalhados para ajudar a diagnosticar problemas:

  • Logs do App: ~/Library/Logs/TruchiEmu/ — logs gerais da aplicação e emulação
  • Relatórios de Crash: ~/Library/Logs/DiagnosticReports/ — logs de falhas do sistema

Ative o log verbose em Configurações → Avançado → Nível de Log para capturar mais detalhes.

Issues do GitHub

Pesquise issues existentes ou abra uma nova em github.com/JuanchoGithub/truchiemu/issues.

Ao relatar um bug, inclua sua versão do macOS, a versão do TruchiEmu e a saída relevante dos logs.
